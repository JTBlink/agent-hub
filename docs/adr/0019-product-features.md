# ADR-0019：产品配置与 Cargo features 编译期组装

- 状态：已接受
- 日期：2026-11-05
- 规格：GitHub Issue #289

## 决策

默认标准版使用 `standard` 产品配置，Personal 个人版使用 `personal`。产品身份、Cargo 特性集合与 dev/release profile 分别表达，不以 feature 充当互斥产品名称。

产品清单驱动前端静态模块入口、Rust 条件编译、配套 CLI、权限与资源。首期仅保证 Herdr 完整可选；功能独立贡献侧栏与路由，公共工作台维护布局和生命周期。

默认标准版保留既有路径，其他产品使用独立构建根、安装标识、端口、数据、凭据及任务命名空间。显式共享项目与外部工具身份继续遵守各自协议。未配置更新渠道的产品不使用标准版安装包。

## 兼容与影响

本决策扩展 ADR-0008 的标准单应用约定，各产品内部仍只有一套宿主及共享实现。关闭特性不删除数据库迁移、用户文件或已有外部任务；产品 ID 保持稳定，不随每次特性变化清空数据。源码非公开是访问策略，不建立第三类产品。首次落地不拆通用 SDK 或动态插件系统。

实现与目录见[应用组装边界](../architecture/app-composition.md)，操作见[编译与安装](../build-and-install.md)。
