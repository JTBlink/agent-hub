# ADR-0020：Agent 执行与状态基础能力集中维护

- 状态：已接受
- 日期：2026-11-07
- 关联：[#294](https://github.com/JTBlink/agent-hub/issues/294)

## 背景

独立任务包曾分发完整 Herdr 生命周期和 Python 状态存储副本。维护源虽一致，已安装任务仍可能长期运行旧副本；任务同时重复实现其他入口已经提供的配置化 Agent 启动。

## 决策

- 沿用 `src-tauri/src/core/`，跨模块能力按职责命名；不增加新的 platform 根目录。
- `agent_execution` 提供显式路径请求、运行观察与恢复入口，任务、CLI 及需要受管理执行的其他入口共用。
- Herdr 专有的命令、身份、布局与状态规则位于 `herdr`。复用现有配置化启动与统一命令客户端，各入口保留自己的焦点、复用、忙碌处理及业务策略。
- `state_store` 提供状态读取、进程运行锁及兼容的 Python 事务存储；业务格式、累计次数与处理决策仍归调用方。
- 保留已经验证的 Python 生命周期实现，由 Rust core/CLI 嵌入并按内容版本发布到本机 runtime。任务包仅分发薄适配器；新版任务需要匹配 CLI，无需桌面进程或开发仓库。
- 旧任务不自动改写。显式更新保留 ID、日程、启停、项目绑定、身份目录、检查点与本地记录。运行资源不随定义导出或备份。

本决策调整 ADR-0016 中“任务携带完整通用运行实现”的分发方式，独立业务包、私有状态和显式迁移约束继续有效。尚未更新的完整旧脚本保留既有行为，不静默切换。

## 验证

通过公共执行入口和后端模拟覆盖忙碌、等待输入、身份更换、超时、重复投递防护与恢复；通过版本资源测试覆盖复用、升级并存及链接/内容篡改拒绝。模板测试验证薄适配契约，业务回调继续验证真实状态和累计次数。支持关闭 Herdr Cargo feature，普通任务不新增 Agent 依赖。
