# ADR-0011：项目技能使用与管理清单分离

- 状态：已接受（2026-10-12）
- 范围：普通项目；细化 ADR-0010 的团队交付规则。

## 决策

团队只需 Git 和所使用的 Agent。技能实际内容与 Agent 原生入口是交付内容；`.agent-hub/project-skills.json` 是 AgentHub 的管理清单，可选择随项目共享，不作为技能读取或团队使用的前提。本决策替代 ADR-0010 中项目元数据必须随 Git 提交的要求，其余部署和修改保护规则不变。

维护者使用 AgentHub 时仍保留清单，记录来源、内容指纹和团队入口，保护显式更新与副本刷新。团队可只提交技能目录；其他维护者缺少清单时按普通项目文件扫描和手动维护，不推断来源、不静默接管、不覆盖既有内容。不引入第二套目录或新的必装工具。

界面将技能路径与可选管理清单分开。仅管理清单被忽略时不提示技能交付受阻；目录及其子文件被共同忽略时收拢为一条目录提示，单独被忽略的资源仍显示。Git 已跟踪的内容不因后来添加忽略规则而被误报。

团队以项目 Git 为版本来源。维护流程为“编辑项目技能 → 刷新需要的 Agent 副本 → 审查 diff → 提交”；成员消费流程为“clone/pull → Agent 直接读取”。个人库不自动覆盖项目；成员也可通过普通编辑器和 Git 维护技能。

## 影响与验证

- 保留现有清单格式、文件生成行为和安全保护；共享清单仍可让其他 AgentHub 维护者恢复管理关系。
- 桌面共享列表不将清单计入技能交付路径；CLI 保留 `files_to_commit`，新增 `management_files` 标识可选管理信息。
- 回归覆盖不提交清单的真实 Git clone、忽略目录聚合、内部资源忽略、已跟踪文件及新增文件诊断。
