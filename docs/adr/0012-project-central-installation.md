# ADR-0012：项目中央版本与可移植 Agent 入口

- 状态：已接受（2026-10-12）
- 范围：普通项目；替代 ADR-0010 中新专属入口默认复制的规则。

## 决策

参考本地 `skills` CLI 的 `src/installer.ts`：项目中央仓库固定为 `.agents/skills`，保存实际内容；专属 Agent 入口优先使用指向该项目中央内容的相对软链接，无法创建时回退副本。桌面安装可显式选择复制副本，CLI `project add --copy` 同样支持。公共目录目标直接读取中央内容。已有托管副本保留原模式，全局及链接工作空间不变。

安装顺序为“准备或复用项目中央版本 → 一次生成所选 Agent 入口 → 发布管理清单”。已有有效中央目录优先使用项目版本，不以个人库版本覆盖；来源关系未知时不伪造来源。未登记的中央个人链接仅在它指向本次选中来源时转换为项目实际内容，只替换链接本身，不触碰来源。Agent 的 skills 目录链接到本项目 `.agents/skills` 时按公共目录目标复用，保留原目录链接，仅通过无链接祖先的项目中央路径发布实际内容；多个读取者共用启停状态，不能单独移除共享内容。其他链接祖先、其他外部来源、不同内容的专属目录仍拒绝覆盖。

`npx skills` 的项目内同名中央相对链接可识别。状态和修改保护读取经过验证的中央内容，事务则记录链接文本的指纹，重命名和恢复不沿链接操作外部目录。更新、刷新、启停和移除遵循该边界；失败恢复能还原暂存目录中已经断开的链接备份。

项目批量安装每个 Skill 只调用一次 core，将全部缺失 Agent 一次发布。避免同一中央错误按 Agent 重复执行。安装成功不自动提交 Git；中央内容与入口需要一并提交。支持软链接的成员拉取后无需个人库、来源下载或 AgentHub，管理清单仍按 ADR-0011 可选共享。

## 兼容性与限制

- 不写入或改写已有 `skills-lock.json`，不冒充 `skills` CLI 的来源字段或 hash；锁文件完整互操作仍在规划。
- 新管理字段 `linked_targets` 是可选字段，旧复制记录默认空集合；不修改既有来源记录。
- 团队包含不能正确 checkout 软链接的环境时，维护者选择复制副本。不会采用依赖本机绝对路径的 Windows junction 作为共享入口。
- 用户的已有项目仅只读诊断；真实 CLI 安装在临时镜像中验收，不静默批量迁移用户所有技能。

## 验证

覆盖旧个人链接转换、项目版本复用、原生相对链接、来源保护、更新与启停、移除、失败恢复和无清单的 Git clone；保留复制模式回归。任务记录：[P04](../../.scratch/project-skills-library/issues/P04-project-central-install.md)。
