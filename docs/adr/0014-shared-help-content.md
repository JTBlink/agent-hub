# ADR-0014：应用帮助与公开文档共享内容

- 状态：已接受
- 日期：2026-10-12

## 背景

固定帮助卡片与翻译 JSON 难以承载持续增长的操作文档。桌面端需要离线说明，产品网站需要稳定、可分享和可检索的文章；分别维护正文会造成说明分歧。

## 决策

标准 Markdown/GFM 是帮助正文的唯一来源。独立内容目录与导航配置经统一构建流程校验，输出应用离线内容与 VitePress 网站输入。文章使用跨语言稳定 id，文件路径与公开文章身份分开；链接、章节锚点与图片由同一流程解析。

桌面端保留 React 和现有主题，网页使用 VitePress 稳定版默认文档主题。共享正文不嵌入 Vue、HTML 或单端组件，避免两端内容语法分裂。界面翻译与文章翻译分开，缺少正文翻译时明确回退中文。

离线文档随应用版本交付，网站标明构建版本；草稿和适用版本晚于当前应用的文章不发布。网站与产品首页合并为单次 GitHub Pages artifact，保留现有版本 tag 与手动触发。当前不引入文档热更新、CMS 或完整历史版本站点。

## 取舍

共享纯内容要求少量构建与路由适配，但保留原生阅读、离线可用和网站可分享能力。直接嵌入在线网站实现更少，无法可靠保障离线说明与应用主题；两端分别维护文章会增加长期维护成本。

## 验证

在公开构建入口验证身份、导航、文章和章节链接、资源、草稿和重建行为；应用通过实际路由验证阅读、搜索和分享。Pages 构建与工作流合约验证入口分离及统一产物。维护步骤见 [帮助文档维护](../help/README.md)。
