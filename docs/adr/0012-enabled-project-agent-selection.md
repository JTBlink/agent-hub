# ADR-0012：桌面项目添加使用已启用的 Agent

- 状态：已接受（2026-10-12）
- 范围：桌面项目“添加技能”、默认技能组添加目标和“按 Agent 启用/停用”批量操作。
- 替代 ADR-0010 中桌面目标选择不依赖维护者安装和启用状态的约定；核心部署与 CLI 的适配器能力保持不变。

## 决策

用户明确要求从已启用的 Agent 中选择项目团队目标。普通项目桌面添加窗口使用本机已安装且已启用的 Agent，与项目适配器支持范围求交；后端项目目标 DTO 描述支持能力，不能将其中统一的 enabled 标记当成用户启用状态。

默认选择涵盖所有可选的已启用 Agent。历史选择只保留仍可选的目标；没有任何可用历史选择时回到当前默认，不兜底选择未启用的 Claude Code。目标未加载或没有已启用工具时展示空状态，不能凭空生成可部署目标。窗口打开后目标停用会移出当前选择和提交列表。

链接工作空间沿用它对应的单一目标。项目列表的安装检测筛选、已有团队文件与核心部署能力不变，个人启停不自动改变已经提交的团队副本。

## 验证

覆盖个人停用但项目 DTO 标为可用、未安装工具、空目标、默认选择、过期选择剔除和链接工作空间目标。桌面说明同步为从已启用 Agent 中选择，移除“本机未安装也可选择”提示。
