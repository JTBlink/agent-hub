# ADR-0010：项目技能库与团队共享

- 状态：已接受（2026-10-12）
- 范围：普通项目；全局与链接工作空间保持原有语义。
- 团队清单提交要求由 [ADR-0011](0011-optional-project-management.md) 细化：管理清单可选共享，不影响直接使用技能。

## 决策

项目安装供团队共用。实际内容复制到项目 `.agents/skills`，按当前 Agent 适配器规则向专属目录生成复制副本；公共目录目标直接读取。默认不创建指向个人技能库的链接，团队目标选择不依赖本机安装和个人启用状态。

项目内容、团队入口和可移植元数据随 Git 提交。新成员拉取后可由宿主直接读取，不需要 AgentHub、个人数据库或安装来源。应用列出需提交文件，不自动 commit 或 push。

个人库更新不自动覆盖项目。显式更新时检查项目内容和副本的引入基线，保护本地修改；入口修复以项目库为来源，不升级个人或远程版本。元数据损坏或不支持时拒绝写入。多文件发布保留原件和本机 journal，失败可恢复。

沿用 ADR-0009 的全局目录和部署保护；本决策替代已有项目启停规格中“公共目录不是项目技能库”的限定，仅对新托管的普通项目技能生效。旧内容不自动迁移。

## 交付边界

首轮交付包含个人库到项目导入、团队副本、可重建项目记录、入口修复、更新修改保护和桌面/CLI 操作。来源固定修订下载恢复、远程直接导入和自动三方合并按后续阶段交付；当前项目 Git 本身提供确定内容恢复。

项目公共目录对读取它的宿主共同可见，不宣称逐 Agent 隔离。项目启停是团队文件变更；个人 Agent 启用设置不更改团队内容。
