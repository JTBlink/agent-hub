# ADR-0008：统一主应用与本地数据目录

- 状态：已接受
- 日期：2026-10-04
- 替代：ADR-0007 的独立窗口方案，以及 ADR-0002～0005 中旧配置宿主专属实现约束；ADR-0006 的增量拆分与复用规范继续适用。

## 背景

用户决定直接以 Skills Manager 二次开发，放弃旧 AgentHub 宿主架构，优先跑通应用，再逐步改造；对外名称、Logo、主题色调保留 agent-hub。

## 决策

前端和 Rust 源码提升到根目录 `src/`、`src-tauri/`，只维护一套依赖、版本、构建入口。移除旧配置管理宿主与独立 Skills 启动桥。CLI 作为主应用的配套可执行文件，名称为 `agent-hub-cli`。

数据、配置、日志和 CLI 默认归于 `~/.agent-hub`，与旧版和原管理器隔离，不自动迁移已有数据。用户主动移动技能库时，固定配置、日志及 CLI 仍位于此应用目录。

保留原图标资源，用集中主题变量复用深蓝、蓝、青、紫色调。删除失效的产品和实现文档，保留导入来源清单、MIT 许可证与必要决策历史。

## 影响

旧配置编辑与历史界面不再可用，已有数据库和磁盘技能文件不删除。原主应用可通过 Git 历史恢复。原计划中的库化、配置适配和迁移任务需要重新评估，不作为本轮前置要求。

继承的大模块保留现有行为，后续随功能修改拆分。发布仍需各平台原生验收；本地 macOS 验证不能替代跨平台签名和安装检查。

## 备选

继续双窗口集成会长期维护两套生命周期和数据模型；将旧宿主逐项迁移至新核心会扩大首轮范围。按用户要求采用单应用替换。
