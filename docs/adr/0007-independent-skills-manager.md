# ADR-0007：由独立 Skills 模块统一管理技能

- 状态：已接受
- 日期：2026-10-04

## 决策

AgentHub 的 Skills 入口打开仓库内 `modules/skills/` 的独立管理窗口。技能库、安装、更新、卸载、Preset、多 Agent 部署和备份由该模块负责。主应用保留配置、工作空间和配置诊断，不再运行原 Skills 扫描器、安装器、深链接安装或旧目录迁移命令。

模块暂时以独立进程接入，保持自身依赖、数据目录、锁和生命周期。主应用仅能启动与自身可执行文件同目录的固定管理器文件，不接受来自前端的程序路径或参数。模块已有单实例逻辑负责聚焦已打开窗口。

开发和打包均由 `scripts/tauri-with-skills.mjs` 先构建模块前端及管理器/CLI 两个二进制，再通过 Tauri 的 externalBin 配置纳入主应用。管理器嵌入静态前端资源，不依赖第二个开发服务器。macOS Universal 构建分别编译两个架构后合并。

内置副本通过独立的构建覆盖配置撤销上游应用更新器的下载、安装权限，避免其替换 AgentHub 安装包；模块版本由宿主发布更新。技能内容更新仍由模块管理，模块本身也清空上游更新地址与签名公钥，设置页统一提供宿主发布页入口。

## 兼容性与既有决策

ADR-0002、ADR-0004 中关于主应用 Skills 安装实例和 InstallPlan 的实现边界由本决策替代；配置的作用域、预览、确认和恢复规则继续适用。原 Skills 表、来源缓存及磁盘上的技能不删除，保留未来迁移依据。移除旧入口不等于已将这些数据迁入新模块。

ADR-0005 的三个内置 Agent 身份继续用于配置模块；独立 Skills 模块沿用自身 Agent 适配器。支持某个 Agent 的技能管理不自动意味着主应用支持它的配置编辑。

原 `agenthub://install` 入口退役，不再将安装请求交给旧执行器。技能安装使用新模块自己的入口。

## 后续

将模块改为 Rust core 库和可嵌入 React 组件仍是后续工作；当前不同时维护两套技能写入服务，不自动迁移数据库，也不将前端界面假接到旧后端。
