# ADR-0009：共享技能目录与独立应用状态

- 状态：已接受
- 日期：2026-10-08
- 替代 ADR-0008 中技能内容默认存放于应用目录的约定。

## 决策

默认技能内容存放于 `~/.agents/skills`，数据库、配置、日志保留在 `~/.agent-hub`。复用适配器的共享路径解析器。已有自定义库及 CLI 显式根目录保持兼容；设置分别展示实际技能目录和应用数据目录。

旧默认库在排他租约下预检、无覆盖复制到共享目录，完成后用持久标记切换路径，重写数据库路径和部署链接。旧内容保留作为回退副本。冲突、独立 Git 历史和独立元数据阻止自动迁移；中断日志支持重试。

共享内容原地登记。部署源与目标相同时视为直接使用，禁止以取消部署的方式删除源目录。直接读取共享目录的 Agent 可以看到其中全部 Skills；数据库开关不构成跨 Agent 的通用禁用协议。

Git 工作目录与实际技能根一致，可恢复元数据仍存放于库内 `.agent-hub/`；应用运行状态排除在备份之外。从远端克隆先完成下载再替换，完整旧目录及 Git 历史保留在应用恢复目录；本地独有顶层条目带入新库，冲突以远端为准，原件仍可找回。历史版本恢复继续使用安全快照。

## 影响与边界

共享目录中其他安装器的写入不受 AgentHub 锁控制，因此迁移复制使用无覆盖写入，恢复检测替换期间的目录重建。应用不静默删除恢复副本。软链接备份保存链接本身，外部目标内容需单独备份。

本次不新增全局 Skill 禁用协议，不自动改变已有自定义库，也不改写远端旧历史。恢复、迁移、同路径部署和状态排除通过临时目录及本地 Git 远端验证。
