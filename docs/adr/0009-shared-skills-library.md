# ADR-0009：技能目录与跨工具发现

- 状态：已接受（2026-10-08 修订）
- 日期：2026-10-08
- 替代 ADR-0008 中技能内容默认存放于应用目录的约定。

## 决策

默认技能内容存放于 `~/.agent-hub/skills`（应用数据目录下），数据库、配置、日志同样位于 `~/.agent-hub`。已有自定义库及 CLI 显式根目录保持兼容；设置分别展示实际技能目录和应用数据目录。

`~/.agents/skills` 作为可选软链接指向 `~/.agent-hub/skills`，方便其他 AI 工具发现技能。用户可在设置中开启或关闭此链接；关闭时只删除软链接，不影响技能内容。不再需要共享目录迁移流程。

技能库内容原地登记。部署源与目标相同时视为直接使用，禁止以取消部署的方式删除源目录。直接读取技能目录的 Agent 可以看到其中全部 Skills；数据库开关不构成跨 Agent 的通用禁用协议。

Git 工作目录独立位于应用数据目录下 `backup/`，默认 `~/.agent-hub/backup`。活跃 Skills 在技能库目录；仓库采用 `skills/<原相对路径>/SKILL.md` 与根 `.agent-hub/` 可恢复元数据，并生成 README 安装命令，兼容 `npx skills@latest add <repository-url>`。导出软链接 Skill 的实际内容，避免其他机器安装失效链接。

同步/恢复通过独立工作区投影和发布流程应用到技能库，数据库路径始终指向活跃库。克隆先下载再替换，保留原仓库；本地独有 Skill 带入。发布前检测外部编辑，保存被替换原件和可重试日志。

凭据按用户要求使用应用数据目录下 `credentials/` 本地文件与内存缓存。Unix 权限为目录 0700、文件 0600；这是文件权限保护而非加密，Windows 依赖用户目录 ACL。首次从旧钥匙串成功迁移后无需再次读取；退出写入空记录避免旧凭据复活。凭据、数据库、缓存、日志、恢复数据排除在 Git 备份之外。

## 影响与边界

本次不新增全局 Skill 禁用协议，不自动改变已有自定义库，也不改写远端旧历史。恢复、同路径部署和状态排除通过临时目录及本地 Git 远端验证。远端含软链接的恢复拒绝应用，避免写入外部目标。应用不静默删除恢复副本。
