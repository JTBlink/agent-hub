# ADR-0017：任务说明入口与配置目录

- 状态：已接受
- 日期：2026-11-04
- 细化：[ADR-0016](0016-independent-automation-packages.md)

## 背景

独立定时任务需要像 Skill 一样有清晰的说明入口、可直接执行的脚本和按需读取的资料。原来根目录混放清单、Agent 配置和 README，说明与执行入口不够清晰。

## 决策

新任务以 `TASK.md` 为说明入口，`config/` 集中保存 JSON，`scripts/` 保存独立执行的代码，`references/` 仅在有实际需要时添加。Agent 任务的简短目标仍保存于`prompts/prompt.md`；私有状态、运行记录与依赖环境继续隔离于 `.local/`。

`config/task.json` 是版本、日程、依赖、执行命令与文件清单的唯一机器来源，不在 TASK.md 重复保存配置。文件清单相对任务根目录；它可以声明配置、脚本和资料，但不能覆盖清单本身或市场目录元数据。`config/catalog.json` 仅用于分发侧推荐展示。

分发源码、新建本机包和新写入的云端备份使用相同布局。旧根目录 `task.json`、`README.md`、`herdr.json` 及脚本旁配置保持可读；已有根清单继续在原位置更新，不因列表查询或普通编辑自动迁移。两份清单同时存在时拒绝读取，不以优先级掩盖身份冲突。JSON 单文件交换及清单格式版本保持兼容。

脚本通过本任务目录定位配置和相邻模块，不依赖开发仓库、桌面进程或历史会话。需要模型时可以直接调用运行环境中已安装的 Skill，无需复制另一套规范。系统调度器与外部工具仍作为运行依赖，不将依赖桌面窗口存活的轮询器作为调度方式。

## 验证

验证新旧目录、直接选择 config/task.json、独立脚本运行、配置与资料的相对路径、双清单冲突、目录链接边界、备份恢复、更新回滚和预览说明入口。已有任务的 ID、项目绑定、日程与启停状态不因布局变化改变。
