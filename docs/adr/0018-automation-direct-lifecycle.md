# ADR-0018：自动化任务直接创建与启停

- 状态：已接受
- 日期：2026-11-04
- 执行记录：[移除独立安装与卸载](https://github.com/JTBlink/agent-hub/issues/281)
- 替代：[ADR-0016](0016-independent-automation-packages.md) 中的用户安装／卸载生命周期；独立任务包、锁、依赖归属、备份隔离和删除保护保持有效。

## 背景

用户只需要创建任务、暂停／恢复计划、手动运行和删除。独立安装状态增加了重复操作，导入或恢复后还需要安装才能使用，也让暂停和卸载的区别难以理解。

## 决策

移除 GUI 安装／卸载按钮与安装状态，移除对应 IPC、CLI 子命令和导入的安装开关。创建、导入与显式恢复共用 core，自动检查依赖、准备私有环境并注册调度；导入和恢复默认暂停，准备过程不执行任务正文。市场使用“添加任务”，已有任务日常只管理启停、运行、编辑、导出和删除。

内部保留准备、更新恢复和删除清理阶段，保证进程中断和重复请求安全；它们不构成第二套用户状态。失败保留回执和错误，可通过保存或运行重试。删除清理任务拥有的调度、依赖和权限资源，默认保留任务文件，显式选择才清理本地数据。

兼容旧回执的安装阶段字段；原未安装任务读取为暂停，不在列表查询时注册或搬迁，首次保存或运行自动准备。已注册任务原有启停状态保持。目录迁移自动完成撤销旧调度、移动、重建环境与恢复启停，不要求用户先卸载。

## 验证

覆盖创建、导入和恢复后可用且不执行正文，暂停任务手动运行和恢复计划，旧回执兼容与重试，失败恢复、运行互斥及删除对项目和共享资源的保护。CLI 帮助不再暴露安装／卸载和导入安装开关。
