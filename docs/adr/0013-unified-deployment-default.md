# ADR-0013：统一新入口的默认部署方式

- 状态：已接受（2026-10-12）
- 范围：全局部署、链接工作空间及普通项目；补充 ADR-0012。

## 决策

设置只展示“默认部署方式”，持久化于 `deployment_mode`，值为 `symlink` 或 `copy`，未配置时新用户默认链接。全局与链接工作空间链接个人技能库，普通项目的专属入口链接项目 `.agents/skills`，中央内容始终保存实际文件，公共目标直接读取中央内容。单次安装参数优先于默认值，省略参数读取偏好。

新增值不通过数据库 migration 自动写入。未主动选择统一值时，保留原有 `sync_mode` 与 `project_sync_mode` 解析：普通项目默认链接；链接工作空间优先自己的旧值，缺失时跟随全局。设置界面在旧范围不一致时不选中任何统一方式，并解释选择后新安装采用同一默认值；加载不写入设置，保存失败保留当前选择。

统一默认值只影响新入口。全局同步计划及内容更新保留已有记录的部署方式；链接工作空间更新保留入口的实际方式；普通项目已有入口保持项目记录，新增 Agent 独立采用当前默认值。旧设置下的既有全局同步语义继续兼容，不因升级静默改变部署。

项目状态额外提供 `target_issues`，只检查实际存在的入口，区分链接被目录副本替换、链接目标异常和内容差异，携带 Agent 名称和项目相对路径。不存在的入口视为未添加，即使历史清单仍有记录，也不报告缺失。异常链接的状态诊断不读取外部内容。修复使用当前项目版本，只更新实际存在的入口，不自动添加其他 Agent；独立修改及外部链接沿用拒绝覆盖保护。界面使用“恢复 Agent 技能”，说明原因、使用的版本与修改保护；新增入口通过显式添加完成。状态修订见 [B04](../../.scratch/project-skills-library/issues/B04-clear-agent-skill-status.md)。
