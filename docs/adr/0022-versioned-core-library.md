# ADR-0022：共享 Rust 核心库独立版本

- 状态：已接受
- 日期：2026-11-25

## 背景

AgentHub 的桌面端和 CLI 已共享 Rust 后端。独立产品也需要复用通用能力，并能按版本升级、在本地与上游一起调试。

## 决策

- 在同一仓库维护 `agent-hub-core`。库通过独立的 Cargo 版本交付，桌面应用沿用根目录 `VERSION`。同仓库使用路径依赖，独立产品在库发布后使用 Registry 版本和自己的锁文件。
- 通用后端能力按实际调用逐步迁入。Agent 启动、执行和本地领域规则提供共享接口。GitHub、GitLab、Herdr 和云端备份可分别由产品构建配置选择。Skill、自动化任务和用户配置的云端备份、同步与恢复共用 `cloud-sync`。
- Tauri 窗口、IPC 注册、React 界面和安装包组装由宿主管理。组织专属策略和资源由产品维护。公共核心只提供可在标准版和独立产品间复用的机制。
- 优先发布通过实际调用验证的接口。迁移必须保留现有数据和任务的兼容行为。独立产品的本地联调可指向相同版本的上游 checkout。

## 实施顺序

1. 用启动方案解析验证现有桌面和 CLI 调用、独立 Cargo 打包及下游依赖。
2. 以启动、投递、查询和续作的完整链路验证共享 Agent 执行，沿用 ADR-0020 的身份和恢复规则。
3. 按下游使用顺序迁入项目和本地 Skill 等领域接口、独立的平台集成及统一云端备份。迁入可选能力时验证启用和关闭两条路径。

当前实现见[应用组装边界](../architecture/app-composition.md#共享-rust-核心库)，构建与本地联调见[产品开发指南](../product-development.md#复用和升级-rust-核心库)。
