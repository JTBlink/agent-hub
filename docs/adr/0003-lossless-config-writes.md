# ADR-0003：配置文件采用格式感知最小 Patch 与受保护原子写入

- 状态：已接受
- 日期：2026-08-22

AgentHub 不建立会重排用户文件的统一配置序列化层。JSON/JSONC 使用语法范围 patch，TOML 使用保留 trivia 的编辑文档，YAML/Markdown 第一版以原始文本 patch 为主；所有写入都经过 checksum 乐观锁、受限权限备份、同目录临时文件和平台原子替换。这一选择优先保护未知字段、注释、格式和外部修改，代价是各格式 adapter 需要独立测试，部分字段只能使用原始文本编辑。

## 被否决方案

- **解析成统一对象后完整序列化**：会丢失 JSONC/TOML/YAML 注释、顺序和原始表示，并可能改写 AgentHub 不理解的新字段。
- **直接覆盖或只依赖修改时间**：无法可靠发现并发修改，失败时也缺少可恢复边界。
- **在原文件旁创建 `.bak`**：容易污染用户仓库并被误提交，权限也可能比原配置宽；备份统一存放在用户专属 `~/.agenthub/backups`。
- **把备份正文放入 SQLite**：扩大数据库泄露和损坏影响；SQLite 仅保存受限文件的路径、checksum 和操作元数据。
- **默认跟随并替换符号链接路径**：原子 rename 会破坏链接本身；第一版要求显式选择并写入解析目标。
