# ADR-0015：使用 GitHub Issues 与 Milestones 管理任务

- 状态：已接受
- 日期：2026-10-27

## 决策

规格、独立任务、依赖、讨论和交付状态使用 GitHub Issues；发布版本使用 Milestones。工程技能从 `docs/agents/` 读取统一规则，项目 Skill 的参考入口仅链接该规则。

现有任务迁移为功能总览与子 Issue。完成的任务归档关闭；原有待确认状态和未提交实现保留开放。清理本地任务记录、CI 索引校验及提交约定中的旧路径。

重写现有分支、版本标签和本地恢复 refs，移除旧任务文件及提交说明中的路径，保存仓库外恢复备份。历史源码除任务文件外保持原内容。已有安装包、摘要、签名与 Actions 原始构建记录不重发；后续候选验证使用重写后的实际 SHA，不复用旧 SHA 的构建证据。

## 自动同步

新 Issue 默认归入 `Unreleased`，显式目标版本关联对应里程碑；关闭、重开时同步分诊标签。发布时只把有关闭提交归属证据的任务自动归档到该版本，未完成任务留在 `Unreleased`。
