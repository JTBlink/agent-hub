# GitHub / GitLab 任务与终端 PRD

版本：v0.3。状态：需求与交互原型，已转为开发规格与子任务。更新时间：2026-10-31。

开发规格与后续子任务统一跟踪于 [GitHub Issue #230](https://github.com/JTBlink/agent-hub/issues/230)。

## 目标

在 AgentHub 浏览 GitHub / GitLab 任务，打开对应项目终端继续处理。终端支持普通 Shell、CLI Agent 和 Herdr TUI，尽量将空间留给终端内容。

坚持简单：Herdr 已有的能力直接使用和展示，没有原生数据或明确价值的能力不再补一套。AgentHub 不从终端输出拼接执行历史，不推测 Agent 生命周期，不建立自己的 Herdr 执行中心。

## 已确认的设计

- 任务支持 GitHub / GitLab，参考 Orca 的来源切换、项目筛选和紧凑表格。
- 一级模块命名为“终端”。Herdr TUI 是在终端内运行的程序，不单设页面或预置专用标签。
- 技术采用 Tauri 2 + React + xterm.js + Rust portable-pty，不更换 GUI 框架，不自行绘制终端。
- 终端界面简洁：一行会话标签与少量工具按钮，内容区尽可能铺满；提供终端最大化／还原。
- 保留一个 Herdr 快捷按钮，作用于当前窗格；没有安装时自动安装，安装后启动。
- 版本检查和更新提示不打断使用，不抢焦点、不弹阻断窗口、不重启现有会话。
- 支持左右与上下分屏。每个窗格独立运行，Herdr 自身的内部分屏由它自己管理。
- 不做独立执行记录、运行历史数据库、推测状态、额外编排或自动重跑。

## 页面与职责

| 入口       | 内容                                                             |
| ---------- | ---------------------------------------------------------------- |
| 任务       | GitHub / GitLab Issue、PR / MR 列表、筛选、详情与任务上下文      |
| 终端       | 项目 Shell、标签、分屏、输入输出、Herdr 快捷启动                 |
| Herdr TUI  | 在当前终端窗格中运行，其工作空间、Agent、状态及交互由 Herdr 展示 |
| 现有自动化 | 保留已有功能，本需求不新增调度或执行中心                         |

“终端会话”是当前应用管理的 PTY；“Herdr 会话”由 Herdr 自己管理。二者不混为一个对象，关闭 TUI 客户端不等于停止 Herdr daemon 或其 Agent。

## 任务面板

### 默认布局

采用 **A 为主、B 的按需预览为辅**：紧凑表格用于跨项目扫描，点击任务进入完整详情；预览图标或空格打开右侧预览，保留列表与筛选。预览中可进入完整详情。窄窗口优先完整详情。

不提供三个产品布局开关，不把本机执行看板放进任务页。此前 C 为探索稿，本版不保留该产品范围。

### 首期功能

| 编号 | 功能         | 验收条件                                                                                               |
| ---- | ------------ | ------------------------------------------------------------------------------------------------------ |
| F01  | 平台连接     | 使用所选平台 CLI 的现有认证；明确主机和当前身份；未连接、无权限、限流及读取失败不显示成空列表          |
| F02  | 项目绑定     | 从已登记项目明确绑定远端仓库；多 remote 不静默猜测；同编号的不同项目任务不混淆                         |
| F03  | 任务列表     | 支持 GitHub Issues / PR、GitLab Issues / MR；显示编号、标题、项目、负责人、远端状态、更新时间          |
| F04  | 筛选与分页   | 支持项目、关键词、状态和平台支持的个人筛选；可继续加载；切换范围后过期响应不能覆盖当前列表             |
| F05  | 预览与详情   | 查看正文、讨论及平台元数据；关闭或返回时保留列表上下文；不展示无来源的本机执行状态                     |
| F06  | 在终端中处理 | 准备任务链接、标题和上下文，允许查看与复制，打开对应项目终端；不自动粘贴到未知前台程序，不创建执行记录 |

首期建议只读平台任务；评论编辑、评审、CI 操作、合并和 GitHub Projects / GitLab Todos 后续有明确需求再接入。不因为平台或 Herdr 理论上可支持某能力，就在本次额外增加界面和业务逻辑。

## 终端

### 布局

终端页不放大标题、概览卡片或独立执行列表。顶部只保留普通会话标签、“新建”“Herdr”“分屏”和“终端最大化／还原”；有当前任务上下文时提供一个轻量入口。底部使用已有状态行承载必要的路径或更新提示，不增加占高度的横幅。

每个普通标签表示一个项目终端，可以包含多个窗格。启动 Herdr 后仍是原标签和原窗格，只更新当前程序名称；不自动新建 Herdr 专用标签。原型演示左右或上下双窗格，正式实现按实际范围决定递归分屏和最小窗格尺寸。

最大化使用向外四角图标，还原使用向内四角图标；按钮提示随状态切换为“最大化终端 / 还原终端”，保留键盘焦点。该操作调整应用内的终端可用空间，不改变系统窗口全屏状态。

### 功能需求

| 编号 | 功能         | 验收条件                                                                                                           |
| ---- | ------------ | ------------------------------------------------------------------------------------------------------------------ |
| F07  | 普通终端     | 新建项目 Shell；正常输入、中文输入法、复制粘贴、颜色和光标；未安装 Herdr 也能使用                                  |
| F08  | 标签与分屏   | 标签和窗格保留独立内容；左右、上下分屏；当前窗格有清楚焦点；每个窗格独立调整 PTY 尺寸                              |
| F09  | 同窗格 Herdr | 点击快捷按钮在当前空闲 Shell 中启动或 attach Herdr TUI；不另开页面或专用标签，不覆盖运行中的其他程序               |
| F10  | 自动安装     | 用户点击 Herdr 时发现缺失，自动准备依赖后启动；过程有轻量反馈、失败可重试；不会在打开 AgentHub 时无条件安装        |
| F11  | 安装不打断   | 安装期间可以继续使用 Shell；完成时若原窗格已切换、忙碌或正在输入，只提示就绪，不强行投递命令或抢焦点               |
| F12  | 更新不打断   | 已安装时直接启动，后台查更新；有更新只给轻量提示，用户主动更新；失败保留旧版本，现有 TUI、daemon 和 Agent 不被重启 |
| F13  | 真实生命周期 | 只展示实际 PTY 运行、退出或错误；Herdr 的工作状态由 TUI 展示；不把客户端退出当成内部 Agent 已完成                  |

Herdr 快捷按钮是工具启动器，不代表 AgentHub 自己创建了新的“运行”。在 TUI 内手动操作不生成 AgentHub 历史记录。任务上下文仅用于方便继续工作，不包含自动分派、自动提交、审批代答或自动合并授权。

应用切到其他页面时保留已创建终端；整个应用退出后的普通 PTY 保活不属于首期。退出应用时按真实活跃进程处理，不把隐藏到托盘当退出；Herdr daemon 的持久化由 Herdr 负责。

## 异常与边界

- 终端忙碌时，快捷启动不能将 `herdr` 文本写入正在运行的 Agent、编辑器或尚未提交的输入；提供就绪提示或让用户另开窗格。
- 安装或更新下载失败不覆盖当前终端内容，不弹出阻断使用的窗口；可以重试。
- 平台读取失败保留成功来源，不把未知状态推断为完成。
- 首期不承诺 WebView 崩溃后的裸 PTY 画面恢复、普通终端后台服务化、远程主机或 WSL。
- 普通终端输出和输入默认不落盘，不进入技能 Git 备份；任务平台和终端只对本机可信界面开放。

## 可点击原型

文件：[任务与终端原型](../prototypes/tasks-terminal.html)。单个 HTML，可直接用浏览器打开。数据保存在页面内存中，刷新重置；所有命令、安装、更新和 TUI 画面都是模拟，不访问本机账号、真实终端或平台数据。

从项目根目录运行：

```sh
python3 -m http.server 4176 --bind 127.0.0.1 --directory docs/prototypes
```

打开 `http://127.0.0.1:4176/tasks-terminal.html`；`?view=terminal` 直达终端，`?provider=gitlab` 选择 GitLab。顶部“交互原型 · 演示状态”仅用于切换已安装、未安装、有更新等模拟条件，不属于产品功能。

演示路径：

1. 平台与项目筛选 → 快速预览 → 完整详情 → 准备任务上下文 → 打开项目终端。
2. 普通终端 → 点击 Herdr → 在同一窗格进入 TUI → 返回 Shell。
3. 左右或上下分屏 → 切换当前窗格 → 只在选中窗格启动 Herdr。
4. 未安装 → 自动安装中继续输入 → 安装完成不覆盖草稿。
5. 有更新 → 轻量提示 → 主动更新 → 当前终端 DOM、输入与 TUI 保持不变。

没有独立执行记录、AgentHub 推测的 Agent 状态、专用 Herdr 标签或运行看板。终端只承载 Herdr 已有交互，不额外重建它的功能。
