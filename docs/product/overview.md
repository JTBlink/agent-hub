# 产品概述

agent-hub 是管理 AI Agent Skills 的桌面工作台。当前提供技能库、来源发现、标签、技能组、全局和项目工作空间、多工具部署、Git 备份及 CLI。

本轮以 Skills Manager 实现为主应用，沿用 agent-hub 品牌和主题。旧版配置中心、配置编辑与历史记录功能已退役；后续是否恢复相关能力需另行设计，不能将旧文档视为当前功能承诺。

当前优先级是应用正常运行、目录与标识隔离、构建可复现，再按真实使用反馈迭代。需求以仓库 `.scratch/` 为准，GitHub 用于持续集成和安装包发布。

技能组（内部代码层称为 SkillGroup，数据库层保留 `scenario`，CLI 命令为 `skill-groups`，英文界面称为 Skill Group）是按用途命名的 Skill 集合，例如”日常开发”。侧边栏用于查看和编辑组内成员，工作空间中的技能组按钮用于批量添加或移除技能；成员变更不会自动更新已有部署。

仪表盘的”本地 Skills 管理”和”安装 Skills → 本地”进入同一个管理入口。扫描结果可按名称、路径或 Agent 搜索，每个实际安装位置均支持查看内容、打开目录和确认删除；适用 Agent 直接显示在目录下方，保留单个与批量导入。技能库 `~/.agent-hub/skills` 中存在的 Skill 优先作为主位置展示。此处管理扫描发现的本地副本，已由技能库部署的条目继续在对应 Agent 工作区中管理。

GitHub 备份默认使用独立注册的 agent-hub OAuth App 进行设备授权登录，也可使用个人访问令牌。应用内展示设备码并打开 GitHub 验证页面；授权凭证保存在系统钥匙串中。设备授权不依赖回调地址，也不需要在桌面应用中配置 Client Secret。

Agent 可用性由独立的 Agent 状态或显式自定义路径配置判断，仅有 `skills` 目录不算检测到 Agent。首页显示已检测且启用的 Agent 数量；本地扫描的来源目录数量与此不同。扫描仍覆盖仅含 Skills 的目录，共享路径的删除会影响所有读取该路径的 Agent。

本地管理的操作与性能验证见[本地 Skills 管理](local-skills-management.md)。
