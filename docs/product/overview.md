# 产品概述

AgentHub 是本地优先的 AI 开发工作台，围绕项目与 Git 工作树连接终端、Agent、Git、平台任务、Skills 和自动化。桌面宿主与配套 CLI 共用 Rust 核心；当前可通过产品配置和 Cargo features 组装标准版、个人版与 Agent Flow 定制版，功能以实际构建为准。

## 项目与 Agent

项目侧栏发现已有 Git 工作树，提供文件浏览、文本与 Markdown 编辑以及内嵌终端。终端支持多标签和分屏，可直接在当前工作树启动已安装的 Codex、Claude Code、OpenCode 或 Hermes。独立 Herdr 入口用于连接和管理会话，按目录与身份核对归属。

切换项目或工作树时，应用关闭旧工作区的自有终端并释放 PTY；再次进入时新建 Shell，不重放旧命令。暂时进入其他功能页则保留当前工作区。关闭 Herdr 客户端不等于停止其后台会话。

## Git 与平台任务

Git 工作区提供更改、差异、提交图、分支与标签操作。文件树和 Git 版本比较支持独立图片查看、左右／上下排列、缩放与大图；沿用项目授权及 20 MiB 单图读取限制。写入按工作树归属和 Git 状态校验，沿用确认、错误与恢复流程。

平台任务连接 GitHub / GitLab，支持登录账号、私有站点、多项目筛选、Issue 与 PR / MR 以及 CI 状态查询。评审、修复和 CI 排查进入 Agent 启动预览，不把选择任务视作直接合入、发布或任意外部写入授权。平台任务的 CLI 认证与技能备份的 OAuth / Token 认证分别管理。

## 技能库与工作空间

技能库管理内容、来源、版本、标签及部署关系。技能组是按用途命名的 Skill 集合；中文界面使用“技能组”，英文使用 Skill Group，CLI 顶层为 `skill-groups`，数据库兼容保留 `scenario`。

导入技能库、修改组成员与部署到 Agent / 项目分别执行。修改组内成员不自动更新已有部署。普通项目的 `.agents/skills` 保存团队实际内容，适用的 Agent 专属入口使用相对链接或副本；项目成员读取团队技能不依赖个人技能库或应用数据库。

导入后可删除本地原目录，技能库副本独立保留。仓库技能卡片按版本关系区分安装、上传及详情，覆盖或写回继续沿用原有确认与路径保护。

Agent 可用性根据真实安装或显式自定义路径判断，只有技能目录不算已安装 Agent。本地扫描和管理说明见[本地 Skills 管理](local-skills-management.md)。

## 定时任务与预览

自动化管理当前用户的系统任务和 Hermes 任务，支持从模板创建、完整复制、导入导出、编辑脚本和日程、切换提示词方案及查看执行记录。市场模板只读，本地实例独立维护；导入、复制和备份恢复默认暂停并准备依赖，没有独立安装/卸载步骤。

系统任务由操作系统原生调度器运行，Hermes 任务沿其原生调度。Agent 生命周期和状态存储由共享模块维护，任务脚本负责业务选择、去重、回调与限制；单轮数量和修复上限需要任务实现，不能作为所有模板的统一承诺。启动、进程退出和业务验证分别判定，结果不明时保留恢复材料。

浏览与预览提供项目网页、移动端视口及文档入口；连接、运行环境和远端能力按桌面设置与实际可用环境提供。

## 本地数据与备份

技能默认在 `~/.agent-hub/skills`，应用数据库在 `~/.agent-hub/agent-hub.db`，独立任务包默认在 `~/.agent-hub/automations/<task-name>/`。任务的本机绑定、运行环境和记录保存在 `.local/`。

Git 备份保存可移植技能、任务定义和受支持的用户配置，凭据、数据库、执行日志和扩展业务状态不进入备份。系统钥匙串保管适用凭据，目录和排除规则以[目录与本地数据](../architecture/directory-structure.md)和[定时任务记录规范](../architecture/automation-records.md)为准。

## 产品边界

当前使用单一 React + Tauri 主入口。旧配置中心与独立 Skills 子窗口已退役。AI Native 场景编排为独立需求原型，未接入生产功能，不能将规划或原型视作现有功能承诺。需求和进度以 GitHub Issues / Milestones 为准，安装包能力以对应 Release 说明为准。
