# Git 文件夹右键菜单

在源代码管理的树形视图中，右键文件夹、按 Shift+F10，或打开行尾「···」。菜单标题显示目录、所属分组和受影响文件数。左键仍用于展开和收起。

| 动作              | 未暂存更改                                                             | 已暂存更改               |
| ----------------- | ---------------------------------------------------------------------- | ------------------------ |
| 暂存或取消暂存    | 暂存该目录下本组文件                                                   | 取消暂存该目录下本组文件 |
| 放弃更改          | 确认窗口按路径列出文件，单独标出将被删除的未跟踪文件。保留已暂存的版本 | 无                       |
| 加入 `.gitignore` | 目录在仓库中没有已跟踪或已暂存的文件时提供。确认时展示将写入的规则     | 无                       |
| 查看文件夹更改    | 在现有差异区打开本组变更列表                                           | 查看本组暂存差异         |
| 查看文件夹历史    | 在现有 Git 历史页按目录筛选当前分支                                    | 同左                     |
| 复制更改（补丁）  | 复制本组可生成的完整补丁。混有无法生成补丁的文件时禁用                 | 复制本组的暂存补丁       |

菜单与行内快捷按钮共用暂存、取消暂存及放弃动作。目录只是范围，正式实现应依据当前仓库、工作树、分组和完整的后代变更列表生成精确文件清单。禁止用目录通配执行批量操作。变更列表截断或目录有冲突时，为禁用的批量选项显示原因。确认期间如果范围或文件状态改变，刷新后重新确认。

从菜单按 Esc 回到触发行，方向键移动焦点。成功后刷新原分组，并尽量保持目录展开状态。目录已经消失时将焦点移回所属分组。

`./prototype.sh git-folder-menu` 可进入交互演示。页面里的差异、历史和忽略规则使用演示数据。
