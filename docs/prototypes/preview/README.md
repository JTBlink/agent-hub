# 预览与浏览交互原型

运行 `./prototype.sh preview`，打开 <http://127.0.0.1:4176/docs/prototypes/preview/>。

只保留一个实现对照方案：浏览区加右侧「检查与批注」面板。旧 `variant` 查询参数不再改变布局，也不再提供方向键或菜单切换方案。

与正式组件对齐的交互：

- 标题、抓取元素、添加批注、截图绘制、更多和关闭合并到一行；窄面板以图标展示操作并保留提示。
- 移除整条底部工具栏。批注数量在右侧显示，复制路径、导出文档及复制／导出批注收进面板的更多菜单。
- 底部输入修改要求，展开「查看完整发送内容」查看文件路径、元素、DOM/CSS、意见及截图信息。
- 文件发送使用路径，Tab 以文件名命名，按完整路径区分；首次创建专属 Agent Tab，后续向同一 Tab 追加消息，复用上下文。

验收：打开检查与批注，添加批注并填写修改要求，展开完整内容，连续发送两次，查看同名演示 Tab 中保留两条消息；切换文件后发送，验证上下文隔离。切换明暗主题、调整窗口尺寸，验证单行工具栏和发送内容可访问。

原型使用合成数据，不启动真实 Agent、不读取数据库或系统文件。文件选择器无法取得真实磁盘绝对路径，使用 `/workspace/...` 演示路径；截图仍是演示。正式模块使用已授权文档的真实路径、真实截图和已有 Agent 交付端口。原型回执不能作为真实 Agent 运行证据。

正式实现入口：`src/features/preview/PreviewWorkspace.tsx`、`components/AnnotationPanel.tsx`、`components/AgentDelivery.tsx` 与 `src/components/terminal/previewAgentRuntime.ts`。主题和基础控件复用正式资源，生产代码不依赖原型。
