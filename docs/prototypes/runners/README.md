# 任务与 Runner 页面原型

本次设计基于当前 `TaskToolbar`、`TaskListTable`、`TaskDetails` 和项目多选交互。原型中的账号、项目、任务和 Runner 全部为演示数据。正式任务工作台已接入两平台的只读 Runner 查询，沿用任务的仓库绑定和 CLI 登录。GitLab 的标签和最后联系等附加字段在详情打开后按需查询，具体可见字段取决于平台版本和账号权限。

任务和 PR/MR 的页头首行包含标题、已选项目、平台筛选、账号摘要和操作入口。状态筛选与搜索位于下一行。原型通过 `TaskToolbar` 的可选前置内容组合页头。正式接入侧栏时应复用现有筛选状态。

## 保留的任务能力

任务和 PR/MR 页面直接引用 `TaskToolbar`、`TaskListTable`、`TaskAttributeFilters`（由工具栏使用）、`TaskDetails`、`TaskRowActions`（由列表使用）及 `TaskConnections`。保留平台筛选、搜索限定词、状态 / 作者 / 标签 / 负责人筛选、账号和仓库连接入口、仓库跳转、开始、快速预览和更多操作菜单。页面切换时保留挂载的任务视图，避免切到 Runner 后丢失任务搜索条件。

原型只演示布局和交互入口。远端写入、账号切换、Agent 启动和系统操作均未接真实服务；这些能力在正式应用中的实现不受本次原型修改影响，不能把原型入口演示当作真实业务验收。

## Runner 状态与验证

共享 Runner 可以在多个所选项目中可用，但仅显示一行，并在「可用项目」列中列出关联。GitHub 只展示自托管 Runner，托管 Runner 不提供在线机器清单。未知不归为离线，查询失败、无权限和空列表分别展示。正式平台不提供的系统、任务状态和最后联系时间保留未知。

Runner 首行沿用任务页的顺序，左侧依次显示标题、已选项目、平台筛选和账号摘要，右侧显示刷新、账号和连接设置。更新时间和自动刷新位于列表下方。GitHub 范围内的「GitHub 仅自托管」可通过悬停、点击或键盘聚焦查看说明。

平台筛选默认「全部平台」，也可选择 GitHub 或 GitLab。筛选范围与侧栏项目选择取交集，状态计数和表格同步更新。选中项目未连接当前平台时，可以直接恢复到全部平台。列表与详情显示平台主机，演示数据在 GitHub 与 GitLab 各包含一台 #128，用于核对跨平台同编号的归属。
