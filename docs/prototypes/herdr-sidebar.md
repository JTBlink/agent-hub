# Herdr 侧边功能区：需求草案

本稿供界面评审，尚未成为实现规格。配套原型为 [herdr-sidebar.html](herdr-sidebar.html)，所有会话、终端、安装和任务操作均为内存中的模拟数据。

## 要解决的问题

用户已经在 AgentHub 终端中使用 Herdr。工作空间、标签页和 Agent 较多时，需要反复进入 TUI 查找目标，记忆快捷键，并逐个检查哪些 Agent 需要输入。希望从 AgentHub 左侧直接找到目标，再回到终端继续工作。

## 已确定的位置

- Herdr 作为左侧活动栏的独立入口，紧随终端入口，位于用户标注的空位。
- 点击入口展开 Herdr 侧边功能区；再次点击收起。收起面板不关闭任何会话。
- 主区域继续显示终端，保留现有标签、输入和运行中的进程。
- 切换 Herdr 工作空间或 Agent 不切换 AgentHub 项目、不关闭该项目的其他终端。

## 首版范围

### 默认启动页

- 启动时恢复上次打开的会话和工作空间；上次目标已不可用时选择现有的工作空间。
- 加载工作空间期间显示品牌欢迎页，文案为“加载中…”，不显示终端、工作空间内容或创建操作；加载完成后恢复上次工作空间，没有工作空间时显示创建引导。
- 只有加载完成且没有任何工作空间时，主区域显示带创建入口的欢迎页；左侧保留导航和创建入口，Agent 区域继续默认折叠。
- 欢迎页参考居中的桌面工作台布局，沿用 AgentHub 图标、系统字体和当前明暗主题，以品牌标识、简短引导、添加项目／创建工作空间两个入口及快捷键为中心。
- 创建或选择工作空间后进入终端；欢迎页不显示终端标签、分屏和终端工具条。
- `⌘ N` 创建工作空间，`⌘ ⇧ ↑` / `⌘ ⇧ ↓` 切换上一个／下一个工作空间；帮助入口放在底部。
- 原型记住模拟会话和工作空间选择，用“演示状态 → 空工作空间”评审欢迎页。添加项目与创建只改变页面中的模拟数据。

### 会话和连接

面板顶部显示本机及明确选定的 Herdr 会话。可以选择已有会话、手动刷新，并显示加载、未安装、未运行、连接失败和空工作空间状态。面板展开且应用在前台时更新状态；关闭后停止刷新。读取失败不显示成“没有 Agent”。

“打开终端”定位已关联的 Herdr 终端。尚未关联时，在当前项目的可用终端中打开选定会话；当前 Shell 忙碌或有输入草稿时提示另开终端，保留原输入。查看列表不隐式启动服务。

### 查找和切换

侧边栏主要承担用户示例中的快速切换功能：上半部分展示工作空间、分支及关联工作树，下半部分展示 Agent、所属工作空间、标签页及状态。Agent 状态来自 Herdr，至少区分工作中、等待输入、已完成、空闲和未知，不能仅依赖颜色。允许按名称筛选。

点击条目聚焦明确的目标并定位关联终端。Agent 名称、窗格 ID 和会话组合用于定位，不能借用其他客户端的当前焦点。界面中的“已完成”只表示 Herdr 的生命周期状态。

### 常用操作

- 空工作空间列表提供创建入口；已有内容时以切换为主。
- 新建标签页：在选定工作空间内创建。
- 左右／上下分屏：在明确选定的窗格内创建 Shell，继承其目录。
- 放大／还原窗格：只作用于选定窗格。
- 显示／隐藏 Herdr 原生侧栏：保留用户继续使用 TUI 的能力。
- 侧边栏提供手动 Agent 操作；常驻任务输入和审批确认仍在终端中处理。

创建操作不抢占无关终端的焦点；操作失败保留上下文并提供重试。原型中的简化新建表单只验证交互位置，正式实现需要目录校验和 Shell 就绪检查。

### 侧边栏布局优化

- 会话选择压缩为“本机 / 会话”一行，连接状态放在标题旁。
- 上半部分是工作空间列表：名称下显示分支，关联工作树缩进展示，当前空间高亮。
- 下半部分是 Agent 列表：第一行显示所属空间和标签页，第二行显示 Agent 名称和状态，当前窗格高亮。
- Agent 区域默认折叠，仅保留标题、数量和排列切换；点击标题展开或收起，支持键盘操作。折叠后工作空间列表占用剩余高度，展开后恢复列表比例和滚动位置。
- 两组列表独立滚动，中间分隔线可以拖动，也可用键盘上下调整列表比例。
- Agent 默认按工作空间排列，可切换为按状态排列；搜索同时筛选两组列表。
- 单击直接切换；方向键上下移动焦点，Enter 进入目标。点击工作空间回到该空间上次选中的窗格。
- 切换和刷新保留列表滚动位置，不自动回到顶部。创建、分屏等操作集中在终端底部。
- 侧边栏不放常驻任务输入区、Agent 详情卡片或管理操作网格，为切换列表保留空间。任务仅在点击发送后以弹窗编辑。

### 适合 Agent 编程的手动操作

| 入口             | 行为                                                            | Herdr 能力与边界                                                                          |
| ---------------- | --------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| 新建 Agent       | 选择 Codex、Claude 等类型、唯一名称、新窗格方向，可填写初始任务 | 先创建 Shell 窗格并确认就绪，再调用 `agent start`；初始任务在就绪后用 `agent prompt` 投递 |
| 待处理           | 展开 Agent 列表并筛选等待输入的目标，再次点击恢复全部           | 根据 `agent_status` 筛选，不自动回答问题或审批                                            |
| 条目上的发送任务 | 在弹窗编辑任务，可套用审查、测试、排障示例                      | 仅向明确的空闲／已完成 Agent 发送；工作中、等待确认、状态未知时禁用                       |
| 条目上的查看输出 | 查看其他 Agent 的可见输出快照，可复制或定位终端                 | 使用 `agent read --source visible`，打开输出不切换当前工作窗格                            |
| 条目上的中断     | 确认后向工作中的 Agent 发送 Ctrl+C                              | 使用 `agent send-keys`；保留窗格及会话，发送后重新核实实际状态                            |

条目操作在悬停或键盘聚焦时显示，触摸设备可直接操作。新建默认保持当前目标，用户可勾选切换到新 Agent。任务模板由 AgentHub 组合提示词，不是 Herdr 内置审查或修复功能；用户可在发送前修改。

### 终端底部工具条

按钮位于终端显示区下方、应用状态栏上方，与侧边栏独立，收起侧栏后仍然可用。

| 按钮                | 行为                                            |
| ------------------- | ----------------------------------------------- |
| 新建标签            | 在当前 Herdr 工作空间内新建标签页               |
| 左右分屏 / 上下分屏 | 在当前目标中创建对应方向的窗格                  |
| 放大窗格 / 还原窗格 | 切换当前窗格的放大状态                          |
| Herdr 侧栏          | 切换 Herdr 原生侧栏，按钮反映当前状态           |
| 复制输出            | 复制当前窗格的可见文本                          |
| 清屏                | 清空当前窗格显示，不中断进程、不修改 Agent 状态 |

工具条按使用频率排列：新建标签 → 左右分屏 → 上下分屏 → 复制输出 → 放大／还原窗格 → 清屏 → Herdr 侧栏。右侧显示当前 Agent 和窗格标识，目标不可用时禁用操作。窄窗口下按钮保留图标及可访问名称，允许换行。原型的清屏提供恢复模拟输出入口，方便反复评审。

### 自动监控与决策的归属

自动监控归入现有“自动化／定时任务”，侧边栏不增加监控开关或常驻监控区。本轮只确定归属和可行性，不创建或启用真实定时任务。

可以将每次巡检设计为：核验目标身份 → 读取状态及有限的新输出 → 判断是否仍有问题 → 在既有任务范围内形成下一步 → 必要时向原 Agent 投递具体指令 → 核验回执。Herdr 提供状态、输出、任务和按键接口；问题判断、授权范围及处理策略需要由决策 Agent 或模型承担。

- 正常工作且有进展时继续观察，不打断。
- 构建或测试失败且目标可输入时，可按配置发送具体修复和验证要求。
- 限流、连接失败可以退避后恢复；先核实问题尚未自行恢复。
- 等待审批、缺少授权或需要修改需求时通知用户，不自动批准。
- 查询失败、身份变化或上次投递结果不明时，先核实，不重复投递。
- 定时器需要互斥和检查点，避免多个巡检同时控制同一 Agent；`done` 只是生命周期状态，仍需验收证据。

## 当前方案

根据用户提供的 Herdr 侧栏示例，原型已收敛为“工作空间 + Agent”上下两组快速切换列表。主终端及底部功能按钮保留。原型底部标识、状态演示和需求说明属于评审工具，不进入产品。

## 本轮不包含

SSH 机器配置、插件管理、工具升级、关闭或删除会话／工作空间、自动批准 Agent 请求、任务调度与历史记录。已有自动化和 Herdr 工具安装能力仍沿用现有入口，未安装状态仅提供接入现有安装流程的入口。

## 验收点

1. Herdr 入口位于终端下方，可用键盘打开和收起，具有明确名称与选中态。
2. 展开、收起、筛选和刷新均保留终端进程及未提交输入。
3. 切换会话后，旧请求不覆盖新会话；后续操作只作用于所选会话及目标。
4. 点击工作空间、标签、Agent 后，主终端显示对应目标；保留当前 AgentHub 项目及其他终端。
5. 等待输入的 Agent 可直接定位，在终端中由用户回答；不会自动批准。
6. 创建和分屏均有目标、禁用条件、等待与失败反馈，防止重复执行。
7. 未安装、未运行、空内容和连接失败具有不同提示和下一步操作。
8. 深浅主题、放大文字、长名称、窄窗口和侧栏内部滚动下，主要操作仍可见可达。
9. 终端底部按钮始终作用于明确的当前目标；放大、原生侧栏按钮具有状态，清屏不改变 Agent 生命周期。
10. 收起侧边栏仍可使用终端底部工具条；切换目标和筛选不会丢失终端输入草稿。
11. 工作空间与 Agent 列表独立滚动，可调整高度；切换不重置滚动位置，返回工作空间时恢复其上次选中的窗格。
