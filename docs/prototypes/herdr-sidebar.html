评审问题：在保留终端工作流的前提下，Herdr 面板怎样组织最顺手？

入口与布局

在 AgentHub 左侧活动栏的终端下方新增 Herdr 入口。点击展开侧边面板；主区域保留 Herdr 终端，收起面板不结束任何进程。

首版要做什么

  1. 选择明确的本机会话，显示连接状态并支持刷新。
  2. 查找工作空间、标签页和 Agent；点击后定位主终端。
  3. 突出等待输入及已完成的 Agent，保留 Herdr 的状态语义。
  4. 新建工作空间、标签页，左右／上下分屏，放大／还原窗格。
  5. 保留 Herdr 原生侧栏开关，允许用户继续使用 TUI。
  6. 可选：向所选 Agent 发送任务；等待确认时由用户在终端处理。

比较三个方案

A 工作空间树 空间归属清晰，适合经常切换项目。推荐作为首版。
B Agent 待处理 先显示需要介入的 Agent，适合多个 Agent 同时工作。
C 常用操作 先显示当前目标和常用操作，适合单一主工作空间。

关键验收

  • 入口在终端下方；打开、收起、筛选不影响进程和输入。
  • 切换会话时，旧响应不覆盖当前目标。
  • 工作空间、标签、Agent 的切换定位准确，不关闭其他终端。
  • 未安装、未运行、空内容、连接失败有各自提示。
  • 等待确认时定位终端，不自动批准；任务不重复发送。
  • 明暗主题、长名称、窄窗口、键盘操作和放大文字均可用。

后续再考虑

SSH 机器、插件、工具升级、会话删除、任务调度及历史。先确定这一层是否顺手，再扩展管理能力。
