Herdr 侧边功能区 · 需求草案

评审问题：在保留终端工作流的前提下，Herdr 面板怎样组织最顺手？

入口与布局

在 AgentHub 左侧活动栏保留独立 Herdr 入口，不再增加单独的“终端”入口。点击展开侧边面板；主区域保留 Herdr 终端，收起面板不结束任何进程。

首版要做什么

  1. 选择明确的本机会话，显示连接状态并支持刷新。
  2. 侧边栏上半部分显示工作空间、分支及关联工作树，单击直接切换。
  3. 下半部分显示 Agent、所属空间、标签页和状态，单击定位对应窗格。
  4. 两组列表独立滚动，中间分隔线可拖动调整高度。
  5. 支持搜索、按空间／状态排列 Agent，以及上下方向键定位、Enter 切换。
  6. 侧边栏提供新建 Agent、待处理筛选，以及发送任务、查看输出和中断。
  7. 按真实目录联动项目／工作树，未打开时自动打开对应工作空间。
  8. 新建标签、分屏和放大等操作集中在终端底部。

本轮优化

以“工作空间 + Agent”两组快速切换列表为主，补充轻量的手动操作。任务输入按需打开弹窗，不常驻挤占列表空间。切换时保留滚动位置，并记住每个工作空间上次选中的窗格。

终端底部按常用顺序排列：新建标签、左右分屏、上下分屏、复制输出、放大／还原窗格、清屏、Herdr 侧栏。右侧标明操作目标；清屏只清空显示，不改变 Agent 状态。

自动监控与决策

归入现有自动化／定时任务，侧边栏不增加监控开关。巡检读取状态和新输出，核实仍存在的问题，再按已配置范围给原 Agent 发送具体下一步；审批和缺少授权的问题交给用户。本轮仅确定归属，不启动真实监控或定时任务。

当前方案

入口与布局已确定，以快速切换为主。本轮评审重点是列表密度、上下列表比例、当前目标高亮，以及切换是否准确顺手。

关键验收

  • 活动栏仅保留 Herdr 功能入口；终端从项目工作空间进入。
  • 切换会话时，旧响应不覆盖当前目标。
  • 按目录打开对应 AgentHub 项目／工作树，Herdr 服务和 Agent 持续运行。
  • 未安装、未运行、空内容、连接失败有各自提示。
  • 等待确认时定位终端，由用户处理，不自动批准。
  • 切换工作空间回到上次使用的窗格，不把列表重置到顶部。
  • 明暗主题、长名称、窄窗口、键盘操作和放大文字均可用。

后续再考虑

SSH 机器、插件、工具升级、会话删除、任务调度及历史。先确定这一层是否顺手，再扩展管理能力。
