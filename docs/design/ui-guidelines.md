# AgentHub 界面规范

AgentHub 是本地优先的 Agent 工作空间控制台。界面应帮助用户快速回答三件事：配置在哪里、Skill 从哪里来、一次写入是否可以安全回退。

## 视觉语言

- 参考 Edge macOS 图标的深海军蓝底板与蓝—青—绿能量流，但不复制 Edge 的 `e` 轮廓；AgentHub 的识别点是“三个 Agent 流向一个本地 Hub”。
- 页面基底使用 `#08101F`，主 Surface 使用 `#111D35` / `#182748`，边框使用 `#263B67`；卡片允许一层很轻的内高光和阴影，表达图标同款立体层次。
- `#168BFF` → `#42D9B1` 渐变只用于主 CTA、连接拓扑和重点状态；violet 表示 Skill，amber 表示提醒，不能用颜色作为唯一状态表达。
- 图标统一使用 SVG；品牌标记、Hub 和拓扑节点使用同一套蓝绿渐变与深色下层轨道。不使用 emoji 作为导航或操作图标。
- 正文对比度至少 4.5:1，正文至少 14px、行高 1.5；辅助文字使用语义色 token，不在组件内散落新的 hex 值。

## 布局与响应式

- 桌面端使用固定侧栏 + 内容区，内容最大宽度 1260px；页面内间距遵循 8px 节奏（8/16/24/32）。
- 小于 740px 时，导航变为可横向滚动的带文字标签栏，不能只保留图标，也不能造成页面横向溢出。
- 主要按钮、输入框和图标按钮最小高度 44px；相邻可操作控件至少间隔 8px。
- 375px、768px、1024px 和 1440px 都要检查；长路径和 Skill 名称必须允许换行。

## 交互与可访问性

- 每个输入都有可关联的标签；图标按钮必须有 `aria-label`，选项卡和筛选按钮使用 `aria-pressed` 或 `aria-current`。
- 异步扫描显示稳定的加载状态，并通过 `role="status"` 通知结果；错误提示必须包含重试或修复路径。
- 配置修改始终遵循“读取原文 → Diff 预览 → 明确确认 → 备份写入”的顺序。
- 所有焦点环可见；动画只用于连接、扫描和状态变化。拓扑流动、Hub 呼吸和节点脉冲必须在 `prefers-reduced-motion` 下停用。

## 总览信息层级

- 总览按“当前健康状态 → Agent 连接拓扑 → 配置、Skills、诊断指标 → 下一步操作”组织，不使用仅用于装饰的大面积图表。
- 首屏主操作由真实状态决定：存在未接入 Agent 或待处理诊断时优先进入诊断中心，否则进入配置中心。
- 拓扑方向与桌面图标一致：三个 Agent 汇入本地 Hub；动画仅表达已扫描连接，未接入与异常节点必须同时使用文字和不同轨道状态。
- 安全写入流程保持可见但处于辅助层级，不能盖过当前异常或核心管理入口。
