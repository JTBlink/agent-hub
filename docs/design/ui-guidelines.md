# 视觉规范

保留 agent-hub 的原 Logo 和图标母版 `src-tauri/icons/app-icon.svg`，不得替换为导入项目的图标。

主题变量集中在 `src/styles/brand.css`：深色背景 `#08101f`，卡片 `#111d35`，边框 `#263b67`，主色 `#168bff`，辅助青色 `#42d9b1` 与紫色 `#9b9cff`。同时提供浅色主题和跟随系统设置。

页面使用 Tailwind 的语义颜色和共享组件，避免硬编码另一套品牌配色。保留现有明暗主题切换、文字缩放、操作反馈和键盘可访问性。页面布局基于当前工作台逐步迭代，不再采用旧配置中心原型。

平台图标生成与验收见 [图标规范](../development/icon-assets.md)。
