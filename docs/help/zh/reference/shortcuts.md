# 键盘快捷键

| 操作     | macOS | Windows / Linux |
| -------- | ----- | --------------- |
| 命令面板 | ⌘ K   | Ctrl K          |
| 设置     | ⌘ ,   | Ctrl ,          |
| 刷新数据 | ⌘ R   | Ctrl R          |

## 命令面板

快速跳转到技能、技能组和项目，或执行可用操作。输入框正在编辑时，部分全局快捷键不会触发。

## 帮助中心

使用 Tab 移动焦点，Enter 打开文章。文章目录链接定位到相应章节，浏览器或应用返回操作保留路由历史。
