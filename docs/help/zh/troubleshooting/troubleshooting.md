# 常见问题与排查

先确认问题属于导入来源、技能内容、Agent 入口还是备份同步。不同问题需要不同处理，保留修改过的原件。

## 导入失败

检查来源路径或仓库地址，以及目录中是否包含有效 Skill 入口。远程导入失败时检查网络与仓库权限。本地来源已移动时，技能库已有副本仍可使用。

## Agent 入口失效

检查目标 Agent 和工作空间是否正确。项目页提示入口异常时，使用“修复 Agent 入口”；若目标内容与项目版本不同，先比较差异。

## 同步失败

检查网络、登录状态和仓库访问权限。在「云端同步」页查看具体错误，避免反复更换来源覆盖本机内容。

## 内容冲突

查看双方内容与恢复提示，再选择保留本机、使用远端或两个都保留。项目内容修改与个人库更新分别处理。

## 导出日志

在“设置 → 关于”使用“导出日志”保存压缩包。反馈中说明应用版本、操作步骤、预期结果和实际结果。分享前检查日志与附件，移除凭据和个人信息。
