# 按任务搭配 Skills

根据任务建立技能组，再选择适合的来源。以下是组合思路，具体技能名称和行为以你安装的入口文档为准。

## 日常开发

组合项目开发规范、代码审查和提交约定。项目相关规范放在项目技能库，个人通用习惯按需全局部署。

具体技能名称、matt 系列推荐集合与调用提示词见 [Coding Skills 推荐集合](coding-skills.md)；部署和调用步骤见 [Skill 使用技巧](skill-usage-tips.md)。

## 代码审查

组合领域上下文、编码规范和审查流程。明确审查的代码范围和验收条件，避免把工具输出直接当作结论。

## 发布维护

组合版本约定、构建验证与发布验收。只有当前任务确实需要时才配置发布相关工具和权限。

## 团队引导

将团队术语、目录入口、常用操作与验证命令写入项目技能。新人拉取仓库后，可以使用团队共同维护的版本。

## 定期整理

移除重复和不再适用的技能，检查来源更新，再重新确认工作空间部署。技能组成员变化不会自动改动已有部署。
