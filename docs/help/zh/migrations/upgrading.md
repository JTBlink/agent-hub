# 升级与文档版本

## 文档版本

应用帮助随安装包提供，可以离线阅读。帮助首页与文章顶部显示对应版本。在线文档显示网站构建的版本，可能与你安装的版本不同。

## 升级前

查看发布说明，确认是否涉及部署方式、目录或同步行为变化。保留已有备份和项目 Git 历史。

## 项目技能

普通项目中央库保存实际内容。旧的个人库链接与副本在操作时按当前策略检查；存在冲突或修改时，先比较，避免直接覆盖。

## 默认部署方式

新版统一默认部署方式；已有入口保留原方式，旧范围偏好在尚未选择统一值时继续保留。详见[链接与复制](../guides/deployment-modes.md)。

## 在线与离线

“在浏览器打开”访问当前在线文档；复制分享链接可把具体文章或章节发送给他人。阅读时对照文档和应用版本。当前不提供自动文档热更新或完整历史版本切换。
