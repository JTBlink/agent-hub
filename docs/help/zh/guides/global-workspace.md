# 管理全局工作区

全局工作区按 Agent 展示其全局技能目录的内容，包括不通过 AgentHub 安装的 Skills。

## 添加技能

点击“+ 添加 Skills”，从技能库选择内容，再选择目标 Agent。通用的提交规范、审查指南等适合全局使用。

## 多 Agent 管理

在各 Agent 页面查看实际目录内容，也可通过“全部 Agents”总览统一管理。目录和配置文件存在并不等于宿主工具已经安装；显示结果以应用检测和工具实际使用为准。

## 只在 Agent 目录中的技能

可以查看这些技能，按应用入口导入技能库或管理目标内容。删除前确认是否仍需要原件。

## 项目级技能

特定项目的团队规范应使用[项目技能与团队共享](project-team-sharing.md)，以便团队获得一致内容。
