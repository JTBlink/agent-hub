# 链接与复制

在设置中选择默认部署方式，控制新建 Agent 入口的链接或复制方式。已有入口保留记录中的方式。

## 链接

链接让 Agent 入口指向技能内容。普通项目中央库始终保存实际内容，专属入口优先使用项目内相对链接，不依赖维护者的个人主目录。

## 复制

复制为 Agent 创建独立副本。中央内容更新后，副本可能需要刷新；单独修改的副本应先查看差异。

## 旧设置与单次选择

尚未选择统一默认值时，应用保留已有范围的偏好。项目单次安装的复制选择仍然有效。

## 自定义 Agent

在设置的 Agent 列表添加名称和全局技能目录。需要项目使用时，还需填写相对项目根目录的技能路径；不要把个人绝对路径作为团队交付约定。
