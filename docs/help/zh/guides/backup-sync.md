# 备份与多设备同步

Git 备份为个人技能库保存内容和同步元数据。默认备份工作区位于 `~/.agent-hub/backup`，与团队项目仓库分开管理。

## 连接备份仓库

在备份页完成 GitHub 登录并连接仓库。在另一台设备上连接同一备份仓库，依据应用状态确认内容已同步。

## 内容冲突

同一技能在多设备同时修改时，应用会显示需要处理的冲突。比较内容后选择保留本机、使用远端或两个都保留。每次选择前建立安全快照。

## 恢复与隐私

凭据和本机专属设置不进入技能备份。恢复原件和安全快照保留在本机；默认恢复目录为 `~/.agent-hub/recovery`。

## 无法同步时

检查网络、登录状态和仓库访问权限。导出日志的步骤见[常见问题与排查](../troubleshooting/troubleshooting.md#同步失败)。
