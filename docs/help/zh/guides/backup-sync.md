# 备份与多设备同步

「云端同步」通过 Git 仓库在设备间同步个人技能库，并保存版本历史供恢复。默认本地同步仓库位于 `~/.agent-hub/backup`，与团队项目仓库分开管理。

## 连接备份仓库

在「云端同步」页完成 GitHub 登录并连接仓库，也可以填写其他 Git 仓库地址。另一台设备连接同一仓库，即可同步同一份技能库。连接完成后检查页面状态；如有待上传或云端更新，点击「立即同步」。

## 日常同步

- **立即同步**：先保存本机更改，再获取云端更新、按技能合并，最后按需上传本机提交。
- **检查并同步**：本机显示已同步时，仍可检查云端是否有新更新；没有变化时不会创建新快照。
- **刷新**：重新获取仓库状态，便于查看待上传和云端更新；不会将云端内容合并到本机。
- **自动同步**：应用运行时，在本机改动停止约 2 分钟后执行同步；启动约 90 秒后也会检查一次。退出时仅尝试本地保存，上传留到下次启动。

当前自动同步由启动和本地变更触发，本机长期没有改动时不会定期拉取云端。需要获取其他设备的新内容时，点击「检查并同步」。失败会保留错误提示并延迟重试。

## 内容冲突

同一技能在多设备同时修改时，应用会显示需要处理的冲突。比较内容后选择保留本机、使用远端或两个都保留。每次选择前建立安全快照。

## 恢复与隐私

手动同步在需要上传时创建可恢复的历史快照；自动同步保存 Git 提交，不为每次自动操作创建快照。在「历史快照」中恢复时会先保存安全快照，原历史仍保留。恢复后的本机内容可在后续同步中传播到其他设备。

凭据和本机专属设置不进入技能备份。恢复原件和安全快照保留在本机；默认恢复目录为 `~/.agent-hub/recovery`。

## 无法同步时

检查网络、登录状态和仓库访问权限。导出日志的步骤见[常见问题与排查](../troubleshooting/troubleshooting.md#同步失败)。

## 断开同步

「断开本机」停止当前设备的同步并清除保存的连接与凭据。本地技能和云端仓库保留，其他设备仍可继续使用该仓库。
