# 使用技能组

技能组是按用途命名的 Skill 集合，例如“日常开发”或“代码审查”。它负责集合关系；部署记录属于具体工作空间。

## 创建与维护成员

在技能库选择技能组，查看与维护成员。未分组的技能可以通过“加入技能组”入口归入已有技能组。

## 添加到工作空间

在全局或项目工作空间点击技能组按钮，批量添加或移除其中的 Skills。全部添加后显示已添加状态，部分添加时显示数量。

修改技能组成员**不会自动更新已有部署**。成员变化后，到对应工作空间重新选择需要添加或移除的技能。

## 按任务组织

建议根据真实任务建立少量技能组。某些技能可以共用，但不要为了切换任务反复复制相同正文。推荐搭配见[按任务搭配 Skills](../recommendations/workflow-recipes.md)。
