# 管理技能库

技能库是个人收藏和管理 Skill 内容的地方。默认技能内容位于 `~/.agent-hub/skills`。

## 导入与整理

从本地目录、Git 仓库或压缩包导入后，打开技能详情检查正文与来源。用标签描述用途，用技能组整理经常一起使用的 Skills。

技能库支持技能组、来源、标签与部署状态筛选。组合筛选后没有结果时，先清除筛选，再确认技能是否已经导入。

## 浏览 Git 仓库

在「发现 → Skills → Git 安装」中添加远程地址或选择本地 Git 仓库根目录，通过顶部下拉框切换仓库。远程地址支持 HTTPS、HTTP、SSH（含自定义端口）、`git@主机:路径` 和 GitHub 的 `组织/仓库` 简写；私有仓库使用本机 Git 凭据或 SSH 密钥。

仓库中的 Skills 以卡片展示，可搜索名称、描述或路径，并按安装状态筛选。点击名称查看详情，点击「＋」安装单个 Skill；「批量选择」支持一次导入多个，确认时可修改名称。

同一来源的已导入项显示「已安装」。技能库中已有其他来源的同名 Skill 时，卡片显示「本地已存在」，并纳入已安装筛选。详情可打开已有安装，或点击「覆盖安装」；确认后用当前仓库内容替换现有内容并更新来源，保留原有标签、技能组和部署关系，已部署的复制副本也会同步更新。覆盖会替换本地修改，不会另外生成同名副本。仓库版本较旧时禁止覆盖，改为「同步新版到仓库」：在本地仓库中确认目标、版本和移除文件后写回新版，再自行查看改动并提交。远程地址需先添加本地工作区。同步及刷新会更新已打开的详情。

本地仓库直接读取当前工作区，包含尚未提交的 Skills；安装会将内容复制到技能库，后续来源更新仍使用本地目录。移动或删除原仓库不会移除已安装副本，但可能导致刷新和来源更新失败。

仓库列表会保存目录缓存及上次选择。点击「刷新」更新可浏览的目录，不自动更新已安装内容。远程仓库菜单中的「清理克隆缓存」删除克隆文件与该条目的目录缓存，之后刷新可重新克隆。正在使用的克隆缓存不能清理。移除仓库只删除列表记录，不卸载 Skills，也不删除用户自己的本地 Git 仓库。

## 部署状态

技能库中存在内容，不代表所有 Agent 已经使用它。通过工作空间添加技能，或使用 Agent 部署入口关联目标。全局和项目工作空间具有不同生命周期。

## 来源与更新

有有效来源的技能可以检查更新和查看差异。导入后原本地目录被移动，不影响技能库已有副本的使用，但来源更新可能不可用。

## 删除前确认

技能库删除与移除某个 Agent 的部署是不同操作。只想让某个 Agent 不再使用技能时，先在对应工作空间移除；删除内容前阅读应用的影响说明。
