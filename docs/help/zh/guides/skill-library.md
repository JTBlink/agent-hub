# 管理技能库

技能库是个人收藏和管理 Skill 内容的地方。默认技能内容位于 `~/.agent-hub/skills`。

## 导入与整理

从本地目录、Git 仓库或压缩包导入后，打开技能详情检查正文与来源。用标签描述用途，用技能组整理经常一起使用的 Skills。

技能库支持技能组、来源、标签与部署状态筛选。组合筛选后没有结果时，先清除筛选，再确认技能是否已经导入。

## 部署状态

技能库中存在内容，不代表所有 Agent 已经使用它。通过工作空间添加技能，或使用 Agent 部署入口关联目标。全局和项目工作空间具有不同生命周期。

## 来源与更新

有有效来源的技能可以检查更新和查看差异。导入后原本地目录被移动，不影响技能库已有副本的使用，但来源更新可能不可用。

## 删除前确认

技能库删除与移除某个 Agent 的部署是不同操作。只想让某个 Agent 不再使用技能时，先在对应工作空间移除；删除内容前阅读应用的影响说明。
