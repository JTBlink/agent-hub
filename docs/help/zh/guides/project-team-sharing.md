# 项目技能与团队共享

普通项目使用 `.agents/skills` 保存项目技能实际内容。个人技能库负责个人收藏；项目版本随项目 Git 管理。

## 添加到项目

关联项目后，点击“+ 添加 Skills”，选择技能和团队目标 Agent。已有项目技能版本优先复用；专属 Agent 入口可采用项目相对链接或复制。

项目版本不会随个人技能库自动更新。需要变更时，先查看差异，再显式更新项目内容。

## 交付给团队

安装完成后，检查应用列出的共享文件和 Git 忽略提示。提交项目技能实际内容以及团队需要的 Agent 入口，其他成员拉取后即可按宿主工具原生规则读取。

`.agent-hub/project-skills.json` 是供 AgentHub 维护者使用的管理清单，可选共享。团队使用已提交技能不依赖个人技能库或该管理清单。

## 修复 Agent 入口

缺失、失效或陈旧的入口会显示具体 Agent 与原因。使用“修复 Agent 入口”让入口对应当前项目版本；已单独修改的内容应先比较，避免丢失。

## 变更与冲突

更新项目内容和修复入口是不同操作。对有修改的副本先保留原件，再依据应用提供的差异与选择处理。

当前入口策略见[链接与复制](deployment-modes.md)。
