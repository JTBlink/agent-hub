# 独立预览与浏览

生产实现跟踪 [#270](https://github.com/JTBlink/agent-hub/issues/270)。`/preview` 提供独立工作区，切换其他工作台页面时保留标签，不依赖当前项目。项目文件阅读器可将已验证工作树中的 HTML 和 Markdown 交给此模块。

## 模块与复用

- `src/features/preview/PreviewHost.tsx` 按需加载并保留宿主；`shared/` 管理会话、地址解析、打开请求和修订隔离。
- `web/` 将真实 Chromium 的画面和输入接入工作区；`markdown/` 复用 `MarkdownContent`、`CodeEditor`，增加目录、源码位置、资源授权和截图。
- `components/` 组合批注、实际 Agent 目标交付、下载、登录配置和页面调试。
- `src-tauri/src/core/preview/` 是桌面端与 CLI 共享的浏览宿主。命令层仅处理桌面选择器、导出与 IPC；CLI 通过独立认证回环接口操作相同页面。

本地文档读取复用项目文件读取器；保存复用既有冲突检查与原子保存。浏览器使用应用专属资料目录，不读取日常浏览器资料。网页与应用 IPC 分离，页面输出先作为数据检查后交给界面。

## 会话与资源

最多同时打开 12 个标签，最近关闭保留 20 个；标签恢复不重放输入或 Agent 操作。重启仅恢复网页地址、标题与登录配置元数据。本地文档授权需重新打开；草稿不作为自动恢复操作持久化。内置访客与自定义临时登录配置不保存标签恢复元数据；其浏览器使用新建临时资料目录，进程回收后清理。原有配置缺少 `ephemeral` 字段时保持持久配置。

批注绑定标签和原生文档修订。导航、刷新或编辑使旧上下文失效；截图和 Agent 投递前复核修订。每个当前页面最多 20 条批注，整体最多 200 条；单张附件上限 3 MiB，内存附件整体上限 32 MiB。文本及图片可形成应用拥有的临时上下文包，退出时清理，不删除其他文件。

授权文档的资源服务仅监听回环地址，限制根目录、规范化路径、隐藏路径和资源大小。HTML 每份授权使用独立来源，支持根相对资源。Markdown 的资源保留授权前缀。文档授权随最近关闭记录淘汰后撤销。

浏览器按配置独立管理；单页控制与配置启动分别加锁，不让一个慢页面占据所有页面的控制锁。帧、事件、表达式、截图和连接数量均有上限。空闲配置延迟回收；应用退出结束自己启动的进程。远端连接使用独立浏览上下文，断连不会宣称目标已关闭。

## 登录导入

Cookie 导入统一由 `core/preview/cookies/` 校验，支持 JSON 数组或 `cookies` 对象、Netscape 文本、显式选择的 Firefox `cookies.sqlite`，以及用户指定回环调试端点的 Chrome／Edge／Chromium 默认浏览上下文。Firefox 支持数据库版本 9–17，依据版本区分秒／毫秒过期时间并保留 SameSite 的未设置状态，版本依据 [Mozilla 存储迁移](https://searchfox.org/firefox-main/source/netwerk/cookie/CookiePersistentStorage.cpp)与[接口定义](https://searchfox.org/firefox-main/source/netwerk/cookie/nsICookie.idl)。Firefox 文件与 WAL 在私有临时副本中解析，限制数据库大小、SQLite 值长度与执行时间，拒绝视图和生成列，不改写来源数据库。Chromium 本地加密数据库需先由来源浏览器导出，或启用明确的调试连接。

原生层暂存 Cookie 值，界面仅接收域名、数量、跳过原因与目标信息。每批最多 2000 条、2 MiB，最多保留四批，五分钟后回收。导入预览绑定原生页面和修订，可取消，使用后失效；应用前再次核验，不能把旧预览用于导航后的页面。

域名使用离线 Public Suffix List 校验；无效、过期、分区和已知设备绑定状态单独计数。Google 域名及其子域沿用保守导入策略，跳过迁移并保留现有登录，用户在目标配置直接登录。Firefox 容器与分区信息不降级成普通 Cookie。导入不迁移 passkey、浏览器密码或全部站点存储。

用户选择精确域名及合并／替换模式。同配置的显式导入串行执行，替换只删除所选精确域名；存在无法保留的分区状态时拒绝替换。失败先恢复受影响原 Cookie，再清理新增项；恢复无法核实时报告结果不明，不自动重放。来源浏览器只读，不关闭或接管来源标签。

## 传输与边界

本机下载在受管目录中记录进度，可取消、打开和定位。文件选择必须经过桌面原生选择器，最多 20 个文件、合计 10 MiB。远端上传将内容暂存在远端浏览器内存中，再设置文件输入；不发送本机路径。文件输入接受后才能报告成功，不把文件传输等同于网站表单提交。

浏览宿主需要本机 Chrome、Edge 或 Chromium，或经 SSH 转发的回环 Chromium 调试端点。没有浏览器时提供明确错误和运行时配置入口。真实第三方登录、远端网络环境和其他系统需按实际环境验收。

自定义登录配置可在关闭全部页面与下载后确认删除，同时清理该配置的受管资料目录；默认与访客配置保留。删除意图先写入配置；移动或清理失败保留可见的待删除记录和受管恢复目录，可重试完成，待删除配置不能启动或编辑。下载文件由下载面板管理。默认与访客不占用 20 个自定义配置名额，旧的满额配置可继续编辑。

当前仍在实现完整范围中的远程下载管理、托管分享适配等能力；不能以原型入口或合成 IPC 界面测试作为这些功能的验收证据。CLI 只补关键功能，使用说明单独维护于 [预览 CLI](../help/zh/reference/preview-cli.md)。
