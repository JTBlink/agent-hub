# 独立预览与浏览

生产实现跟踪 [#270](https://github.com/JTBlink/agent-hub/issues/270)。`/preview` 提供独立工作区，切换其他工作台页面时保留标签，不依赖当前项目。项目文件阅读器可将已验证工作树中的 HTML 和 Markdown 交给此模块。

## 模块与复用

- `src/features/preview/PreviewHost.tsx` 按需加载并保留宿主；`shared/` 管理会话、地址解析、打开请求和修订隔离。
- `web/BrowserSurface.tsx` 仅选择后端，`web/chromium/` 管理 Chromium 帧与输入，`web/native/` 管理系统 WebView 和独立 IPC；`markdown/` 复用 `MarkdownContent`、`CodeEditor`，增加目录、源码位置、资源授权和截图。
- `components/` 组合批注、实际 Agent 目标交付、下载、登录配置和内核信息弹窗。开发人员工具按钮与 F12 打开当前页面的原生检查器；Chromium 使用同一受管回环调试端点提供的内置 DevTools 前端，在系统浏览器中连接原页面（远端端点沿用 SSH 转发地址），系统 WebView 打开自身检查器。
- `src-tauri/src/core/preview/` 是桌面端与 CLI 共享的浏览宿主。命令层仅处理桌面选择器、导出与 IPC；CLI 通过独立认证回环接口操作相同页面。

本地文档读取复用项目文件读取器；保存复用既有冲突检查与原子保存。浏览器使用应用专属资料目录，不读取日常浏览器资料。网页与应用 IPC 分离，页面输出先作为数据检查后交给界面。

## 会话与资源

最多同时打开 12 个标签，最近关闭保留 20 个；标签恢复不重放输入或 Agent 操作。重启仅恢复网页地址、标题与登录配置元数据。本地文档授权需重新打开；草稿不作为自动恢复操作持久化。内置访客与自定义临时登录配置不保存标签恢复元数据；其浏览器使用新建临时资料目录，进程回收后清理。原有配置缺少 `ephemeral` 字段时保持持久配置。

批注绑定标签和原生文档修订。网页修订包含文档加载身份、主框架导航序号和完整 URL 摘要，SPA 路由与片段导航均产生新修订；返回原地址也不会复活旧元素引用。原生快照引用按修订校验，最多保留最近八批；复制抓取上下文前也核验当前修订。导航、刷新或编辑使旧上下文失效；截图和 Agent 投递前复核修订。抓取上下文保留页面标题、URL、修订、DOM 路径、视口尺寸、DPR、缩放及滚动位置；Markdown 额外保留可信的起止源行。复制或交付批注时带上这些测量，不能用浏览器未知的源码位置代替真实来源。截图使用共享 PNG 流程，可保存或复制到系统图片剪贴板，批注支持单条与批量复制。每个当前页面最多 20 条批注，整体最多 200 条；单张附件上限 3 MiB，内存附件整体上限 32 MiB。文本及图片可形成应用拥有的临时上下文包，退出时清理，不删除其他文件。

授权文档的资源服务仅监听回环地址，限制根目录、规范化路径、隐藏路径和资源大小。HTML 每份授权使用独立来源，支持根相对资源。本地文档地址栏默认显示源文件真实完整路径，可点击栏内图标切换预览 URL；路径模式支持选中和复制，URL 模式保留导航，不从临时资源 URL 推断磁盘路径。Markdown 的资源保留授权前缀。文档授权随最近关闭记录淘汰后撤销。

浏览器按配置独立管理；单页控制与配置启动分别加锁，不让一个慢页面占据所有页面的控制锁。帧、事件、表达式、截图和连接数量均有上限。空闲配置延迟回收；应用退出结束自己启动的进程。远端连接使用独立浏览上下文，断连不会宣称目标已关闭。

## 登录导入

Cookie 导入统一由 `core/preview/cookies/` 校验，支持 JSON 数组或 `cookies` 对象、Netscape 文本、显式选择的 Firefox `cookies.sqlite`，以及用户指定回环调试端点的 Chrome／Edge／Chromium 默认浏览上下文。Firefox 支持数据库版本 9–17，依据版本区分秒／毫秒过期时间并保留 SameSite 的未设置状态，版本依据 [Mozilla 存储迁移](https://searchfox.org/firefox-main/source/netwerk/cookie/CookiePersistentStorage.cpp)与[接口定义](https://searchfox.org/firefox-main/source/netwerk/cookie/nsICookie.idl)。Firefox 文件与 WAL 在私有临时副本中解析，限制数据库大小、SQLite 值长度与执行时间，拒绝视图和生成列，不改写来源数据库。Chromium 本地加密数据库需先由来源浏览器导出，或启用明确的调试连接。

原生层暂存 Cookie 值，界面仅接收域名、数量、跳过原因与目标信息。每批最多 2000 条、2 MiB，最多保留四批，五分钟后回收。导入预览绑定原生页面和修订，可取消，使用后失效；应用前再次核验，不能把旧预览用于导航后的页面。

域名使用离线 Public Suffix List 校验；无效、过期、分区和已知设备绑定状态单独计数。Google 域名及其子域沿用保守导入策略，跳过迁移并保留现有登录，用户在目标配置直接登录。Firefox 容器与分区信息不降级成普通 Cookie。导入不迁移 passkey、浏览器密码或全部站点存储。

用户选择精确域名及合并／替换模式。同配置的显式导入串行执行，替换只删除所选精确域名；存在无法保留的分区状态时拒绝替换。失败先恢复受影响原 Cookie，再清理新增项；恢复无法核实时报告结果不明，不自动重放。来源浏览器只读，不关闭或接管来源标签。

## 传输与边界

本机下载在受管目录中记录进度，可取消、打开和定位。文件选择必须经过桌面原生选择器，最多 20 个文件、合计 10 MiB。远端上传将内容暂存在远端浏览器内存中，再设置文件输入；不发送本机路径。文件输入接受后才能报告成功，不把文件传输等同于网站表单提交。

Chromium 宿主需要本机 Chrome、Edge 或 Chromium，或经 SSH 转发的回环 Chromium 调试端点。普通本机配置在明确检测到浏览器未安装时自动回退到系统 WebView；显式代理、远端端点和传输目标配置不自动回退，避免改变网络策略。启动失败、配置占用、连接失败均保留原错误和恢复入口。真实第三方登录、远端网络环境和其他系统需按实际环境验收。

自定义登录配置可在关闭全部页面与下载后确认删除，同时清理该配置的受管资料目录；默认与访客配置保留。删除意图先写入配置；移动或清理失败保留可见的待删除记录和受管恢复目录，可重试完成，待删除配置不能启动或编辑。下载文件由下载面板管理。默认与访客不占用 20 个自定义配置名额，旧的满额配置可继续编辑。

当前仍在实现完整范围中的 Windows 文件取回、托管分享适配等能力；不能以原型入口或合成 IPC 界面测试作为这些功能的验收证据。CLI 只补关键功能，使用说明单独维护于 [预览 CLI](../help/zh/reference/preview-cli.md)。

下载记录与文件分开管理：只可移除已完成或已取消的记录，保留磁盘文件；进行中或无法核验的活动下载必须先确认取消。控制连接失败时保留已知字节数并显示「无法核验」，不推断完成；收到后续进度事件后才恢复已核验状态。远端会话已可管理下载观察与取消；Windows 取回仍待实现和验收。

控制连接恢复由 `Browsers::reconnect` 统一提供给 GUI 和关键 CLI：通过同一已验证回环端点重新建立控制连接，确认原 target 仍属于当前隔离上下文，再恢复页面通道、画面流、设备尺寸和本地下载事件。不会创建页面、导航或重放输入；连接代次使旧快照、抓取和登录导入预览失效。断连画面明确标为最后画面并暂停输入；恢复前排队输入与迟到的剪贴板读取不继续发送。原页面/浏览进程已消失时不假装恢复成功，保留明确错误并提供显式重新打开。

显式重新打开使用同一逻辑页面 ID 和登录配置，先完成所有前置核验，再关闭旧 target，从最后核验地址创建替代页面。它不恢复旧表单或重放操作；本机持久资料由 Chromium 恢复，访客进程重启及丢失的远端隔离上下文需重新登录。进程／上下文丢失由库存观察确认，保留 `gone` 记录直到关闭或替换；站点主动关闭的独立弹窗仍正常移除，可从已关闭标签恢复。库存应用前核验观察时的页面指针和 target，旧轮询不能删除或覆盖新页面。关闭、重开共享 profile 操作租约，临时替代 target 不暴露为额外标签；满 12 个逻辑标签时允许一个受租约保护的替代位置。旧进程／上下文的活动下载标为已中断，移除记录不删除文件。新 target 在附加通道前即登记归属，初始化与清理同时失败时按原 ID 保留无法核验的替代对象，不自动重复创建。启动失败释放租约并保留可重试记录，修复可执行文件后可重试。

## 内容链接打开位置

预览设置可选择网页内容链接进入系统浏览器或预览模块，默认保留系统浏览器行为。终端普通 URL 与 OSC 8、共享 Markdown 阅读器、帮助外链以及预览 Markdown 的网页链接复用 `src/lib/openWebLink.ts`；HTTP／HTTPS 以外的地址不进入此路由。Shift + Ctrl/⌘ + 点击临时反转选择，终端链接需要 Ctrl/⌘ + 点击。终端普通点击保留选择和鼠标协议，打开链接的点击不投递给 PTY。

外部内容入口使用默认登录配置；预览内文档的网页链接传递当前配置。懒加载前最多暂存 12 个请求，重复 URL 可独立打开。设置读取或系统打开失败会显示错误，不静默改用其他目的地。授权文档的相对文件链接同样遵循此设置，并继续经过原生资源解析；认证、更新等明确的系统操作保持自身打开流程。

## 批注交付校验

复制单条／全部批注、导出及发送给 Agent 前，以捕获的标签和修订调用 `shared/verifyContext.ts`。网页／HTML 使用原生 `verify_revision` 主动核验，不依赖画面轮询是否已发现软导航或断连；异步返回后再检查标签是否关闭、编辑以及原生页面映射是否替换。Markdown 校验当前内存文档修订。截图复制同样在写剪贴板前复核。

带图片或大文本的 Agent 上下文打包前后各核验一次；等待期间锁定草稿和目标，防止重复提交。对话框关闭后未完成的核验不能继续发送。网页批注与截图导出携带原生页面和修订，保存对话框关闭后、写目标文件前再次核验；页面已变化或丢失时保留既有目标文件。取消选择不写入文件。

## 文件链接与锚点

`shared/documentLinks.ts` 统一预览 Markdown 中的网页链接和相对文件链接。系统目的地由原生 `resource_link` 校验现有目录授权后返回地址，不新增文档授权；模块目的地使用 `open_link` 打开 Markdown／HTML 标签，其他资源进入浏览标签，继承来源登录配置。相对路径、隐藏路径及符号链接仍复用原生文件访问边界；不接受任意 `file:` URL。源授权撤销或应用退出后，受限资源地址失效，不能作为公开分享链接。

文件树右键与编辑器的浏览器预览共用 `useWorktreeBrowserPreview`，集中处理未保存文档与重复打开；菜单只决定入口展示并呈现错误。`shared/preview-file-types.json` 是前后端文件类型、MIME 与渲染方式的共同来源。HTML／Markdown 保留编辑能力；图片、SVG、PDF、文本、音视频作为只读 `resource` 文档，经既有授权资源桥交由浏览器呈现，不进行 UTF-8 文本转换或保存。文件内容修订由有界流式摘要生成，沿用目录、隐藏路径与 16 MiB 边界；音视频解码与 PDF 显示取决于运行的浏览器。

两种目的地都保留查询参数及锚点，路径中的字面百分号、空格和井号按文件名编码。Markdown 标签只在首次可见时跳转到传入锚点，切换标签不重复重置阅读位置。普通文件阅读器复用 `MarkdownLink` 的网页策略；缺少已验证目录上下文的相对文件链接保持不可点击，用户可显式将文档交给预览模块。系统浏览器按自身文件格式支持呈现资源，可能将 Markdown 显示为源文；GFM 阅读与源码功能由预览模块提供。

## 自有进程退出后的后台回收

浏览宿主的既有维护线程在预览模块隐藏时继续检查自有子进程是否已退出，不新增 UI 轮询或远端 CDP 探测。确认退出后，在下载事务与全局状态一致的边界内保留逻辑标签、owner、最后地址和「已丢失」状态，将活动下载标为已中断，再移除退出的运行时和进程引用。自有临时资料目录随最后引用释放而清理，持久资料目录保持可复用；已完成的下载记录和文件不删除。普通帧与缓存对话框均不能将已丢失页面恢复成可用画面。

回收前比对实际进程对象身份，跳过同配置的启动、重新打开和目标附加事务，旧退出观察不能回收替代进程。运行时、控制连接和临时目录的析构位于共享状态锁外。远端或外部浏览器没有自有子进程，不因控制断连而推断其已退出；其会话处置仍使用已有显式关闭与恢复流程。

原生回归 `background_reaping_clears_guest_data_keeps_recoverable_tabs_and_preserves_persistent_profiles` 在不调用帧或列表轮询的等待阶段验证后台清理，随后验证故障标签恢复、访客数据与未提交表单不重放、持久目录保留及下载中断。该测试需要安装 Chromium 并显式使用 `--ignored` 执行；普通测试覆盖启动／恢复／下载事务保护和过期进程观察。

## 远端下载归属

远端配置可填写浏览器可写的绝对下载根目录（POSIX 或 Windows 盘符形式），本机不解析服务器上的真实路径。每次运行时在根目录下使用随机独立子目录，以 `allowAndName` 按下载 GUID 保存；`Browser.setDownloadBehavior` 仅作用于应用创建的隔离上下文。缺少目录时保持远端下载管理未启用，旧配置不自动改变默认上下文行为。

下载开始事件必须核验 frame 所属上下文，子 frame 通过应用自身临时 CDP 会话读取 frame tree，随后解除自己的附加。外部上下文事件不进入记录；无法确认归属时有界保留事件并标为无法核验。取消绑定记录的运行时身份及上下文 ID，旧记录不能取消替代会话中的下载。进度只接受已知协议状态，不把未知值当作完成。

界面和关键 CLI 区分宿主来源与本机文件可用性。远端 `completed` 是浏览器报告的状态，不等同于实际文件已传输、仍然存在或可在本机打开；当前不提供虚假的本机打开入口。本次 Chromium 资源流实验对 `Network.loadNetworkResource` 的 `file:` 请求返回 `Unsupported URL scheme`，当前没有把该接口视为文件取回能力，取回需独立传输适配器。协议依据：[Browser 下载行为与取消](https://chromedevtools.github.io/devtools-protocol/tot/Browser/)、[Network 资源加载](https://chromedevtools.github.io/devtools-protocol/tot/Network/)。

远端下载取回复用 `download_transfer` core，GUI 与认证 CLI broker 使用相同的有界后台作业。状态独立于 CDP 事件快照，避免慢轮询覆盖传输进度或已发布的本机路径。每次最多两个作业、512 MiB/文件、五分钟；取消信号交给共享进程执行器，Unix 进程组只清理本次任务及其 SSH 子进程。源文件由已核实的远端下载事件绑定，SFTP 仅访问该记录中的唯一下载路径。OpenSSH 主机别名沿用现有配置，不保存认证材料、跳过主机校验或提供任意远端文件读取接口。目前本机取回支持 macOS / Linux，Windows 的进程树回收与原生取回待单独实现和验收。

远端配置的代理在创建隔离 BrowserContext 时通过 CDP `proxyServer` / `proxyBypassList` 设置，恢复已丢失上下文也使用同一策略。未配置代理时沿用远端浏览器默认网络；显式代理包含 loopback 请求，不静默退回直连。代理地址中的 `127.0.0.1` 指远端 Chromium 所在主机，HTTP / WebSocket 请求也由该宿主发起；HTTP 代理接收目标主机名，SOCKS5 的 DNS 行为由 Chromium 与代理实现决定。控制通道始终使用独立回环端点，不跟随页面代理。此策略不提供本机渲染与远端网络的自动切换，该完整选择能力仍需独立完成。

远端 HTML 资源通过自有页面的 CDP Fetch 请求阶段返回：只匹配文档能力域名 `*.agent-hub.localhost`，每次读取重新核验 UUID 授权、真实路径、隐藏文件及 16 MiB 上限；普通网络请求仍由远端浏览器处理。该域名在远端作为虚拟资源命名空间，URL 端口不要求服务器能连接到客户端；它不是公共分享地址。已附加页面与显式重新连接共用初始化，恢复后继续校验现有授权。配置 SSH 主机后，文档地址通过受管反向转发在首次导航前映射至服务器端口，popup 不依赖库存附加来读取初始资源；未配置 SSH 的远端本地文档 popup 仍不保证首次加载。原始 HTTP 资源服务与 CDP 共用有界读取，撤销授权后后续请求返回 404。已加载的 DOM、图片及浏览器内存内容不会因撤销而被远程擦除；没有任意本机文件路径接口。当前资源桥覆盖页面发起的文档和相对 CSS、JS、图片、fetch 请求，独立 Worker / Service Worker 会话的资源路径仍需另行验证。

资源桥为每个附加的远端页面持有独立 Fetch 控制连接与有超时的后台工作线程，按既有页面数量限制约束；即使预览隐藏，也不依赖帧轮询来解除资源请求暂停。页面关闭或传输替换时关闭该连接并回收自有线程，不读写浏览器默认上下文，也不接管日常浏览器。资源连接丢失时页面操作返回需要重新连接的错误，不能将停滞的资源状态当作已加载。

macOS / Linux 的远端配置可复用 SSH 主机设置建立文档反向转发。仅应用登记的文档服务端口可作为转发目标，URL 仍需当前有效授权；每个浏览运行时最多一条专属 SSH master，远端请求绑定 `127.0.0.1` 的动态端口。转发控制命令不读取用户 SSH 配置，因此不会重放配置中的其他转发；master 沿用现有主机别名、密钥和严格主机校验，禁用后台派生及 ControlPersist。关闭运行时回收 master、进程组和控制 socket。SSH 中断后要求关闭该配置页面并重新打开，不将旧端口当作仍然可用。服务器须允许反向转发并使用 `GatewayPorts no` 或 `clientspecified`；服务器策略最终决定监听范围，授权文档地址不是公共托管链接。

文档能力域名是受控资源的例外：配置代理时，`*.agent-hub.localhost` 走文档通道，不经过普通页面代理；普通 HTTP、WebSocket 和 loopback 仍使用既有代理规则。独立 Worker / Service Worker 以及 Windows 的 SSH 转发仍需原生验收；未配置 SSH 的直接页面资源桥继续可用，不声称其具备弹窗首导航保障。

慢 SSH 初始化在专属门内串行，运行时和共享状态锁在握手期间释放；退出取消半成连接，安装前重新核验授权及运行时身份。导航等待期间若用户已导航、停止或重连，旧请求不再执行；系统浏览器打开能力地址时，通过现有授权解析器重新生成客户端服务地址，不直接打开远端转发端口。

## 渲染与网络位置

`execution` 是创建运行时时从已校验配置捕获的只读快照，由页面库存及普通／对话框帧返回；前端不使用可变配置列表重新猜测活动页面位置。`render: client` 表示应用管理的本机 Chromium，`server` 表示配置的外部调试内核（可以是经 SSH 接入的服务器，也可以是外部本机实例，不构成物理主机身份认证）。网络路径区分 `client_default`、`server_default`、`proxy`；默认网络可能继承宿主系统代理，不能把它标成已证明的直连。`proxy` 表示显式配置的代理路径，不对代理服务器的物理位置或 DNS 行为作额外推断。

设置中可分别选择渲染与网络路径，仍以兼容的 endpoint/proxy 字段持久化；本机内核可连接已经建立的远端 HTTP/SOCKS5 代理，外部内核也可使用代理。选择另一配置会在新标签打开当前地址，保留原页面、表单、批注和连接；Markdown 使用独立本机渲染器，禁用浏览器配置切换。执行位置不随会话元数据保存，重启后等待当前帧核验。自动管理 SSH 网络代理、SOCKS5 DNS 宿主与断线恢复的完整验收仍在原需求范围，不能以 HTTP 代理验证代替。

跨配置打开授权 HTML 时，先验证能力标识与资源路径，再把旧渲染主机端口归一化为登记的客户端文档服务；外部内核按自己的转发重新映射。输入 URL 中的端口不会被用作新的客户端转发目的地，查询和片段保持不变。关闭历史恢复和删除配置重置也会丢弃执行位置快照，等待新帧。

## 预览到 Herdr 的交付确认

原型与正式界面均按 Herdr 会话 → 工作空间 → 具体 Agent 选择目标；原型只使用合成数据和沙盒日志。正式模块经 Herdr 模块 API 发现会话，仅查询选中会话的快照，不启动服务。切换上级目标或刷新时清空下级选择，丢弃旧请求的响应；未安装、无运行会话、空工作空间和无 Agent 分别显示处理说明。

交付确认保存当前页面和修订的快照，展示页面地址、批注、元素截图及其坐标和尺寸，明确会话、目录、Agent 与窗格。用户可编辑完整上下文；有截图或 UTF-8 文本超过 32 KiB 时沿用反馈包。投递复用 `herdr_action` 的身份、就绪及前台进程校验，按当前 Herdr CLI 的位置参数传递提示词。失败保留草稿，不自动重试；结果不明时先检查目标终端。成功只表示已经发送，Agent 完成修改后由用户刷新预览检查结果。

标签栏统一从「+」菜单新建普通或访客网页；右侧检查栏复用 `ResizableSidebar`，从左边界拖动，支持缩放、键盘、双击复位与本机宽度记忆。窄屏和底部批注模式沿用纵向布局。

开发重启时，停止脚本同时回收已识别桌面进程直属、带受管 headless／动态 CDP 端口参数的浏览器及其辅助进程，避免默认配置被孤儿进程锁定；不遍历桌面终端 Agent 或普通浏览器。Chromium 因配置占用返回退出码 21 时，界面显示明确的占用说明，保留登录数据和配置目录。对既有孤儿进程的恢复须先核实父进程、可执行文件和配置目录，不以删除锁文件或清空配置替代进程归属确认。

## 独立渲染后端

`BrowserSurface` 作为选择层，不承担任何渲染传输。Chromium 后端使用 `preview_request`、core 浏览器页标识与 CDP；Native 后端使用 `preview_native_open/update/action` 和单独的 WebView 标识，互不导入对方运行时、帧模型或登录配置。两者仅共享 URL 安全策略和宿主层导航契约，切换配置另开标签，不迁移活动表单或冒充同一浏览器会话。

系统后端通过 Tauri child WebView 直接显示网页，当前以 `unstable` 子 WebView API 集成，不需要本地 HTTP 业务服务器。macOS 适配使用 WKWebView 回调取数和实际页面截图，支持元素选取、批注、视口／区域／有界整页截图、页面表达式、元素快照引用和 Agent 交付；导航与截图前后即时校验修订。整页截图采用有界滚动分块并恢复滚动位置，固定／粘性元素可能在不同分块重复出现，不能宣称与 Chromium 单次整页捕获完全一致。

原生登录导入复用共享 Cookie 规范化、域名选择、预览过期和修订校验，支持粘贴、文件与显式 Chrome/Edge 调试端点；凭据值留在 Rust 中，可选应用来源 UA。WebKit 直接设置 Cookie，保留 host-only 与 domain 的区别；当前只提供合并，不在无法完整表达分区状态时替换 Cookie。失败尝试恢复原 Cookie，无法核实时报告结果不明，不自动重试。UA 可在关于面板查看、编辑或恢复系统默认，设置应用至当前页和之后创建的原生页面，不表示整个浏览器指纹得到复制。

原生真实运行验收使用独立临时下载目录、隐身 WebView 与本机合成站点，不读取用户浏览器或原生登录资料：

```bash
cargo test --manifest-path src-tauri/Cargo.toml --test native_preview_runtime -- --ignored
```

该用例拥有独立的原生 GUI 事件循环，仅显式传入 `--ignored` 时打开测试窗口；普通测试构建它但不自动打开窗口。覆盖语义快照、Shadow DOM、同源 iframe、引用读取与点击填写、失效及只读保护、Cookie、存储、主题、实际截图、键盘复制、截图降级、视口及原生下载。

原生资料使用独立目录及 WebKit 数据存储标识。macOS 14 及以上使用持久配置；更早系统保留临时资料模式。Windows/Linux 已接入查询、截图、UA 和主题适配，Cookie 导入仍返回明确的不支持状态。三平台运行结果由手动 `Native Preview` GitHub Actions 验证，Linux 使用 Xvfb；未通过云端运行前不能宣称平台验收完成。原生未提供 CDP，现有外部 CLI broker 仍只管理 Chromium 页面；Tauri 内的原生自动化接口与 CLI 接入范围必须区分。

NativeSurface 按实际视口坐标更新子视图，切换标签、隐藏页面或打开菜单／模态框时隐藏子视图，关闭及异步创建取消时回收。权限从窗口级收紧为 main WebView 级；应用 command handler 拒绝所有非 main WebView，网页不能借同窗口继承文件、Shell 或业务 IPC。Native 命令再次校验调用者、目标归属、URL 与有限布局范围。跨平台 UI 尚需 Windows/Linux 原生验收，不能由 macOS 的验证推出等价行为。

## Chromium 帧接收与缓存

每页为 screencast 持有独立 WebSocket 与接收线程，控制命令仍使用原有连接。接收线程持续处理帧，最多保留一个最新 JPEG，并在约 33ms 的预算内 ACK；没有读取者两秒后发送 stopScreencast，读取恢复后重新启动，关闭页面时关闭套接字并 join 线程。不会因 UI 停止取帧积压无界图像，也不关闭页面、下载或 Agent。

桌面帧读取采用 quick 模式：页面信息与 history 缓存最多 500ms，导航、尺寸变化、重连与重开立即失效；CLI 默认保留完整查询。修改前每次读取均查询身份、DOM metadata 和 history；验证用同一静态页面各读取 20 次，全量 22.599ms，缓存 122.625µs，缓存分支控制查询为零。此结果只说明该环境下的查询成本，不代表 FPS 或端到端延迟。

画面仍通过有版本的 base64 JSON 返回，前端保留单次在途请求，并按新画面／近期操作约 33ms、静态约 100ms 调度；后台不取帧。二进制传输、全事件驱动控制连接和异步图片解码不属于本次已实现范围。所有元素操作、截图与交付前的目标／修订核验继续走即时查询，不能以 metadata 缓存替代。

## 独立交付与系统权限

预览作为独立业务模块拥有标签、浏览配置、批注及页面生命周期，不依赖活动项目。`lib/agentDelivery.ts` 定义投递端口，工作台组合层注入 Herdr 实现；目标选择与发送留在 `features/herdr`，预览不导入 Herdr 内部 API。项目文件通过授权文档入口进入预览，Herdr 通过同一端口接收反馈包，两者不成为网页打开的前置条件。

设置的权限引导仅调用只读授权查询及固定的系统设置入口，不自动申请或修改授权、不扫描受保护目录探测权限。无法查询的完整磁盘与文件夹授权显示需在系统设置确认；辅助功能及录屏按实际工具用途标为可选。网页 DOM 操作和 WebKit/Chromium 页面截图不依赖桌面录屏或辅助功能授权。

原生子 WebView 改变了 Tauri 的单 WebviewWindow 假设。终端、Herdr 与任务命令按调用 WebView 取身份；布局、托盘恢复、隐藏与退出按 Window 操作。回归测试在同一窗口建立主 WebView 和原生子视图，验证主界面终端 IPC 可用、预览页面仍被全局命令守卫拒绝。

文件树及源文件工具栏发起的预览留在项目工作区，在源文件后新增带「预览」标记的标签；相同工作树与路径复用已打开的标签，不切换到 `/preview`。工作区预览复用授权文档与 Markdown／浏览器渲染器，关闭标签或宿主退出时释放文档授权与浏览页面；源码草稿继续由既有编辑器管理。

工作区预览与独立浏览页共用完整 `PreviewWorkspace` 及功能菜单，工作区会话不读取或覆盖全局浏览标签，也不消费独立页面的打开请求。预览源码草稿在切换源文件、终端和工作树时保留，关闭前检查未保存修改；查找与 Markdown 截图按实际预览标签标识选择 DOM，避免误用隐藏预览。

网页主题由 `useBrowserTheme` 统一读取应用主题并发送 `set_theme` 动作：Chromium 使用原生媒体偏好模拟，macOS 系统 WebView 使用视图 appearance，Windows 使用 WebView2 profile 色彩偏好，Linux 使用 GTK 应用主题偏好；新页面、导航和应用主题切换均重新同步。默认空白页额外使用应用背景色，仅处理未编写内容的 `about:blank`；普通页面的配色仍由站点响应 `prefers-color-scheme`，不注入覆盖站点样式的通用 CSS。

原生云端验证使用固定提交、标准三平台 runner 和独立临时网页／下载目录，不发布安装包、不读取签名密钥。普通 Rust 测试只编译原生验收入口，必须显式传入 `--ignored` 才会执行真实 WebView 流程。

## 前端项目开发预览

工作树内的 HTML 右键预览先检查最近的 `package.json`。目前自动启动支持 `scripts.dev` 直接以 `vite` 开头的项目；其他 HTML 沿用静态文档预览。按进程工作目录、监听端口和 Vite 客户端响应识别已运行的开发服务，不按固定端口猜测项目。

没有运行服务时，按项目锁文件选择 npm、pnpm、Yarn 或 Bun，在新的内部终端标签执行 `dev`，显式绑定回环地址和独立端口。预览最多等待 30 秒，就绪后在当前工作区打开 HTTP 页面；启动失败保留终端输出。相同项目的并发启动请求合并。服务归属该终端标签，关闭标签、切换工作树或退出应用会释放自有 PTY；复用的外部服务不受影响。布局不保存启动意图，重启不自动重跑。Unix 上已运行服务的端口识别使用 `lsof`，Windows 使用 `netstat`。

GTK 应用偏好会影响主 WebView 的媒体查询。主题操作同时接收解析后的 `dark` 与可选 `system` 模式；跟随系统时撤销 GTK 应用覆盖，最后一个原生视图关闭时同样恢复。前端通过系统媒体偏好订阅更新解析主题，并以 `data-theme-mode` 区分颜色相同的模式切换；旧主题请求省略模式时继续按解析色执行。
