# 工作台排版

字体、字号和基础行高统一定义在 `src/styles/typography.css`。Tailwind 配置、CodeMirror 和终端均消费该文件的 CSS 变量；调整排版从此处修改，不在组件中新增像素字号或另一套字体栈。

| 内容                             | 工具类                | 默认字号 |
| -------------------------------- | --------------------- | -------- |
| 辅助文字、分组标题、数量、快捷键 | `text-xs`             | 12px     |
| 导航、树节点、表单、列表正文     | `text-sm`             | 13px     |
| 代码、终端                       | `font-mono text-code` | 14px     |
| 小标题                           | `text-lg`             | 16px     |
| 页面标题                         | `text-xl`             | 18px     |
| 文档章节标题                     | `text-2xl`            | 20px     |
| 文档大标题                       | `text-3xl`            | 24px     |

界面使用系统无衬线字体和系统中文回退，代码与终端使用随应用提供的 JetBrains Mono，并保留终端符号字体。编辑器关闭编程连字，便于辨认运算符；终端保持连续行网格，避免 TUI 框线断开。紧凑导航通过间距和行高控制密度，不再降低至 8–11px。

设置中的文字大小通过现有 `--app-scale` 对全界面统一缩放，不重复乘入字号。终端在创建时从样式变量读取数值选项，加载同一字号的字体后测量 PTY 网格。
