# Native terminal initial prompts

Research checked against primary documentation and source on 2026-11-04. `PROMPT` below is one argv element containing the complete task. Append arguments to the configured executable and existing flags unless the row explicitly requires a subcommand. Interactive modes require a real terminal; a visible terminal window alone does not change a CLI's batch mode into a chat session. These findings describe documented interfaces, not an installation or authentication test.

| Agent kind | Documented invocation                                                  | Mode and evidence                                                                                                                                                                                                                                                                                                                                                                                                          |
| ---------- | ---------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `claude`   | `claude PROMPT`                                                        | Interactive initial prompt; `-p` instead exits after answering. [CLI reference](https://code.claude.com/docs/en/cli-reference)                                                                                                                                                                                                                                                                                             |
| `cursor`   | `cursor-agent PROMPT` (legacy binary); current docs use `agent PROMPT` | Positional initial prompt is interactive. `-p` selects print mode. [Current overview](https://cursor.com/docs/cli/overview), [legacy official overview](https://docs.cursor.com/en/cli/overview)                                                                                                                                                                                                                           |
| `opencode` | `opencode --prompt PROMPT`                                             | Top-level TUI accepts `--prompt`; `opencode run PROMPT` is explicitly noninteractive. [CLI reference](https://opencode.ai/docs/cli/)                                                                                                                                                                                                                                                                                       |
| `copilot`  | `copilot -i PROMPT`                                                    | Interactive and automatically executes the prompt. Long spelling is `--interactive=PROMPT`, **not** `--prompt-interactive`. `-p` is programmatic and exits. [Command reference](https://docs.github.com/en/copilot/reference/copilot-cli-reference/cli-command-reference)                                                                                                                                                  |
| `gemini`   | `gemini --prompt-interactive PROMPT`                                   | Executes prompt and continues interactive; alias `-i`. `--prompt` is headless. [CLI reference](https://geminicli.com/docs/cli/cli-reference/)                                                                                                                                                                                                                                                                              |
| `kiro`     | `kiro-cli chat PROMPT`                                                 | `chat [OPTIONS] [INPUT]` starts interactive chat; input is the first question. Omit `--no-interactive`. Do not duplicate `chat` if already configured. [CLI commands](https://kiro.dev/docs/cli/reference/cli-commands/)                                                                                                                                                                                                   |
| `pi`       | `pi -- PROMPT`                                                         | Positional message provides initial prompt; terminal stdin and stdout select the TUI. `--` protects leading dashes and file-like text from option parsing. `--print` exits after answering. [Official CLI documentation](https://github.com/badlogic/pi-mono/blob/main/packages/coding-agent/docs/cli.md)                                                                                                                  |
| `omp`      | `omp -- PROMPT`                                                        | Official parser stores positional messages; main passes the initial message to the interactive session when print/output modes are absent. [Parser](https://github.com/can1357/oh-my-pi/blob/main/packages/coding-agent/src/cli/args.ts), [interactive dispatch](https://github.com/can1357/oh-my-pi/blob/main/packages/coding-agent/src/main.ts)                                                                          |
| `amp`      | `amp --execute PROMPT`                                                 | Verified argv interface is single turn then exit. Interactive first-message input is documented through stdin piping, not an argv flag; do not invent an interactive argv option. [Execute mode](https://ampcode.com/docs/cli/execute-mode), [interactive stdin](https://ampcode.com/docs/cli)                                                                                                                             |
| `droid`    | `droid PROMPT`                                                         | Starts REPL with initial prompt; `droid exec PROMPT` is single-shot. [Official CLI reference source](https://github.com/Factory-AI/factory/blob/main/docs/reference/cli-reference.mdx)                                                                                                                                                                                                                                     |
| `cline`    | `cline -i PROMPT`                                                      | Current official README explicitly documents interactive starting prompt. Positional alone is one-shot. The older reference page differs, so version capability matters. [Official CLI README](https://github.com/cline/cline/blob/main/apps/cli/README.md)                                                                                                                                                                |
| `kimi`     | `kimi --prompt PROMPT`                                                 | Current Kimi Code CLI reference explicitly describes single-prompt noninteractive stdout mode; it does not open the TUI. No compatible initial TUI prompt argv is established by this reference. Older `kimi-cli` releases may differ. [Command reference](https://www.kimi.com/code/docs/en/kimi-code-cli/reference/kimi-command)                                                                                         |
| `qodercli` | Current product: `qoder --prompt-interactive PROMPT`                   | Official current reference documents `qoder`, not the legacy executable `qodercli`. This proves the flag for current Qoder only; legacy binary compatibility requires its installed `--help`, and must not be inferred from third-party reports. Current positional prompt selects noninteractive mode. [CLI reference](https://docs.qoder.com/cli/cli-reference), [installation](https://docs.qoder.com/cli/installation) |
| `qwen`     | `qwen --prompt-interactive PROMPT`                                     | Starts interactive session with initial input; alias `-i`. Cannot combine with piped stdin. `--prompt` is noninteractive. [Configuration reference](https://qwenlm.github.io/qwen-code-docs/en/users/configuration/settings/)                                                                                                                                                                                              |
| `grok`     | `grok PROMPT`                                                          | The author-maintained `superagent-ai/grok-cli` README documents an opening positional message; `--prompt PROMPT` is explicitly headless and exits. This is a third-party Grok API client, distinct from xAI's `grok-build`; confirm the installed implementation. [Official project README](https://github.com/superagent-ai/grok-cli)                                                                                     |
| `kilo`     | `kilo run PROMPT`                                                      | Verified initial-task command is noninteractive; no initial TUI prompt argv was established in the bounded check. `--auto` additionally controls autonomous permission handling and should not be silently added. Docs apply to 1.0+. [CLI reference](https://kilo.ai/docs/code-with-ai/platforms/cli)                                                                                                                     |
| `agy`      | `agy -i PROMPT`                                                        | Google now documents a real CLI TUI and initial interactive prompt; `agy -p PROMPT` is batch. The repository's `antigravity .` default is an IDE launcher and is **not** equivalent to `agy`. Do not append these CLI flags to the IDE launcher. [Official getting started](https://antigravity.google/docs/getting-started?tab=cli)                                                                                       |

The unresolved compatibility cases are the legacy Qoder binary and identifying which Grok implementation is installed. Unknown commands should surface an actionable unsupported-command error rather than silently discard the task or substitute an unverified flag. CLI availability and credentials are separate from prompt syntax.
