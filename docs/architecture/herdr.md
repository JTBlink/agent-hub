# Herdr 集成模块

Herdr 定制逻辑集中在独立模块中。通用工作空间、任务、自动化和终端模块作为调用方，不各自实现 Herdr 会话、工作树或安装管理规则。

## 前端

入口目录为 `src/features/herdr/`：

| 位置          | 职责                                                                      |
| ------------- | ------------------------------------------------------------------------- |
| `api.ts`      | Herdr 功能使用的 API 入口，聚合控制、工具及终端挂接 bindings              |
| `components/` | 侧栏、工作空间行、工作树右键菜单、会话管理、Agent 操作与 Herdr 自动化配置 |
| `hooks/`      | 快照订阅、会话选择及项目与 Herdr workspace 联动                           |
| `lib/`        | 显式会话 IPC、工具安装与更新 IPC、Agent 定义、仓库分组与焦点解析          |
| `terminal/`   | Herdr PTY 客户端创建、挂接恢复、快捷启动及终端操作栏                      |

模块内部通过自身 `api.ts` 调用 Herdr 功能，不经应用级 `src/lib/tauri.ts` 反向引用自身。`tauri.ts` 保留现有导出兼容调用方，通用终端的 `terminalApi.ts` 将 Herdr 客户端创建委托给模块适配器。PTY 事件、写入、关闭与布局仍由通用终端模块统一管理。

侧栏名称保留 Herdr 原生 workspace label，不用目录 basename 覆盖用户命名；路径仅用于明确的项目关联。侧栏快照优先使用 Herdr 明确提供的工作树 checkout；没有工作树元数据且选中窗格位于仓库内时，保留该窗格目录。选中窗格在主目录等非仓库目录时，仅回退到同工作区中唯一可确认的仓库 checkout；多个仓库候选保持未解析，不按工作区名称猜路径。显示、打开与重新挂接共用此解析规则；实际 Agent 操作仍独立校验窗格和 Agent 身份。Git 分支与 HEAD 单独传递，游离状态统一按 `短提交号 (detached HEAD)` 显示，不翻译状态名称。

默认列表展示 Herdr 原生已打开的工作区和工作树。本机发现但尚未在 Herdr 打开的工作树放在独立折叠入口，展开时刷新 Git 数据，不混入原生工作区列表或数量；用户可从该入口显式打开工作树。

终端新建菜单的“打开 Herdr”与原生 Agent 入口同组，左侧显示 Herdr 图标，右侧默认 Agent 图标与设置按钮保持一致的视觉大小，二者默认隐藏，仅在整行悬浮或键盘选中时同时显示；设置按钮通过通用侧栏面板请求直接打开 Herdr 模块自己的设置视图，不触发启动或进入全局 Agent 设置页。工作台仅负责选择已注册的模块面板，设置视图及返回行为由 Herdr 模块持有；独立模块惰性加载时也保留本次打开意图。菜单图标与实际启动共用默认选择及已安装回退规则。该入口直接使用默认 Agent 配置，在当前项目／工作树目录新建原生 Herdr tab 并启动 Agent，不复用已有 Agent 窗格，也不弹出选择确认框；应用新建内部 tab 统一使用小写名称、连字符及编号（如 `claude-code-1`、`codex-1`、`shell-1`）；编号按当前 workspace 内同名 tab 的最大现有编号递增，旧的无编号自动名称占用第 1 号，不依赖本地计数器；目录使用解析后的 checkout，不能继承旧窗格的主目录；AgentHub 的工具栏、菜单和侧栏按 session 复用唯一的外层终端标签与 PTY，不以 workspace 或入口区分客户端；再次打开时合并旧的重复客户端，仅移除多余的客户端窗格，保留普通 Shell 分屏及其他 session，并显式聚焦新的原生 tab；保留已有终端名称，新客户端默认显示 `herdr-<session>`（例如 `herdr-default`），不附加 Agent 名称。创建原生 tab 后立即聚焦，并通过 IPC Channel 通知前端挂接；等待 Agent 就绪时释放全局操作锁，界面在创建完成后即可继续操作。启动完成只回报警告，不再次导航或抢焦点；旧请求的结果不能覆盖新请求。创建阶段防止重复请求，创建失败时在终端状态栏显示原因，不回退挂接旧窗格；已创建但启动状态不明的 tab 保留供检查。

普通左键选择已有 workspace 时保留最近窗格。侧栏根工作空间可拖拽排序，按 Herdr 会话在应用设置中保存根 workspace ID 顺序；筛选列表复用该顺序，新工作空间追加到末尾，子工作树始终随所属根工作空间整体移动。右键打开子工作树时传入当前项目、checkout 路径及父 workspace ID，使用 Herdr 原生 `worktree open --workspace <id> --path <path> --no-focus`，复用已有工作树并保留仓库分组。项目根菜单显示“打开项目”，子工作树显示“打开工作树”；主工作树不提供删除入口，锁定工作树可打开但不可删除。菜单按打开／系统文件管理器、复制路径／相对路径／名称／分支名和危险操作分组，右键不改变当前工作空间。系统文件管理器入口复用项目目录与工作树归属校验；目录不可用时禁用打开与删除，但保留已有信息的复制。相对路径以所属项目根目录为基准（项目根为 `.`），未登记项目以分组根目录为基准；无法计算相对路径时禁用该项。未知路径禁用路径复制，未知分支不显示分支复制。

### Agent 选择与启动

通用 `AgentSelect` 只负责图标与选择交互，预览交付与 Herdr 入口共用选项定义和安装证据。Herdr 启动选择弹窗、目录路由、工作空间及 Agent 复用位于模块内，通用标签栏通过 `@app/herdr` 消费组件和 hook；关闭功能时使用无 IPC、监听或定时器的空适配器。普通 Agent 菜单通过 native PTY 直接启动 CLI，不隐式进入 Herdr。

“打开 Herdr”在提交时读取默认 Agent，按当前项目与工作树核实目录，复用 `default` 会话中该目录的空间与同类 Agent；不存在时使用统一 `herdr_start_agent` 接口。启动指令来自统一配置，Claude Agent Teams 通过新窗格环境启用，配置不会污染其他 Agent。切换选择打开新标签，已有会话继续运行；结果不明时保留空间和窗格并显示反馈，不自动重试。目录、启动与复用规则不进入通用终端菜单。

Herdr 侧栏设置提供带图标的默认 Agent 选择和启动命令编辑，与总设置共享启动文档，修改仅影响后续启动。

### 焦点与设置

侧栏加载、刷新与普通项目／工作树导航默认只读取状态，不准备 Herdr 会话或调用工作空间聚焦。侧栏工作空间、打开当前项目和终端 Herdr 图标的显式点击保留准备、创建／复用与聚焦能力。

「更多 → 设置」使用共享 `SidebarSettingsPage` 填满原侧栏，顶部返回后保留原列表、筛选和滚动状态；开关复用 `ToggleSwitch`。`herdr_follow_project` 通过现有应用设置保存，缺失、无效或读取失败均按关闭处理，保存失败保留原值。开启后仅在 Herdr 侧栏打开、当前目录可用且选中原生 `default` 会话时跟随项目／工作树，快速导航合并为最新目标，同一目标的刷新或面板重开不重复聚焦；其他会话保持不变。取消后的旧响应不覆盖新目标，不自动重试结果不明的写操作。

启动恢复保留终端布局与名称，仅创建普通 Shell；保存的 Herdr 定位信息不自动重新挂接。用户手动点击侧栏目标或终端 Herdr 图标后再挂接并核验实时目标，Herdr daemon 与 Agent 生命周期不受影响。

## 后端

Tauri 适配集中在 `src-tauri/src/commands/herdr/`，核心实现集中在 `src-tauri/src/core/herdr/`：

- `client.rs`：各 Herdr 入口共用的显式会话命令、环境隔离与响应解析。
- `agent_execution.py`：受管理执行的 Herdr 专有布局、归属核验、观察与恢复，由 `core/agent_execution` 组织调用。
- `control/`：显式会话快照、目标身份与前台进程校验、workspace 打开、子工作树原生打开与确认删除。
- `agents/`：Herdr 中的原生 Agent 启动、环境隔离和就绪检查。
- `session/`：原生 `default` 会话准备与项目目录路由；仅在 crate 内可见。
- `tools/`：安装来源检测、下载、版本检查与更新。

`commands/terminal.rs`、任务启动及自动化代码调用这些领域能力。通用终端保留原子化的输入修订、Shell 就绪、前台所有权及 PTY 写入检查；Herdr 会话选择与命令构造由 Herdr 模块提供。项目与 checkout 归属、路径和文件操作继续复用 `project_worktrees`，不复制通用 Git 安全规则。

## 兼容性与验证

整理模块不改变 IPC 命令名、参数、持久化布局或会话生命周期。后端按层引用 `core::herdr::{control, agents, tools}`，不保留旧模块路径的平行实现。组件和单元测试随所属模块就近放置，跨模块 Rust 集成测试保留在 `src-tauri/tests/`，浏览器验收保留在 `tests/browser/`。

前端执行全量测试、Lint 和构建；后端执行全量测试、格式检查及严格 Clippy。工作树原生命令另在独立 Herdr 测试会话验证，不能对用户会话执行实验性删除或重启。
