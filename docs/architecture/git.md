# Git 模块

Git 是独立的工作台模块。页面入口为 `src/views/Git.tsx`，不经任务模块读取仓库或发起操作。宿主提供项目 ID、可选工作树路径和文件选择回调；Git 组件不拥有终端或任务的状态。

## 边界与数据流

- `src-tauri/src/core/project_git/`：Git 状态、历史、引用、提交检查与仓库操作。只读历史直接查询仓库对象，不使用工作区内容拼接提交差异。
- `src-tauri/src/commands/project_git.rs`：验证已登记项目／工作树作用域，在阻塞任务中调用 core。
- `src/lib/gitApi.ts`：Git IPC 契约与调用；UI 不直接拼装 Git 命令或访问目录。
- `src/hooks/useGitGraph.ts`：按项目、工作树和远程引用选项隔离请求。加载与刷新保留同一作用域的数据，失败保留列表并允许重试；旧作用域响应不得覆盖当前结果。
- `src/lib/gitGraph.ts`：纯拓扑布局，只接受 SHA 与父 SHA，不依赖 IPC、React 或提交说明。返回轨道和逐行连线，是替换图形算法的边界。
- `src/components/git/GitGraphTable.tsx`、`GitGraphLines.tsx`：表格和 SVG 渲染，只接收数据和选择回调；视口窗口由 `useGitGraphViewport.ts` 管理。
- `GitCommitDetails.tsx`、`GitCommitMetadata.tsx`：历史列表和 Graph 共用提交检查、完整元数据和文件树；不各自实现详情查询或差异计算。Graph 默认展开元数据，支持沿父提交继续检查。

## Graph 与详情约束

布局基于全部已加载提交计算，再对表格执行虚拟滚动；不得先裁剪提交再布局，否则可见区边缘会丢失合并关系。固定行高为 30 CSS 像素，跟随应用缩放；窗口前后保留额外行，空白占位保持滚动高度，表头与未提交行计入滚动定位。方向键、Home/End 可跨窗口定位提交。

当前 Graph 接口读取拓扑有序的历史前缀，默认 200 条、每次增加 200 条、上限 5000。加载更多仍会重新读取和布局整个前缀；这不是服务端游标分页。若后续改为分页，需设计引用快照和遍历状态，不能直接用易受并发提交影响的 offset 拼接历史。

远程分支来自本地缓存引用，Graph 查询不隐式联网。详情中的时间为提交者时间，以本机时区显示秒和时区。作者与提交者姓名、邮箱来自原始提交；逐文件增删统计相对第一父提交，初始提交相对空树，二进制文件无文本统计时不显示虚假行数。完整说明保留换行，包括正文与引用编号。

验证覆盖拓扑连线与前缀扩展、5000 条历史的 DOM 窗口和键盘跨窗口定位、异步作用域隔离、失败恢复、提交身份与逐文件统计。浏览器 fixture 入口：`tests/browser/git-history.html?graph`。
