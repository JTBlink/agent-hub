# 为未分组技能增加加入技能组入口

## Acceptance

- 卡片和列表均可将未分组技能加入已有技能组，不触发详情或部署操作。
- 已分组技能保留切换与移出操作；无组可选、等待、失败和成功有明确反馈。
- 更新技能列表与相关组成员，当前未分组视图能及时移除已分组技能。
- 键盘、焦点、三语文案与现有主题一致；回归测试覆盖实际页面入口与成员 API。

## Comments

- 复用 SkillGroupSwitchMenu 和已有成员更新回调；移除页面对未分组技能的隐藏条件，新增行为保留在共享组件内。

## Result

- [SkillGroupSwitchMenu](../../../src/components/SkillGroupSwitchMenu.tsx) 为未分组技能显示常驻“加入技能组”入口，选择已有组即可加入；已有技能保留切换和移出。复用三语成员文案，无组可选时提供创建提示，请求中防重复，失败可重试。
- [MySkills](../../../src/views/MySkills.tsx) 的卡片与列表复用同一入口，加入后等待技能和成员刷新；页面只调整组件连接并减少分支，新增展示行为集中在已有共享组件。
- 菜单支持方向键、Home、End、Tab 和 Escape，打开时聚焦首项、关闭时恢复焦点，操作有焦点环。菜单有高度限制和滚动；[文字缩放](../../../src/lib/textScale.ts) 提供当前缩放值，避免放大文字后菜单定位偏移。
- `npm test`：59 个文件、278 项测试通过；`npm run lint`、`npm run build` 通过。页面回归覆盖卡片和列表的成员 API、刷新及从未分组视图移除；组件回归覆盖三语、既有切换/移出、键盘、无组、失败重试、防重复和缩放定位。
- Chrome 本地合成数据页面复核深色卡片、浅色列表及 110% / 120% 文字缩放；菜单与入口对齐且无水平溢出，合成 IPC 的加入操作将未分组数量从 12 更新为 11。临时页面和测试标签已清理；未操作真实技能数据。
- Standards：复用成员 API、既有组件、语义主题和 i18n，不修改部署、Rust 或存储契约。Spec：未分组技能可直接选择目标组，成功刷新当前视图；原技能组切换/移出继续可用。
- 未进行原生桌面人工点击、窄窗口或 Windows/Linux 宿主验收。
