# 项目技能卡片窄宽度布局

项目卡片底部同时展示同步状态、技能组和多个 Agent 操作时，应保持状态标签横排。

- 状态与停用标签不可按字符换行，空间不足时整体标签换行。
- 技能组名称截断并提供完整名称提示，图标不压缩。
- 标签区和操作区空间不足时分行，操作区保持靠右并允许扩展 Agent 图标换行。
- 网格与列表复用相同标签展示组件。

- 网格卡片的上传、更新和重置按钮移到标题右侧，组成同步工具栏；底部仅保留状态、技能组、Agent、启停和删除。
- 同步工具栏在有可用操作时始终可见，提供键盘焦点、加载反馈与操作名称；多选模式隐藏操作。
- 网格和列表复用同步按钮，按状态保留相同操作方向。

- 卡片和列表的 Agent 快捷图标仅展示本机检测到安装的目标；即使已存在团队副本，未安装或未知目标也不展示、不计入展开数量。
- 已安装但个人停用的 Agent 仍可展示；检测尚未返回时不使用默认目标冒充安装结果。团队部署目标选择保持现有范围。
