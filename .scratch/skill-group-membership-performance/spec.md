# 技能组成员操作性能

加入或移出技能组仅改变成员关系，不改变技能内容、部署目标或项目同步状态。

- 单项操作只持久化当前组的元数据；元数据未初始化时生成完整可恢复快照。
- 批量操作一次 IPC、一次仓库锁、一次数据库事务和一次元数据导出；无效成员导致整批数据库回滚。
- 成员更新后只回读成员 ID，更新界面名单、组计数和待备份提示，不重新解析全部 Skill 或扫描项目、备份内容。
- 成员写入的文件监听回声被局部抑制；保留外部文件变更通知及自动备份通知，托盘刷新合并触发。
- 保留排序、Agent 开关、其它组与完整元数据重建兼容性。
