# 项目变体上传目标说明

多变体上传确认弹窗显示所选版本对应的目标中心技能及目标技能组。

- 选择不同 Agent 版本时，目标说明跟随其中心技能 ID 更新。
- 匹配已有中心技能时，展示中心技能名和现有技能组，明确更新保留原组。
- 没有中心匹配时，展示新建技能并保存到“未分组”；已有中心技能无成员关系时显示“未分组”。
- 默认技能组名称沿用界面语言；关联数据缺失时显示信息暂不可用，避免误报未分组。
- 上传确认支持选择已有技能组或“未分组”。已有中心技能默认选中原组，新技能默认未分组；显式选择的组在切换版本时保持。
- 确认后按上传返回的中心技能 ID 保存成员关系，再同步项目变体。选择新组会移出原组，选择未分组会移除原成员关系。
- 上传失败不改分组；上传成功但分组失败时明确告知部分完成，并停止后续变体覆盖。

- 分组选择使用应用主题菜单，背景不透明，显示当前选中项，限制列表高度并支持滚动、键盘上下选择、Escape 和点击外部关闭。
