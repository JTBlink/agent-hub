# 切换技能组时重置筛选

## Comments

- 用户反馈切换技能组后仍沿用“未部署”等旧条件，导致有成员的技能组显示为空；要求切换时重置筛选，并明确要求提交和推送本地所有改动。
- 组间、技能库与未分组视图切换清空搜索、来源、标签、未分组条件和部署状态；进入技能组恢复“已添加”，进入全库或未分组恢复“全部”。同一组数据刷新保留用户选择，工作台初次进入未部署列表仍保留入口筛选。
- 部署状态查询清理保留其他 URL 参数；重置在新组首次可见渲染前生效，同时数据刷新不会把旧标签重新写回。

- [行为回归](../../../src/hooks/useSkillLibraryFilters.test.tsx) 3 项覆盖组间切换、全库与未分组切换、同时刷新防旧标签回写、URL 清理、直接未部署入口和同组刷新。
