# 部署筛选与移除弹窗

## Comments

- 用户提供技能库截图要求合理增加未部署筛选，明确要求删除工作台未部署弹窗。采用 ui-ux-pro-max 的筛选标签换行、原位展开和可见状态建议，保持现有品牌主题。
- 筛选组件与派生逻辑从历史超大页面抽出，不变更后端或部署语义。

## Result

- 技能库默认单行显示技能组“已添加 / 全部 / 待添加”，部署状态、来源与标签收进“更多筛选”；折叠时显示生效的高级筛选数量，保留结果数量与清除入口，标签可原位展开且选中标签始终可见。
- 移除未部署弹窗；工作台入口直接打开全库未部署列表。修复全库选择被默认技能组回退覆盖的问题，侧栏库入口可返回全库并在刷新和重启后保持选择。
- 筛选与排序派生规则抽入纯函数，状态抽入 hook，展示抽入独立组件；URL 保留部署状态，变化时清理隐藏的多选项，部署刷新自动更新结果。全库卡片去除无效拖拽的禁用语义，不再错误禁用内部部署按钮。
- 三语文案、CHANGELOG 和合成数据预览已同步。
- 独立快照（排除工作区另一项并行的项目共享修改）：`npm test` 46 文件、201 项通过；`npm run build`、`npm run lint` 通过。工作区全量曾因并行项目共享修改尚未补齐文案而有 3 项失败，本任务使用独立快照复核。
- Chrome 合成数据预览检查：深色中文单行筛选、浅色英文 1.2 倍字号、全库未部署入口与返回技能组、折叠后的筛选数量可见。未执行 Tauri 原生、窄窗口与真实部署写入验收；部署接口未改动。
- Standards：沿用品牌 token、领域 DTO 和部署语义；新增纯函数与组件承接历史页面的筛选职责，不变更 IPC、数据库或文件系统。筛选 hook 统一管理各维度和重置生命周期，面板保留组合 JSX，避免拆成透传状态的碎片组件；长函数只组合相关状态和展示，纯规则已独立拆分。
- Spec：默认显示技能组并折叠部署状态，移除独立列表弹窗；组合筛选、零结果恢复、刷新数量、收起保留标签、隐藏多选项清理与全库范围均有行为测试。
