# 技能库部署筛选与布局优化

用户要求合理添加未部署筛选，并移除工作台未部署列表弹窗。沿用现有桌面工作台主题、搜索、详情与多选部署操作。

## 验收

- 工作台未部署入口直接进入技能库未部署列表，覆盖全库，不受上次技能组或未分组选择限制；零数量禁用。
- 技能库部署状态包含全部、已部署、未部署；以现有 targets 是否为空判断，与工作台一致。
- 部署筛选与搜索、来源、标签、技能组成员筛选组合，数量反映其他维度的筛选结果；部署状态持于 URL，返回导航可恢复。
- 搜索与操作工具栏保持分离；默认单行展示部署状态、结果数量和更多筛选，展开后展示技能组、来源、标签；折叠时显示生效筛选数量，清除可见。
- 标签超过六个可原位展开，选中标签始终可见；键盘可达，状态语义明确，支持主题、缩放和窄窗口。
- 部署数据刷新自动更新列表、数量；筛选切换清理隐藏的多选项，清除筛选可恢复列表。
- 三语文案、CHANGELOG、回归测试及验证结果同步。
