# 本地改动审查与优化

检查当前未提交的技能部署、技能组提示、项目目录快捷入口和开发启动改动，保留功能意图并修正接口、错误语义与代码复用问题。

- 单技能部署默认保护未托管内容，冲突返回结构化信息；显式覆盖采用现有替换策略，并维护来源引用。
- 技能组只把目标冲突报告为跳过，其余错误保持失败语义。
- 项目页复用目录操作组件，支持目录和 VS Code 快捷入口、打开错误提示与无障碍标签。
- 开发端口清理仅匹配监听进程。
- 新增覆盖确认弹窗拆到独立组件，覆盖失败时显示错误并保留弹窗。
- 补充相关回归测试，运行前后端检查。

## 批量错误展示补充

跳过多个操作时必须逐项展示所有 Skill 名称、Agent 与完整原因，不能只保留第一条。长路径支持换行与滚动，并能复制；Toast 提供详情入口。

## 冲突覆盖入口

全局与龙虾 Agent 的技能组操作详情为每条目标冲突提供“覆盖”入口，显式替换对应 Skill-Agent 的现有内容。普通失败不提供覆盖。覆盖成功刷新列表并标记已覆盖；失败允许重试，执行期间禁用重复操作和弹窗关闭。
