# 官网链接

设置页“官网”按钮打开 `https://jtblink.github.io/agent-hub/`。集中维护官网地址，README 与 package.json 的现有正确地址继续一致。

## 帮助与更新日志

官网主导航和页脚增加“帮助”与“更新日志”，首屏文档操作统一称“帮助中心”。帮助指向现有中文帮助站，日志正文从 CHANGELOG.md 生成到帮助站的独立网页，保持官网内阅读、版本章节与未发布状态。帮助站导航三语同步，日志中文正文提供回退说明。发布使用既有 Pages 工作流。

顶部“下载”和首屏“下载 AgentHub”直接打开 `https://github.com/JTBlink/agent-hub/releases`，不再跳转页内下载区域；保留下载区域的平台说明。
