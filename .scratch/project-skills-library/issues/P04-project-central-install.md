# 以项目中央仓库统一安装并兼容已有技能

## Scope

参考本地 `skills` CLI 的 `installer.ts`，以 `.agents/skills` 保存项目实际内容；安装先复用项目中央版本，再建立 Agent 入口，不依赖个人库链接。兼容既有中央内容、旧个人链接和 `npx skills` 的项目相对链接，保护项目修改与未托管路径。用户已授权完成后提交、push。

## Acceptance

- 已有中央实际内容不同于个人版本时，保留项目版本并从它部署 Agent 入口。
- 当前技能源对应的旧中央个人链接可安全转换为项目实际内容，不修改或删除个人技能源；不接管其他外部链接和链接祖先。
- 专属入口优先使用项目内相对链接，无法创建时回退副本；更新、修复、启停、移除及失败恢复都保护中央内容和外部修改。
- 项目实际内容和入口可通过 Git clone 独立使用；全局及链接工作空间不受影响。
- 批量项目安装按技能一次发布到多个 Agent，避免中央冲突按 Agent 重复执行。
- 提交前前后端行为回归、格式、构建及严格静态检查通过。

## Comments

- 实际只读诊断确认旧中央目录可能是个人库链接或未登记的项目实际内容；原安装校验分别产生路径越界和未托管内容冲突。
- 与原 ADR-0010 的专属目录默认副本策略区别：新入口采用相对链接优先，旧复制入口保留；团队不需要 AgentHub，管理清单依旧可选共享。

## Result

- 状态、事务和恢复分别校验中央内容与链接文本；覆盖更新、刷新、整体与单入口启停、移除及断链备份恢复。项目安装按 Skill 一次发布全部缺失 Agent，前端回归验证不按 Agent 重复调用。
