# 未添加的 Agent 不显示技能异常提示

## Scope

用户明确指出灰色 Agent 本来就未添加，这属于正常状态。历史清单不能作为入口必须存在的依据；没有实际入口时不显示异常提示，也不通过刷新自动补齐。只诊断已存在入口的链接、方式与内容差异。

## Acceptance

- 未添加的灰色 Agent 不显示“缺失”“找不到此技能”及重新添加提示，即使历史清单仍记录着它。
- 刷新项目内容或恢复其他 Agent 时不自动生成不存在的入口；显式添加只部署选中的 Agent。
- 已存在入口的链接或副本差异仍逐 Agent 提示，并说明当前项目内容与独立修改保护。
- 简体中文、繁体中文和英文保持一致；卡片与列表共用展示。
- 确认主动移除会清除目标记录，不再产生异常，也不会被恢复操作重新添加。

## Comments

- 原触发条件是历史清单记录了目标，但该目标文件不存在；这与卡片根据实际扫描显示灰色的规则不一致。此前只调整文案不足以修正该问题，用户进一步明确未添加属于正常状态。
- 状态只读检查实际入口；不存在的入口跳过诊断。更新已有入口时跳过不存在的路径，显式添加仍可重新部署。保留历史记录、实际项目内容和用户选择，不做批量迁移。
