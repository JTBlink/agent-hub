# 用明确文案解释 Agent 技能文件缺失

## Scope

用户无法理解“Agent 入口与项目技能不一致”“入口缺失，需要重新生成”。说明项目技能内容仍然保留，具体缺少的是各 Agent 的技能文件或链接，并明确恢复操作的效果。

## Acceptance

- 全部异常均为缺失时显示“部分 Agent 找不到此技能”，操作显示“重新添加到 Agent”。
- 详情说明项目内容仍保留，并逐 Agent 解释实际问题；其他差异使用“恢复 Agent 技能”，避免单用“入口”术语。
- 简体中文、繁体中文和英文保持一致；卡片与列表共用展示。
- 确认主动移除会清除目标记录，不再报告缺失，也不会被恢复操作重新添加。

## Comments

- 状态由管理清单中的目标与实际文件对比生成；未选择的 Agent 不会产生缺失警告。当前项目清单的目标已为空，真实专属目录也为空，不能将此前的提示直接判定为新的移除缺陷。
- 不改变实际项目内容、Agent 选择或恢复行为。
