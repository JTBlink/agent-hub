# 项目共享说明折叠及技能卡片刷新状态

## Scope

项目顶部的共享说明默认折叠为一行，展开后显示共享路径、忽略诊断和可选管理清单。技能的项目内容变化、团队入口需要刷新及操作入口移到对应技能卡片与列表行。需要更新或刷新的技能优先排序，不改变现有核心刷新和修改保护规则。

## Acceptance

- 顶部默认只有一行共享摘要，支持键盘展开；必要 Git 忽略风险在摘要可见，展开后可查看路径及建议。
- 摘要展示警告及错误数量，标题按警告/错误着色，错误优先；展开后路径、忽略详情及管理清单直接显示，不再二次折叠。
- 顶部不再逐技能列出刷新提示和按钮；卡片及列表都展示对应技能的状态和刷新入口。
- 按技能目录关联状态，不以展示名称关联，避免同名技能混淆。
- 需要更新或刷新的技能排在普通技能之前，同优先级保留原有状态和名称顺序；刷新后更新状态和排序。
- 请求中阻止重复刷新，失败可重试；切换项目后旧响应不能影响当前项目。
- 保留筛选、选择、详情、同步及原生入口功能，三语文案同步。

## Comments

- 用户要求逐技能刷新信息放到对应卡片，需要更新的技能前置，并提供截图要求顶部提示折叠为一行。
- 项目页面已超过体量规范，本次抽出技能集合展示与项目技能库状态请求，避免继续堆积页面职责。
