# 统一默认部署方式并解释项目入口异常

## Scope

设置中合并全局与链接工作空间的部署选项，普通项目的新 Agent 入口也采用统一默认值。项目中央内容始终保存实际文件。提供入口异常原因及明确的修复操作，保护已有入口方式、团队版本与本地修改。

## Acceptance

- 设置仅显示“默认部署方式”的符号链接与文件复制选项；新安装读取同一偏好。
- 全局与链接工作空间的链接指向个人技能库；普通项目入口采用指向项目 `.agents/skills` 的相对链接。
- 未选择统一设置时保留旧范围偏好；冲突在界面解释，不自动写入或迁移。
- 已有入口保留原方式；项目单次复制选项覆盖默认值；省略选项时采用默认值。
- 未添加的灰色 Agent 不提示缺失；已有入口记录为链接但变成副本、链接目标异常及内容差异分别显示 Agent、原因与路径，操作说明只恢复已添加 Agent 的技能。最新状态规则见 [B04](B04-clear-agent-skill-status.md)。
- 内容相同的链接替换副本可安全修复，独立修改与外部链接来源保留；覆盖相关回归与失败交互。

## Comments

- 用户反馈同项目技能有目录和链接混用。只读检查发现一个入口实际为目录、记录为链接且内容相同，另一入口正常。该状态是记录与实际入口不一致，无法仅凭当前文件确定外部替换的来源。
- 检查发现项目安装 binding 总是传入 `false`，普通项目没有读取偏好。改为可省略的单次参数并集中解析持久化默认值。
- 工作区存在其他任务的并行改动，保留其内容与提交边界。项目真实入口随后已由其他工作更新为相对链接，本任务不重复改写。
