# 项目技能库与团队协作：评审范围

状态：首轮已完成。用户已授权修改代码及提交、推送。

## 需求

团队通过项目 Git 仓库共享 Skill 内容；项目使用的版本不依赖维护者个人中央库。多个 Agent 使用同一项目内容，来源更新和入口重建需保护项目本地修改。

维护者安装并提交后，新成员只需 clone/pull 并使用团队支持的 Agent；不要求安装 AgentHub、恢复本机数据库、导入个人库或重新下载 Skill。公共目录直接读取，专属目录默认提交复制副本；项目内链接仅为团队可选策略。

## 设计原文

参见[项目技能库与团队协作方案](../../docs/plans/agent-hub.md#项目技能库与团队协作方案)。实施分期、兼容性、验收、迁移及非目标统一维护于该节。

## 评审焦点

- 项目公共目录与共享可见性；不承诺逐 Agent 独立隔离。
- 来源清单及 AgentHub 元数据布局、固定修订与外部 CLI 兼容范围。
- 停用内容目录及可选链接的目标平台范围；默认内容与团队专属副本提交 Git。
- 团队支持目标不受维护者本机安装检测限制；个人偏好不能改写团队文件。
- 普通项目优先；链接工作空间与全局技能库维持现有语义。
- 文件发布与数据库索引的恢复契约、逐目标失败结果。

## 执行状态

首轮范围采用 [ADR-0010](../../docs/adr/0010-project-skills-library.md)。执行任务：[P01](issues/P01-team-project-install.md)。最低交付包含新成员拉取即可使用、项目入口修复及更新安全；来源固定修订下载恢复和旧项目批量迁移保持后续阶段。

首轮使用 AgentHub 项目清单，外部 `skills-lock.json` 互操作和可选链接不在当前实现内。项目筛选遵循用户最新要求，仅显示检测到安装的 Agent；团队部署目标选择与筛选相互独立。

## 团队友好性修订

按 [ADR-0011](../../docs/adr/0011-optional-project-management.md)，团队不强制安装 AgentHub，管理清单可选共享。项目技能与 Agent 原生入口是使用基础；维护者可用 AgentHub 增强来源维护和修改保护。共享面板分开展示交付内容与管理信息，收拢忽略目录提示且保留单个资源诊断。执行任务：[P02](issues/P02-friendly-team-sharing.md)。
