# U02：精简技能组侧栏

Type: task
Status: claimed
Blocked by: none

## Scope

侧栏显示排序前 5 个常用技能组，其余通过「更多...」面板搜索和切换；保留组管理和持久化排序，当前非常用组临时可见。

## Acceptance

- 0～5 个组不显示「更多...」；超过 5 个时面板展示全部组和正确总数。
- 搜索、置顶、当前组定位、新建、编辑、删除可用；排序失败反馈并恢复权威数据。
- 中、英、繁体文案完整；键盘、主题和文字缩放可用。

## Comments

- 已获授权完成实现、提交并 push；常用组沿用已有排序前 5 个，避免新增独立置顶偏好。
