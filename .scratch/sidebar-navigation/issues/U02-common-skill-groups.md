# U02：精简技能组侧栏

Type: task
Status: resolved
Blocked by: none

## Scope

侧栏默认显示排序前 5 个常用技能组；点击「更多...」直接在侧栏展开其余组，再次点击「收起」恢复默认长度。保留组管理与持久化排序，当前非常用组在收起时临时可见。

## Acceptance

- 0～5 个组不显示「更多...」；超过 5 个时点击直接展开完整列表，显示正确总数，可再次收起。
- 保留当前组定位、新建、编辑、删除和完整拖拽排序；排序失败反馈并恢复原顺序。
- 中、英、繁体文案完整；键盘、主题和文字缩放可用。

## Comments

- 已获授权完成实现、提交并 push；常用组沿用已有排序前 5 个，避免新增独立偏好。
- 用户明确「更多...」为侧栏原地展开操作，按此验收。
