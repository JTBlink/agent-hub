# 侧边栏导航与自动折叠

- 全局工作区只保留一个分组和“全部 Agent”入口；编程 Agent 在前，龙虾类 Agent 追加在后，保留两类已有拖拽排序和详情路由。
- 全局总览包含全部已安装且启用的 Agent；旧龙虾总览与详情链接仍可访问。批量技能组操作以实际展示的 Agent 为目标。
- 技能库、全局工作区、项目工作区采用单组展开交互；切换页面时展开活动区域并折叠其他区域，其他页面默认折叠；允许手动展开或折叠。
- “技能库”标题整行只负责展开/折叠，在下方提供独立“全部技能”入口。入口进入现有技能库页面，清除技能组与未分组范围，保留原有筛选能力。
- 工作台技能卡片进入“全部技能”；待部署通过 URL 自动选中未部署，待分组通过 URL 自动选中未分组，侧边栏对应“全部技能”。筛选可继续组合或清除，切换技能组清除旧范围筛选。
- 新增文案同步中、英、繁体；标题按钮提供展开状态和键盘焦点反馈。

- 中文及繁体侧边栏首页入口使用“工作台”，与页面标题一致；英文沿用 Dashboard。

## 技能组常用入口

- 侧栏按已有持久化排序显示前 5 个技能组作为常用组；沿用拖拽排序，不新增偏好或迁移。
- 超过 5 组时显示「更多...」，数量表示全部技能组数量；打开可搜索全部组的面板，支持切换、置顶、新建、编辑和删除。
- 面板置顶将组移到排序首位，常用组仍为前 5 个。当前选中但不在前 5 个的组临时追加显示，不改变常用排序，且不参与侧栏拖拽。
- 搜索同时匹配原始名称、本地化名称及说明；支持空结果、键盘焦点、Escape 关闭与关闭后焦点恢复，适配三语、明暗主题、窄窗口及文字缩放。
