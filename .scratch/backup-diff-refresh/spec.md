# 备份文件差异页手动刷新

在文件差异页标题栏提供刷新按钮，方便查看进入页面后产生的新改动。

## 验收条件

- 点击刷新重新读取备份改动列表、文件数和当前文件内容，即使当前路径未变也重新读取差异。
- 当前文件仍有改动时保留选择；已无改动时选择剩余首项；列表为空时清除旧差异，可再次刷新发现新文件。
- 状态及差异请求期间按钮显示旋转图标并禁用，阻止重复刷新。
- 读取失败展示错误并支持重试；列表刷新失败保留已有内容。
- 过期响应不覆盖当前选择；保留重复点击当前文件的现有修复。
- 按钮支持中文、英文、繁体中文，复用主题样式及键盘焦点。
