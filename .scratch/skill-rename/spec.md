# 技能原地改名与来源清理

已有 Skill 改名统一通过 `skills rename <skill> <new-name>`，保留原 ID、标签、技能组、来源及部署关系；移动中心目录并更新 SKILL.md 后刷新既有部署。不得通过复制到 local-sources、重新安装和删除旧技能完成改名。

改名前检查中心与部署目标冲突；文件或部署失败应恢复原内容与入口，禁止吞掉失败并报告成功。原地登记的来源路径随中心移动，独立外部来源保持原路径；改名不生成来源副本。

CLI 提供 `skills detach-source`，复用桌面解除本地来源关联的能力，保留中心、ID、分组和部署且不删除来源文件。仅清理本次已确认由历史 Agent 创建的两个 local-sources 副本，先移入本机恢复目录。

更新内置 agent-hub-cli Skill 的改名与后续维护说明。提交本任务并按项目发布规范发布新版本；已有其他任务未提交改动保留原状，不纳入发布。
