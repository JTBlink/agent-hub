# H02：可增长的分类、搜索与阅读

Type: task
Status: resolved
Blocked by: H01

## What to build

用户在帮助中心分类浏览或搜索操作文档，离线打开文章，使用章节目录、相关文章和分享入口。现有操作帮助迁移到共享正文。

## Acceptance criteria

- [x] 六类内容具有实际文章，首页简洁且推荐入口可导航。
- [x] 中文标题、摘要、标签和正文可搜索，清空与无结果可恢复。
- [x] 稳定文章路由、标题目录、相关文章、外链和剪贴板具有正确行为及错误反馈。
- [x] 三语界面完整，正文缺少翻译时明确回退中文。
- [x] 使用现有主题，支持窄窗口、文字缩放与键盘导航。

## Comments

依赖 H01 的共用文档清单，测试通过实际路由与页面验证。

## Result

迁移为六类、14 篇中文文章，替换固定帮助卡片与翻译正文；应用提供分类、中文搜索、离线阅读、目录、内部跳转、关联文章及在线分享。三语界面完整，正文逐篇回退，未知文章和无效 hash 可恢复。复用现有 Markdown 展示和主题。

验证：帮助页面 7 项、文档查找 2 项测试通过；浏览器实际验证中文搜索、文章导航与锚点，明暗主题、820px 窗口、120% 缩放以及网站 390px 移动布局。原生 Tauri opener/剪贴板在测试中替换外部接口，其既有能力权限已检查，未宣称完成安装包原生验收。
