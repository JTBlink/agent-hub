# 修复其他来源已安装 Skill 的卡片状态

## Comments

- 用户报告部分已有安装的 Skill 仍显示「＋」。只读核对发现示例 Skill 的库内来源与当前仓库不同；原判断只识别同仓库路径，漏掉库内已有安装。
- 后续用户明确要求将当前来源的导入入口改为覆盖安装，见 [B03](B03-overwrite-install.md)。
- 修复前组件回归测试实际失败：其他来源同名的 Beta 卡片没有「本地已存在」，复现用户症状。
- 同来源匹配优先，兼容旧版 `import` 来源和原地登记；其他来源同名项显示本地存在，单独表达来源差异，不假定其内容相同。
- 不修改用户技能、来源记录或数据库内容；只读原场景核对确认卡片现在可识别已有安装，未安装项仍保持未安装。

## Result

- [安装状态规则](../../../src/lib/gitRepositories.ts) 区分「来自当前仓库」和「库内已有其他来源同名项」，同来源优先；补充旧版 `import` 及仓库内原地登记的匹配。
- [卡片](../../../src/components/GitSkillCard.tsx) 将其他来源同名项显示为「本地已存在」，操作图标改为查看关联内容；[列表](../../../src/components/GitRepositorySkills.tsx) 的已安装筛选包含这类记录，详情说明来源差异，保留查看已有安装和从当前仓库安装两种操作。明确批量选择仍可导入当前来源，保留同名确认与改名流程。
- 新增 5 项回归测试，覆盖来源差异、同来源优先、旧导入、原地登记、列表筛选与查看，以及不同来源版本的显式导入入口；相关 17 项测试通过。
- `npm test`：88 个文件、494 项通过；`npm run lint`、`npm run build`、相关文件 Prettier、帮助内容校验及 `git diff --check` 通过。
