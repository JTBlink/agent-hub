# Git 仓库 Skill 卡片浏览器

## 需求

将 Git 安装从一次性的地址输入与勾选弹窗，改为顶部切换仓库、下方展示 Skill 卡片的页面。参考现有 skills.sh 榜单布局，不增加仓库卡片或侧栏。

## 验收条件

- 保存多个仓库及最后选择，支持远程 Git 地址和本地 Git 工作区根目录；支持显示名称、添加、重命名和移除。
- 卡片展示名称、描述、来源及仓库内路径，使用通用 Git 图标；支持详情、搜索、安装状态筛选、单项与批量安装。
- 同来源的已安装状态按仓库来源与准确路径匹配，保留安装后改名的识别；其他来源的同名项显示「本地已存在」，纳入已安装筛选，不宣称来源或内容相同。详情提供「查看已有安装」和「覆盖安装」，确认覆盖后替换原有内容并更新来源，保留 Skill ID、标签、技能组与部署关系，刷新复制部署副本，不生成后缀副本。新安装项仍可调整名称。
- 缓存目录元数据，切换仓库不依赖临时 checkout；安装时获取当前内容并检查目录变化，失败可重新获取内容重试。
- 本地仓库读取当前工作区，包含未提交 Skills；拒绝非仓库、裸仓库、子目录及越界链接，导入复用本地来源逻辑。
- 各仓库的加载与错误状态相互独立，失败保留已有卡片，旧响应不能覆盖当前仓库；串行保存，保存失败提供重试。
- 支持清理远程克隆缓存，并清空该条目的目录缓存；仓库记录、已安装 Skills 及用户本地仓库保持不变。使用中的缓存不删除。
- 中、英、繁体中文文案完整，适配明暗主题、长名称和窄窗口，保留键盘与弹窗焦点行为。
