# 云端同步文案统一

用户指出多设备场景中的「备份」容易被理解为单向上传，要求以 Git 双向同步为主线调整文案，并提交。

## 验收条件

- 侧栏和页面统一为「云端同步」，设置、首次使用引导和差异页返回入口保持一致。
- 主操作表达同步、检查并同步和重试同步；状态区分待上传文件、待上传提交与云端提交。
- 本地仓库目录与云端仓库地址清晰区分；历史快照和恢复仍表达版本保护能力。
- 自动同步文案准确说明本地改动与启动触发，不承诺持续远端轮询。
- 修正连接成功即宣称已恢复、无更改再次同步即创建快照、已实现登录仍写成后续规划的误导性文案。
- 简体中文、繁体中文、英文一致，保持路由、设置键和 Git 行为兼容；本次不改变同步调度或后端流程。
