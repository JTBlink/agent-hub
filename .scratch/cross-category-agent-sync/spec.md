# 跨类别 Agent 同步入口

龙虾 Agent（例如 Hermes）技能列表顶部需要与编程 Agent 一样提供同步入口。

- 在刷新、网格/列表切换所在的工具栏内，刷新按钮左侧显示“同步 Agent”图标入口；悬停提示名称，并提供无障碍标签。
- 同步来源包含所有已安装且启用的其他 Agent，不按编程/龙虾类别排除。
- 复用已有从其他 Agent 同步到当前 Agent 的部署流程，补齐缺失的受管技能；已存在的部署不重复写入。
- 没有可用来源时入口保持可见并禁用；已经一致的来源仍可查看状态。
- 同步及刷新失败显示错误并恢复按钮可用状态。

- 同步来源菜单使用现有不透明 surface 背景，深浅主题下均不能透出下方卡片。
