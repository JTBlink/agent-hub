# 技能差异比较上下文

技能库入口的差异页固定左侧中心库、右侧来源，移除方向箭头。每个文件展示双方完整文件路径、声明版本、缺失文件提示和红绿差异图例。远端展示仓库与真实相对目录，不展示临时克隆路径。

按实际 SKILL.md 的 version 或 metadata.version 比较语义版本；较高声明版本标记“较新版本”，相同、缺失或不可比较版本明确无法判断内容先后，不以可更新状态、文件修改时间或左右顺序猜测。

执行记录：[D01](issues/D01-diff-context.md)。

## 项目详情比较

项目入口固定左侧项目本地副本、右侧中心库，但比较基准始终为中心：以中心为旧版、本地为当前内容，显示本地相对中心的新增、修改和删除。左右位置只影响排版，不反转新旧、增删、颜色与权限变更。技能库入口保持中心在左。

项目入口必须比较实际所选 Agent 项目副本与其匹配的中心技能，而非原导入来源。整个技能目录纳入差异；项目较新状态、Agent 名称和目录在详情中展示，多副本可切换，默认优先项目较新副本。切换忽略过期请求，失败可重试。

执行记录：[D02](issues/D02-project-comparison.md)。

语义修正记录：[D03](issues/D03-local-change-semantics.md)。
