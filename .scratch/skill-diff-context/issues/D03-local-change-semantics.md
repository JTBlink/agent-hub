# D03：项目本地改动以中心为基准

Type: task
Status: resolved
Blocked by: D02

## Reproduction

项目入口左本地、右中心时，本地新增 license/metadata 行被标为红色减号，本地独有文件计为删除。修复前运行 `npx vitest run src/components/ProjectSkillDetailPanel.test.tsx`，3 项失败，分别复现文件计数反转、新增行减号和删除行加号。

## Cause

将视觉左右排序与旧版到新版的差异方向绑定，项目入口同时交换原始/更新内容和增删状态。D02 的反转语义不符合最终用户要求，本记录替代其对应行为约定。

## Acceptance

- 项目入口保持左本地、右中心，但中心始终是比较基准。
- 本地新增行显示绿色加号，本地删除行在中心侧显示红色减号。
- 新增/删除文件计数、缺失侧和权限方向不受排版影响。
- 技能库入口的中心到来源语义保持兼容。

## Result

将内容差异方向与左右排版分离。DocumentDiffViewer 保持 original 为中心旧内容、updated 为本地当前内容，仅通过 updatedOnLeft 调整展示列；颜色、加减号和行号段跟随原始/更新版本，不跟随左右位置。

移除反转内容和文件状态的 helper；项目统计直接使用后端中心到本地的差异状态。缺失文件提示按中心/本地身份判断，权限变更保留中心到本地的方向。空内容按零行处理，新增或删除整文件不产生额外的空行改动。

项目图例明确“以中心为基准查看本地改动”，不再用缺失声明版本的提示代替比较方向。实际声明版本和较新声明版本标签继续展示；技能库入口维持中心在左、来源在右。

验证：修复前 3 项回归失败；修复后前端全量 171 项、生产构建、本次文件 ESLint、Prettier 与 git diff --check 通过。项目详情 10 项回归覆盖新增/删除行的加减号与颜色、新增/删除文件计数、缺失侧及左右路径。未修改 Rust；未进行完整桌面主题、缩放和键盘实测。

## Review

- Standards：以原始/更新版本定义差异语义，左右只决定排版；删除不再需要的反转 helper，复用现有目录差异契约。
- Spec：项目本地新增为绿色加号、项目本地删除为红色减号，仍保持左本地右中心；计数、权限与图例使用同一比较基准。
