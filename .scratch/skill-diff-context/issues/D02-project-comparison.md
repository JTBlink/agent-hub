# D02：修复项目技能详情差异与版本展示

Type: task
Status: resolved
Blocked by: D01

## Reproduction

修复前 `npx vitest run src/components/ProjectSkillDetailPanel.test.tsx`：2 项失败。主文档相同、references 文件不同的项目详情显示 No content changes；详情没有读取所显示副本关联的中心 ID。

## Cause

项目详情单独使用 DocumentDiffViewer，只比较主文档且方向与技能库视图相反。调用方按排序后的 centerSkillIds[0] 读取中心，而非 primaryVariant.center_skill_id；加载状态在页面共享，无请求身份保护。

## Acceptance

- 项目详情比较所选项目 Agent 副本的全部技能文件，项目本地在左，中心在右。
- 读取该副本关联的中心技能，展示路径、项目同步状态与声明版本。
- 默认优先项目较新副本，可切换 Agent；忽略旧响应、允许刷新重试。
- 临时目录覆盖正常、禁用、相同内容/软链接及非法路径。

## Result

- 抽出 ProjectSkillDetailPanel 和项目内容 hook；移除页面共享主文档加载状态，请求绑定项目、Agent、副本目录与中心 ID，忽略过期响应。
- 新增 get_project_skill_diff 命令，复用项目扫描与中心匹配规则，以及技能库全目录 diff；覆盖 scripts、references、二进制、权限等既有差异范围。
- 展示实际所选副本路径、项目同步状态、声明版本，默认选择项目较新副本；多个 Agent 副本可切换，支持刷新和错误重试。
- 按最终用户要求，项目入口左本地右中心，技能库入口左中心右来源。公共展示组件支持入口方向；内容、缺失侧、权限、状态标签与统计一起反转，避免只交换标题。较新声明版本标识始终跟随实际副本。

验证：修复前 2 项 UI 回归失败，修复后项目 7 项及技能库 11 项详情测试通过；前端全量 163 项与生产构建通过。本次前端文件 ESLint 通过。Rust 全量 636 项库测试与 7 项 CLI 测试通过，8 项忽略，严格 Clippy 通过；其中 3 项项目差异回归覆盖主文档相同但辅助文件不同、禁用目录、非法路径/Agent 和中心软链接内容一致。

全工作区格式检查发现同工作区其他项目技能库改动的格式差异；本次新增 Rust 差异模块和前端组件格式检查通过。未进行完整桌面主题、缩放和键盘实测；用户截图已反馈实际项目差异可见，最终左右顺序由 DOM 回归测试验证。

## Review

- Standards：复用扫描、目录 diff、版本解析与状态文案；不直接使用任意输入绝对路径读取文件，不写入用户文件。抽出详情和资源 hook，减小历史大页面。
- Spec：项目入口使用项目 Agent 实际副本而不是原导入来源；主文档相同不掩盖其他文件差异；新旧标记与入口布局分离。
