Type: task
Status: resolved
Blocked by: none

## Acceptance

- 每个文件的左右列标签、路径和内容对应；长路径可换行。
- 可比较声明版本标记较新侧；相同/未知不推断新旧。
- 支持新增、删除、文本和非文本文件。
- 前后端契约、三语文案、回归测试、变更记录完整。

## Result

- 移除中心到来源的箭头，左右列固定标明中心库/来源，显示每个对比文件的完整路径和实际声明版本。新增/删除文件明确提示缺失侧，红绿图例解释内容归属。
- 差异接口返回双方技能目录、声明版本和版本比较结果。读取实际 SKILL.md，复用元数据解析并支持 metadata.version；SemVer 比较包含预发布版本，不把内容差异或 update_available 当作新旧证据。
- 远端显示脱敏仓库地址与技能相对目录，临时克隆路径不展示。差异表左右宽度固定，长路径换行。
- 扩展三语文案、bindings、CHANGELOG；差异 DTO 与版本比较拆入独立模块，避免给历史大文件继续堆叠职责。
