# 构建缓存只保留最新产物

Rust 编译目录积累大量历史目标文件，导致仓库构建缓存约 39 GiB。统一桌面打包、CLI 构建/安装与脚本测试入口，在成功结束后清理历史应用产物；失败不清理，避免影响最后可用的构建。

验收：

- 每种架构、debug/release、编译模式和 feature 配置保留最新应用产物。
- 通过当前库归档清单保留最新目标文件，删除历史编译遗留文件；保留共享依赖、build-script 输出与增量缓存。
- 同类安装包只保留最近构建的一份，签名随旧包一并清理，不混用架构或格式。
- 提供手动清理与只读预览，支持自定义 Cargo target 目录，不遍历目录链接。
- 用真实缓存验证空间下降，当前可执行文件的校验值保持一致；测试覆盖文件保留、失败路径与重复清理。
