## 验收标准

- 实施前拆成本地快照/恢复、手动 Git、对象合并、认证、自动同步五类切片。
- 先定义版本化导出协议、稳定 ID、删除记录及跨设备路径映射，不直接复用旧数据库。
- 首个切片证明本地快照可恢复技能文件、执行位、标签和 Preset；恢复前备份当前状态。
- 仅导出允许清单，排除配置正文、凭据、本机路径及数据库；导出源文件中的敏感信息需有可检查的处理规则。
- 后续再适配对象级三方合并，测试改名/删除/编辑组合、冲突保留、离线重试和协议升级。
- 远端和认证由用户配置；不得继承旧应用发布凭据、自动连接或自动启用上传。
