# B24：一键清理未安装 Agent 遗留的 Skills

Type: task
Status: resolved
Blocked by: none

## Scope

本地 Skills 管理提供一键清理入口，支持按 Agent 筛选并仅清理该 Agent，也可清理全部未安装 Agent，自动生成未安装 Agent 的遗留 Skill 位置清单，确认后清理并移除空 Skills 目录。保留共享给已安装 Agent 的路径、手动配置目标、技能库和其他 Agent 配置/历史；执行前重新检查安装、目录边界、指纹与托管状态。

## Acceptance

- 展示实际待删路径、数量，清理成功立即关闭弹窗，后台刷新。
- 同一路径只操作一次；逐项报告跳过或失败，不能静默丢失内容。
- Rust 临时目录回归覆盖共享根、安装状态变化、内容变化、链接与空目录。
- 浏览器 IPC fixture 验证确认、取消和批量清理，不删除真实安装。
- 更新 docs、CHANGELOG，完成构建与严格检查。

## Result

新增“一键清理”：自动预览未安装 Agent 的遗留 Skills 与空目录，可按 Agent 筛选后确认，也可选择全部未安装 Agent。后端重新检查安装、路径、指纹与托管状态，共享安装、手动路径、链接根及额外共享发现目录排除；物理路径只删除一次，来源与库副本保留，批次最后写入元数据。失败路径列出原因，确认完成后立即关闭、后台刷新。只删除 Skills 与空 Skills 目录，保留 Agent 配置与历史。

验证：Rust 临时目录覆盖安装变化、内容变化、共享/手动/库保护、双 Agent 共用路径、链接及空目录；浏览器 fixture 验证预览、取消、按 Agent 选择只提交该 Agent 的 ID、刷新挂起期间关闭、无遗留提示；不删除真实机器上的 Skill。完整前端/Rust 检查通过。

## Review

- Standards：复用单项删除的路径校验、指纹、部署保护与来源处理；复用确认弹窗，批量操作不重复全表读取与元数据写入。
- Spec：按 Agent 维度清理，有可审阅路径和数量；没有启动时静默删除，安装与内容变化会保留并报告。
