# B33：校验本地 Skill 来源并优化失败提示

Type: task
Status: resolved
Blocked by: none

## Scope

修复普通文件夹或不含 Skill 的压缩包也能导入的问题。失败使用独立弹窗；中文首页的 Library 统计名称统一为技能库。

## Acceptance

- 文件夹必须包含真正的 SKILL.md 或 skill.md 文件；压缩包必须包含这样的技能目录。
- 不把名为 SKILL.md 的目录识别为入口，不再把无入口压缩包的解压根目录当作 Skill。
- 校验在创建或覆盖目标目录前完成，失败不写入技能记录，保留已有目标。
- 保留无 frontmatter 的现有 Skill 兼容性；不增加 YAML 元数据强制要求。
- 导入失败显示可确认或按 Esc 关闭的弹窗，不重复显示页面错误条和 toast；扫描失败仍保留扫描重试入口。
- 简体与繁体中文首页统计、技能数卡片使用技能库称呼。

## Review

- Standards：复用 skill_metadata 的目录识别规则，校验集中在安装层；回归测试独立模块，弹窗独立组件并使用原生 dialog 的焦点约束与键盘关闭能力。
- Spec：覆盖文件夹、zip、skill、伪入口目录、已有目标保留和有效导入；导入失败与扫描失败分离。文案不改变统计口径或英文导航名称。

## Result

修改前新增回归测试有两项失败，证实普通文件夹与普通压缩包被错误接受；修复后三项全部通过。完整 Rust 测试通过（607 项库测试、6 项 CLI 测试，8 项忽略），Clippy 严格检查通过。前端 build、lint、70 项测试通过。检查格式、tracker 与差异后提交。

## Comments

有效性沿用现有扫描规则：存在入口文件，不对说明正文做语义判断。压缩包继续使用现有深度限制和单技能导入约束。
