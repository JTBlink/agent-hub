# B16：为本地扫描入口添加管理能力

Type: task
Status: resolved
Blocked by: none

## Scope

将“扫描本地 Skills 并导入”扩展为本地 Skills 管理。在现有本地页保留导入能力，为每个实际扫描位置提供内容查看、打开目录与删除，支持搜索和 Agent 筛选。

## Acceptance

- 仪表盘、命令面板与本地页使用统一入口文案。
- 同名不同内容及多个来源位置可分别管理，删除前展示具体位置并确认。
- 后端复用扫描器、适配器和路径安全规则；只操作有效扫描记录，拒绝托管部署、越界路径和扫描后发生变化的内容。
- 删除软链接不删除链接目标，删除后刷新列表；查看内容不会被过期异步结果覆盖。
- 相关回归测试、前端构建/lint、Rust 测试/格式/Clippy 通过，补充 CHANGELOG 与产品说明。

## Result

- 同一入口提供搜索、Agent 筛选、内容查看、打开目录、按位置确认删除和原有导入。扫描展示及异步管理流程拆成组件、hook 和纯函数，减少原页面体量。
- 后端复用适配器、安全路径规则、来源引用修复及删除方法，拒绝过期内容、托管部署和技能库路径；共享目录删除影响在确认框明确说明。
- 浏览器 IPC fixture 验证内容读取、取消/确认删除、搜索、Agent 筛选及 900px 布局，无横向溢出或控制台错误。真实文件操作用临时目录验证，不操作本机安装。
- npm build、lint、52 项前端测试、556 项 Rust 库测试及 6 项 CLI 测试、fmt 和严格 Clippy 通过；8 项 Rust 测试默认忽略，计时测试单独执行。

## Review

Standards：复用 bindings、领域类型、扫描根目录、路径规则和现有 UI，新增模块在体量限制内；文档和 fixture 无身份信息。

Spec：同名不同版本分别展示，过滤后仅暴露匹配位置；删除保留软链接目标、独立副本和技能库，托管/内容变化/越界有回归覆盖。交互验证为隔离 fixture，未宣称完成原生桌面端到端验收。
