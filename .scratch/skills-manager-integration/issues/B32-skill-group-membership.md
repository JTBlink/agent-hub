# B32：明确技能组成员操作

Type: task
Status: resolved
Blocked by: none

## Scope

技能库成员开关容易被理解为全局启用或停用。显示当前编辑的技能组和成员数量，以明确的加入、移出按钮管理成员，保持技能组记录与实际 Agent 部署的区别。

## Acceptance

- 列表与卡片均使用加入技能组／移出技能组按钮，提示包含实际组名。
- 顶部显示组名、技能数量和工作区批量添加入口，说明修改分组的效果。
- 筛选、批量操作与完成提示统一用成员语义；无当前组时禁止成员操作。
- 保留原成员 API 与部署行为，按钮请求中防止重复提交并显示错误。

## Review

- Standards：复用已有成员 API，新建成员操作与上下文组件，减少超大页面的展示逻辑；简中、繁中、英文一致。
- Spec：加入或移出只编辑组内名单，用户在工作区选 Agent 后再批量添加，不把成员关系显示成全局启停。

## Result

实现当前组上下文、明确的加入／移出操作与工作区入口，单项与批量反馈均显示组名。`npm run build`、`npm run lint`、`npm test`（70 项）、`npm run tasks:check` 与 `git diff --check` 通过。纯前端交互与文案调整，无后端或存储格式变更。
