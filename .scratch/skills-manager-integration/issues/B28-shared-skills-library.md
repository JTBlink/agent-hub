# B28：共享技能目录与 Git 备份兼容

Type: task
Status: resolved
Blocked by: none

## Scope

默认技能库使用 `~/.agents/skills`，应用数据库、配置、日志仍位于 `~/.agent-hub`。已有自定义库和 CLI 显式目录兼容。旧默认库在排他租约下无覆盖合并到共享目录，保留旧内容作为回退副本；冲突保持旧库并显示原因。同步、原地导入与取消部署保护中央源目录。

GitHub 备份以实际技能根为 Git 工作目录，迁移保留远端、历史和必要元数据；共享目录的克隆恢复保留本地冲突内容和恢复副本，不覆盖其他安装器内容，隔离应用数据库、缓存、日志与配置。

## Acceptance

- 默认路径、旧库迁移、冲突与重试、软链接、原地导入、自部署和取消部署有临时目录回归。
- 验证迁移后原 Git 历史/远端、提交和本地远端恢复；不访问真实用户文件或远程仓库。
- 设置清晰区分实际技能目录与应用数据目录，更新产品文档、ADR 和 CHANGELOG。

## Result

默认共享目录及应用状态分离完成，设置展示实际技能目录。旧库迁移通过预检、无覆盖复制和持久标记完成切换，保留旧内容、Git 历史和远端；冲突继续使用旧库。原地索引、同路径导入/部署以及取消部署均保护中央源文件。

克隆恢复先下载再替换，保留完整旧库、历史与本地独有条目；空远端元数据和新增本地 Skills 可重新入库。根目录应用状态及安装器锁文件不进入后续备份提交。历史快照恢复重新应用排除规则。开发构建的退出保存仍只做本地提交，不需要钥匙串。

验证：Rust 全量 584 个库测试与 6 个 CLI 测试通过，8 个已有测试忽略；随后新增空元数据恢复回归单独通过（共 591 个通过）。前端 58 个测试、构建、ESLint、Rust 格式和严格 Clippy 通过。测试仅使用临时目录与本地 Git 远端，未迁移实际用户目录或推送 GitHub。

## Review

- Standards：迁移/恢复拆到独立模块，路径规则复用适配器，启动索引与备份更新使用仓库锁；数据库和日志不迁到共享目录。
- Spec：共享目录直接读取语义明确，不将取消部署误称为全局禁用；已有自定义库兼容。远端冲突版本生效，本地原版留在恢复目录；软链接按 Git 语义备份，外部目标内容不包含在内。
