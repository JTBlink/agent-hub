# 技能详情操作入口

- 技能库详情顶部移除重复 Agent 图标，说明下方只保留一组并可点击执行对应操作。
- 技能组内沿用 Agent 启停流程；全部技能与未分组视图沿用全局部署/取消部署流程，保留加载与错误反馈。
- 技能目录旁提供“在 VS Code 中打开”：技能库打开中央目录，项目技能打开当前选择的副本目录。
- 实际打开动作封装为通用方法，复用现有跨平台路径编码、opener 权限与目录操作组件，供其他入口调用。
- 复制路径图标直接紧跟路径文字，不放在行末操作区；共用复制组件，一键复制完整原始路径，提供等待、成功与失败反馈。

- 详情完整显示说明与已知版本；SKILL.md 的摘要、版本、许可证及自定义元信息不能被正文渲染丢弃，本地、中心与项目副本分别展示当前文档的信息，异常元信息保留原文。
