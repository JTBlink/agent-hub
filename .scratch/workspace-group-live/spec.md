# 工作空间技能组状态与刷新策略

工作空间的技能组状态、卡片与数量共用目录扫描结果。用户反馈实时扫描过于频繁后，调整为进入或切换页面时扫描一次，保留手动刷新和本页操作完成后的明确刷新。

- 技能库通知、等值 Agent 对象替换和技能组成员变化不触发目录重扫；成员状态直接根据已加载数据更新。
- 进入、切换 Agent 页面各扫描一次，返回之前的页面也读取当前目录。
- Agent 详情与总览的技能组存在状态采用实际扫描结果，复用中心匹配 ID，避免同名误判。
- 手动刷新同时更新技能组成员、技能和 Agent 状态。
- 刷新期间保留已有卡片；刷新失败保留上次成功结果，首次失败使用部署记录回退。
- 较早请求不能覆盖较新的扫描。
