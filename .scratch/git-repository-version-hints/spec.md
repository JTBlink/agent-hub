# Git 仓库技能版本提示

仓库卡片、详情和覆盖确认显示仓库声明版本及已安装中心库版本。已安装版本较高时提示「仓库版本较旧」，覆盖确认明确说明降级及实际版本；仓库版本较高时提示有较新版本。

按 SemVer precedence 比较，支持顶层 version 与 metadata.version；缺失或不可比较版本不推断新旧。兼容旧目录缓存，未保存版本时提示刷新；刷新后读取真实目录版本。覆盖前重新获取目录，版本与已展示内容不同则刷新提示并要求重新确认。

核实截图对应的本地工作区时，setup-ai-native 与中心均声明 0.4.2，25 个文件一致，不能据截图断言当前目录较旧。补齐的是版本可见性和降级提示能力，不自动改写来源或中心内容。

## 追加：新版同步到仓库

仓库版本低于已安装版本时不允许覆盖安装，改为「同步新版到仓库」。本地仓库在确认双方版本、目标目录及移除项后，将技能库新版写回原技能目录；不修改中心记录与部署，不自动提交或推送。确认绑定双方内容快照，变化时需重新预览，保护 Git 元数据与仓库内其他技能。

远程仓库需先添加本地工作区再同步。旧缓存自动补读一次版本，失败可手动刷新；详情按路径读取当前目录状态，避免刷新后仍保留旧对象。同步成功后更新持久化缓存并重新扫描，状态刷新失败须说明文件已同步。
