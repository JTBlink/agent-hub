# 将新版技能同步到较旧本地仓库

仓库较旧时主操作改为同步技能库新版到仓库，禁止旧仓库覆盖技能库。同步前预览双方版本与移除项，确认绑定内容；保留仓库 Git 元数据及技能库身份和部署。同步完成、刷新及旧缓存迁移后，已打开的详情也须反映最新目录状态。

仅写入用户选定的本地工作区，不自动提交或推送；远程地址提示添加本地工作区。关联发布 [P01](../../skill-rename/issues/P01-release.md)。

## Result

- 新增 core 本地工作区写回服务与 IPC：预览版本和移除项，确认绑定双方内容；拒绝旧仓库覆盖高版本，写回失败恢复原目录，拒绝路径逃逸、重叠路径和 Git 元数据替换。
- 卡片详情将旧仓库主操作改为同步新版，本地支持预览、确认及失败重试；远程引导添加本地工作区。不会自动提交或推送。
- 详情以路径派生当前目录对象，旧缓存自动补读一次版本；同步后更新持久化目录并重新扫描，即便状态刷新失败也明确文件已同步。
- 共享提取已有 SemVer 比较模块供差异与同步校验使用，其他来源更新策略的既有未提交内容继续保留。
- 验证：仓库前端 26 项回归、全量前端 561 项通过；仓库覆盖/同步 Rust 回归覆盖内容变化、版本方向、Git 元数据、库身份、仓库其他文件及链接逃逸；TypeScript、ESLint、构建与严格 Clippy 通过。干净发布检出及三平台候选结果由 P01 继续记录。
- Standards：复用目录解析、路径保护、安装复制和共享 SemVer；后端执行降级校验，确认绑定实时内容。Spec：旧版本不会覆盖新版，用户可同步到本地工作区并看到刷新后的状态。原生主题、缩放与键盘手动验收仍未执行。
