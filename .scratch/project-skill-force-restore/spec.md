# 确认后强制恢复项目技能

项目内容较新或托管副本有修改时，从技能库恢复必须先展示覆盖确认。默认请求继续保护现有内容；只有确认当前目标后才发送强制参数。

- 卡片、列表、详情及批量操作共用确认和刷新流程，弹窗列出覆盖的技能，说明项目与对应 Agent 内容会被技能库版本替换。
- 取消不发送恢复请求；确认后强制恢复，失败保持可重试，等待期间禁止重复确认或关闭。
- 后端仍验证技能身份、工作区路径、来源及事务指纹；强制仅放行被确认的内容差异，不放行路径越界、外部来源链接或非技能目录。
- 默认参数保持保护，支持普通项目、托管中央版本及链接工作空间；未添加 Agent 不自动添加，保留部署方式和启停状态。
- 三语文案、回归测试和 CHANGELOG 同步；仅在合成项目中验收，不恢复用户实际技能。
- 恢复必须先校验中心技能并完整准备替换内容，写入失败时保留或恢复项目原件；恢复现有副本不得受旧默认部署设置影响而改成链接。
