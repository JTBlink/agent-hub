# 设置页分组与版本检查

将长设置页改成顶部固定的五个横向 Tab：Agent、技能与部署、外观与行为、备份与网络、关于与诊断。沿用现有主题、控件、国际化及保存方式。

- Agent：检测、启停、自定义 Agent、路径编辑和拖动排序；徽标显示已检测数量。
- 技能与部署：技能目录、默认部署方式、Skill 自动更新。
- 外观与行为：主题、字号、语言、关闭窗口行为、托盘。
- 备份与网络：备份仓库目录、Git 同步、网络代理；Git 引擎设置折叠到高级设置。
- 关于与诊断：应用版本、检查更新、发布说明及下载、帮助、官网、反馈、日志、应用数据目录。
- 保留 `/settings#agents` 入口，支持各 Tab 深链接及浏览器前进后退；键盘方向键、Home/End 切换，状态可访问。
- 切换 Tab 保留未提交内容和各自滚动位置；窄窗口横向滚动 Tab；明暗主题、文字缩放与长路径保持可用。
- 仓库异常和崩溃提示在所有 Tab 可见。
- 检查当前仓库的最新正式 GitHub Release，按 SemVer 比较；显示检查中、已是最新版、新版本、失败重试状态。复用配置的代理，不使用备份凭据，不自动下载安装。
- 后端失败不得伪报最新版；无正式 Release 明确反馈。保留 `AppUpdateInfo` 既有字段契约。
- 按职责拆分设置页，不继续向历史超大文件添加功能；补充导航、版本检查及发布版本解析的行为测试。

用户已要求完成全部任务，不再逐项确认。仓库内现有其他任务的改动需保留。
