# Coding Skill 推荐与帮助导航

Type: feature
Status: resolved

## 需求

帮助中提供以社区 matt 系列为重点的 coding Skill 推荐集合、使用场景和可复制提示词。优化左侧分类与文章的层级，将 Skill 使用技巧放在快速开始之后。

## 验收

- 核实上游来源、当前技能名称和前置条件，提供新功能、调试、审查及架构改进组合。
- 说明导入、技能组、部署和 Agent 调用的关系；区分宿主调用语法与 Skill 名称。
- 内容进入共享 Markdown 帮助，应用和网站均可浏览、搜索；保留三语分类与正文回退。
- 分类标题具备图标、明显分隔与文章缩进；当前文章、键盘焦点和窄窗口导航可用。
- 推荐分类前移，新文章进入首页推荐和既有文章关联。
- 保留工作区其他任务的改动；不安装推荐技能、不执行上游工作流、不发版。
- 用户随后授权提交本地所有改动并 push；按主题提交并验证远端结果。

## 验证

执行帮助内容校验、前端测试、lint、应用和文档站构建；实测导航层级、链接、明暗主题、窄窗口、文字放大和键盘。结果记录在任务文件。
