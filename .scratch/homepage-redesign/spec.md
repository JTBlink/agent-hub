## 未部署技能入口

在工作台“已部署”卡片下方展示“未部署 N · 查看”。点击打开完整的未部署列表，显示名称与描述；点击技能沿用技能库详情入口选择 Agent 部署。未部署定义与已有工作台统计一致：技能没有任何部署目标。列表与数量随技能数据更新，不受当前技能组或近期列表数量限制；无未部署技能时显示 0 并禁用查看。沿用主题变量，支持滚动、键盘关闭和焦点恢复，同步三种语言。本次不包含提交、发布或产品截图更新。
