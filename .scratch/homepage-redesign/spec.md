## 应用 Dashboard 补充需求

用户提供应用内首页截图并要求美化。保持现有品牌与页面壳，把首页组织为标题与紧凑操作、三个关键指标、近期技能列表、已启用 Agent 与项目入口。使用真实派生状态，不新增持久化配置；保留安装、Agent 设置与技能详情入口，覆盖空状态、中英繁体和明暗主题。完成后更新产品截图并提交 push。

## 未部署技能入口

在工作台“已部署”卡片下方展示“未部署 N · 查看”。点击打开完整的未部署列表，显示名称与描述；点击技能沿用技能库详情入口选择 Agent 部署。未部署定义与已有工作台统计一致：技能没有任何部署目标。列表与数量随技能数据更新，不受当前技能组或近期列表数量限制；无未部署技能时显示 0 并禁用查看。沿用主题变量，支持滚动、键盘关闭和焦点恢复，同步三种语言。本次不包含提交、发布或产品截图更新。

## 首页卡片去重

将概览整理为“技能库、待部署、待分组”。技能库展示总数和部署覆盖率；待部署统计没有部署目标的技能，进入全库未部署筛选；待分组统计没有技能组的技能，进入未分组视图并沿用加入技能组操作。替换与右侧 Agent 面板重复的统计，保留该面板及项目入口。每张卡片只提供一个完整点击目标，进入列表前清理旧技能组和详情状态；零待办禁用，初始加载显示占位。三语、明暗主题、窄窗口、字号与键盘交互同步验收。用户已授权完成后提交并 push。

窄窗口与放大字号时，卡片按内容可用宽度换行；页面壳允许内容列收缩，避免固定最小宽度裁掉操作入口。

## 减少首页滚动

用户要求首页减少滚动。沿用现有品牌、SVG 和工作空间切换；压缩概览为同一行，宽窗口下工作空间与近期技能并排，窄窗口顺序排列。工作空间入口保留全部当前类型的项目/Agent，取消每个 Agent 重复的辅助行；近期技能默认展示最近 3 项，可展开其余 2 项并收起，详情操作并入单行卡片。保持正文与点击目标可读可达，不增加内层滚动条。

同一份合成数据的 1440×900 基线：5 个 Agent、2 个项目、12 个技能，原页面主体约 1244px。调整后验证首屏可见及展开、收起、详情和工作空间导航，并同步三语、截图与任务记录。

## 项目优先布局与截图同步

工作台默认项目工作空间，即使没有项目也保留项目空状态；切换栏项目在前、Agent 在后。宽窗口将工作空间作为左侧主区域，近期技能作为右侧辅助区域；空间较多时可按名称搜索，切换清空条件。项目入口保留技能数和冲突状态，近期技能减少重复卡片边框和纵向空隙。复用既有品牌、路由与状态，不引入列表内部滚动。

README 与 GitHub Pages 两张产品截图统一来自当前组件、相同固定示例数据和 1440×900 深色中文界面；更新说明与替代文本，并验收线上图片与源文件一致。
