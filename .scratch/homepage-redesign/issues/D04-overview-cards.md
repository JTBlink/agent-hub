# 首页概览卡片去重

## Scope

替换重复的 Agent 统计，将部署覆盖率合并进技能库；用待部署、待分组卡片呈现可继续处理的事项。保留右侧工作空间入口，复用现有部署目标、技能组成员关系和列表操作。

## Acceptance

- 三张卡片对应总技能、未部署、未分组数量，数据刷新同步。
- 点击进入全库、全库未部署或未分组列表，清理旧分组与详情；分组列表可继续添加到技能组。
- 初始加载不显示假零值，零待办禁用；每张卡片一个按钮，键盘焦点可见，名称及数量可读。
- 简体、繁体、英文文案与明暗主题、窄窗口、文字缩放通过验证。
- 前端测试、lint、build、格式和差异检查通过，按用户授权提交并推送。
