# 减少工作台首页滚动

## Scope

压缩概览、区域间距和卡片，宽窗口并排展示工作空间与近期技能；默认展示 3 项近期技能，支持展开另外 2 项。保留 SVG、完整工作空间入口、既有导航、正常字号和统一页面滚动。

## Acceptance

- 1440×800 的标准合成数据下，默认概览、5 个 Agent 和 3 项近期技能首屏可见。
- 展开保持最新 5 项的顺序和详情操作，收起保留控件焦点；最多 3 项时不显示展开控件。
- 中英繁体、明暗主题、字号放大、窄窗口可用，无内部滚动条；全部项目仍可进入。
- 测试、lint、构建、格式及差异检查通过，回写实测高度和截图。

## Comments

- 用户在工作台改版后要求继续减少滚动，沿用当前会话完成后提交与 push 的授权。
- UI/UX 检索未命中适用的密度条目，本次按项目规范与真实窗口高度调整；未采用无关的标题换行建议。
