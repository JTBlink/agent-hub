# Skill 详情的本地来源、中心与差异

详情页的内容切换应明确区分中心库副本与来源：本地/import 技能显示“本地 / 差异 / 中心”，本地读取原始来源，中心读取技能库副本；远端技能显示“中心 / 差异 / 来源”。即使文本相同，当前版本标题与一致状态也应提供清晰反馈。

本地来源无需网络，打开详情时即计算全目录差异，显示变化文件总数及新增、修改、删除数量；SKILL.md 相同而参考文件变化时仍能看出有更新。远端 diff 保持按需读取，未比较与零差异不同。切换异步资源不串内容，更新 skill 元数据时不重置当前标签；支持刷新内容、失败反馈与重试，键盘可操作。缺失或已解除关联来源沿用已有不可比较行为。

验证使用实际 React DOM 的交互测试覆盖点击后内容变化、目录差异数量、相同文本、刷新、失败与异步结果顺序；更新三种语言与 changelog，完成构建与相关检查后提交 push。
