# D03：确定配置写入与敏感数据策略

Type: decision
Status: resolved
Blocked by: D01

## 目标

确定 JSON、JSONC、TOML、YAML、Markdown 等配置的无损编辑能力，以及并发修改、备份、回滚和敏感字段处理规则。

## 验收标准

- 为每种格式选择解析/保留注释/渲染方案。
- 定义 checksum 乐观锁、原子替换和文件权限继承规则。
- 定义备份位置、保留周期和回滚语义。
- 明确 Token、环境变量和命令参数的遮罩与日志规则。
- 产出失败场景表和 ADR。

## Result

- 已为 JSON、JSONC、TOML、YAML 与 Markdown 确定解析、最小 patch、注释和格式保留策略。
- 已定义原始字节 SHA-256 乐观锁、文件身份复核、同目录临时文件、平台原子替换、权限继承以及 symlink/hardlink 边界。
- 已确定应用数据目录备份、`10 份/30 天/每文件最多 50 份`保留规则和回滚语义。
- 已明确敏感字段、环境变量、命令参数、日志、SQLite、UI 与备份的遮罩/保护规则。
- 已将失败场景与恢复动作写入配置管理架构，并记录 ADR-0003 及被否决方案。
