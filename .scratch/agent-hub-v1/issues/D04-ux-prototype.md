# D04：验证配置中心与 Skills 中心交互

Type: prototype
Status: resolved
Blocked by: D02, D03

## 目标

用可抛弃原型验证核心信息架构，避免在正式实现中才发现配置层级、Diff 或 Skill 安装流程难以理解。

## 验收标准

- 覆盖全局/工作空间切换、Agent 筛选和配置文件树。
- 验证表单/源码双模式、诊断、Diff、保存与回滚流程。
- 验证 Skill 搜索、来源详情、兼容性、目标作用域和安装计划。
- 覆盖空状态、解析失败、外部修改和部分兼容状态。
- 将原型结论写入产品文档；原型代码不进入正式应用。

## Result

- 已在 `.scratch/prototypes/d04-ux/` 创建独立、只读的三变体原型，不被正式 React 入口引用。
- 运行 `npm run prototype:d04` 后打开 `http://127.0.0.1:4173/?variant=A`，可用底部切换器或键盘左右键切换 A「导航分栏」、B「工作台总览」、C「任务流确认」。
- 原型覆盖全局/工作空间、Agent 筛选、配置树、源码与 Diff、诊断、外部修改、空状态、Skill 来源/兼容性/目标和安装计划。
- 结论已回写产品文档：正式 UI 采用“工作台总览作为入口 + 配置/Skills 专题页 + 统一安装计划确认”信息架构；高风险写入不放在列表内直接执行。
