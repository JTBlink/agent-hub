# AgentHub SDK 变更日志

## [Unreleased]

## [0.3.0]

- 产品清单支持 `pageOverrides.discover`。默认仍使用内置发现页，自定义页面复用原有入口和链接。
- 公开 Skills 和任务模板在独立仓库维护，SDK 随包提供锁定的默认内容快照，定制构建无需获取该仓库。

## [0.2.0]

- 新增 `agent-hub-sdk` 构建入口，由 Cargo 提供同版本桌面资源和字体，产品构建无需访问 GitHub。
- 产品清单支持私有 Tauri 插件，Agent Flow 可接入独立 Skill Hub。
- 共享 Skill 来源支持搜索、查询版本和校验指定版本归档，安装后登记到技能库。

## [0.1.3]

- 统一项目 SDK 与 Cargo 包名称为 agent-hub-core，保留 Agent 启动方案接口。
- Cargo 安装入口从已验证的 Git 提交获取源码并校验归档。
- SDK 默认发布到 crates.io，GitHub 工作流负责候选和标签校验。

## [0.1.2]

- 更新 SDK 归档与发行清单的版本标识。共享源码和下游接口与 0.1.1 一致。

## [0.1.1]

- 增加基于 SDK 远端标签的自动选版工具，并记录补丁、次版本和主版本的升级规则。
- SDK 发行说明引用对应版本的变更日志，已准备的版本可复用。
- 发布指南中的标签推送命令兼容 Bash 和 zsh。

## [0.1.0]

- 提供可锁定版本的共享源码归档、安装器和定制产品构建入口。
- 支持自定义侧栏、页面路由、品牌、产品版本及独立能力配置。
