AgentHub 是什么？适合谁使用？

AgentHub 是面向使用 AI 编程工具的开发者的本地优先工作台。在同一处管理项目、终端、Git、Skills 和定时任务，支持 macOS、Windows 与 Linux。

需要换掉现在使用的 Agent 吗？

可以继续使用已安装的 Codex、Claude Code、OpenCode 或 Hermes。AgentHub 负责项目入口与上下文组织，Skills 也可部署到支持的其他工具。各 Agent 的安装、账号和服务由其自身管理。

技能库与项目里的 Skills 有什么区别？

技能库用于收藏和整理，部署则为具体工作空间选择技能。你可以按用途建立技能组，向项目或 Agent 全局工作空间添加需要的内容。了解技能库。

AgentHub 免费吗？数据保存在哪里？

AgentHub 按 MIT 许可证开源，可免费下载使用。数据默认保存在本机，Git 备份由你配置；Agent 服务可能需要各自的订阅或 API 账号。查看本地数据说明。
