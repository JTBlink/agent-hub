一个技能库，少一些重复

从本地目录或 Git 来源导入 Skills，用标签和技能组整理内容。查看文档、检查更新，找到下一次工作需要的能力。

  • 内容与来源一起管理
  • 标签筛选与技能组归类

每个工作空间，各取所需

分别管理 Agent 的全局技能和项目技能。按用途批量添加技能组，查看部署与同步状态，让不同项目保持合适的配置。

  • 全局与项目部署
  • 技能组批量添加或移除

本地保存，有备可回

技能与应用状态保存在本机。配置自己的 Git 远端备份技能库，按需恢复，并在内容发生冲突时检查差异。

  • Git 备份与恢复
  • 桌面与 CLI 共用核心能力

    为开发、设计或研究整理各自需要的技能集合。

  3. 部署到工作空间

    选择 Agent 或项目，添加技能并查看同步状态。
