Features

Everything You Need to Manage AI Agents

One desktop app to configure, monitor, and extend all your AI coding agents.

Unified Configuration

Edit global and project-level configurations for all agents from a single interface with diff preview and safe writes.

Skill Management

Install, browse, and manage agent skills from multiple sources including Git repos, marketplaces, and local directories.

Diagnostics

Detect configuration conflicts, missing files, and permission issues. Guided recovery with one-click fixes.

Change History

Every config write is versioned with automatic backups. Compare, diff, and restore any previous state instantly.

Workspace Aware

Switch between project workspaces seamlessly. Each project gets its own scoped configurations and skill inventory.

Safe by Default

Read-preview-confirm-backup write cycle protects your agent configurations. Nothing changes without your explicit approval.
