项目与工作树

从当前项目打开文件、Markdown、终端或浏览预览。在已有工作树之间切换，把操作留在明确的目录中。

  • 文件浏览与文本编辑
  • 多标签终端与分屏

在项目里启动 Agent

直接启动已安装的 Codex、Claude Code、OpenCode 或 Hermes，也可通过 Herdr 连接和管理会话。

  • 当前目录启动与参数配置
  • 共享会话状态与归属检查

Git 与平台任务

查看变更、图片对比、提交图、分支和标签；连接 GitHub / GitLab，按多个项目查看工作项与代码审查。

  • 平台账号与私有站点
  • 评审和修复的 Agent 启动预览

可切换的技能组合

从本地或 Git 导入 Skills，用标签与技能组整理。区分安装、上传和详情，按工作空间部署需要的能力。

  • 全局与项目技能部署
  • 版本方向与覆盖确认

可维护的定时任务

从模板创建命令或 Agent 任务，编辑脚本、日程和多组提示词。查看源码与执行记录，复制为独立任务继续调整。

  • 系统原生调度与 Hermes
  • 任务包导入、导出和恢复

本地保存，按需备份

技能、任务定义与受支持的用户配置可备份到自己的 Git 远端。凭据、运行环境与任务状态留在本机。

  • Git 备份与冲突处理
  • 配套 CLI 与桌面共用核心
