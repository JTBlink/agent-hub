What it keeps clear

不是又一个设置页。
是 Agent 的控制面。

当配置散落在多个目录、多个作用域，真正昂贵的是“不确定”。AgentHub 先把事实摆出来，再让你动手。

01 / CONFIG

知道它实际读了什么

扫描全局与工作空间配置，标出实际路径、格式、解析状态和冲突来源。

scope → source → revision
02 / SKILLS

知道能力从哪里来

为每个 Skill 记录来源、版本、兼容 Agent 和安装作用域，避免重复与漂移。

source → descriptor → install
03 / RECOVERY

知道改错后怎么回来

写入前查看 Diff，自动保留备份；诊断中心把修复路径和变更历史连在一起。

revision → diff → rollback
