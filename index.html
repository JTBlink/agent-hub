功能

当多个 Agent 同时使用时，问题不是"不会配置"， 而是不确定哪个文件被哪个 Agent 读取、改错格式后工作流突然失效、 同一个 Skill 重复安装在不同作用域。AgentHub 把这些信息放到操作前面。

  • 扫描 Claude Code、Codex、OpenCode 的全局配置和工作空间配置
  • 表单或源码编辑，写入前生成 Diff 并自动备份
  • 从 skills.sh、Marketplace、Git 仓库安装 Skills，管理生命周期
  • 检测配置冲突和权限问题，提供一键修复路径
  • 变更历史可追溯，即时还原到任意备份
  • 默认只读扫描，外部修改检测，敏感字段遮罩
