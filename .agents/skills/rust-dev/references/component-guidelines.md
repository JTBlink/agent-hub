# 组件规范

适用于本仓库 React/Tauri 页面调整。主题与布局规则见 [UI 规范](ui-guidelines.md)，跨端逻辑与文件拆分见 [开发规范](coding-standards.md)。

## 选用与复用

| 场景                       | 当前入口                                                         | 要求                                                              |
| -------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------- |
| 普通单选、筛选与表单选择   | `src/components/ThemedSelect.tsx`                                | 受控 `value`，沿用 option/value 契约；禁止页面自建另一套系统下拉  |
| 技能组领域选择             | `SkillGroupSelect`                                               | 保留领域图标与标签；共享选择交互改进应下沉普通单选组件            |
| 开关                       | `ToggleSwitch`                                                   | `checked`、`disabled`、`loading` 明确区分，等待状态归属实际操作项 |
| 删除等确认                 | `ConfirmDialog`                                                  | 失败时保留弹窗与上下文，不先关闭再展示无法重试的错误              |
| 主操作、次级操作、图标操作 | `app-button-primary`、`app-button-secondary`、`app-button-ghost` | 使用已定义样式；图标按钮必须有可访问名称和焦点状态                |
| 图标、状态与展示转换       | 既有 Agent 图标、领域 badge 和 `src/lib/` 纯函数                 | 列表与详情共用，不复制技术标识解析与状态文案                      |

先查当前调用方再扩展组件；复杂领域流程不塞进普通控件。只因出现第三处相似 JSX 才考虑展示抽取；菜单交互、路径安全与跨端业务规则从第一次复用起保持单一权威实现。

## Props 与行为

- 输入、选择和开关由调用方持有业务值；组件内只维护展开、键盘活动项与焦点等交互状态。值由 props 更新后必须立即反映，取消菜单不得提交临时选择。
- 沿用 DOM 或现有回调契约，变更契约时同时检查所有调用方。不要为了复用而增加互相冲突的布尔选项、`any` 或类型断言。
- `disabled` 阻止鼠标与键盘提交；`loading` 展示当前目标的等待状态并防止重复请求。失败保留输入值与可重试入口；陈旧响应不能覆盖新目标。
- portal 菜单需清理事件监听，菜单打开时跟随触发器定位。弹窗内的菜单先消费 Escape，不能误关整个编辑流程。不能依赖隐藏按钮代替后端权限检查。
- 优先保留浏览器原生表单语义、标签关联和提交行为；自定义单选需提供 combobox/listbox/option、选中项与活动项语义。隐藏表单桥接不能成为第二个可聚焦控件。
- 组件不直接调用 CLI、文件系统或同步引擎。页面/hook 组织请求，`src/lib/tauri.ts` 维护 IPC，Rust core 统一执行业务。

## 验证与交付

- 有意义的控件交互测试覆盖选择、取消、禁用、键盘与外部点击；弹窗覆盖请求失败、输入保留、初始焦点、焦点约束与返回焦点。避免只匹配 CSS 类或 DOM 数量。
- 实际打开弹出层验证主题与定位，至少检查默认及放大字号、窄窗口和长中英文。不要把闭合态截图作为弹出菜单验收。
- README/官网截图复用 `tests/browser/product-preview.tsx` 的合成数据和实际产品组件。任务、路径、账号及提示词必须脱敏；不得用用户实际数据库截图再靠遮挡补救。
- 页面只组合布局与业务状态。共享控件按职责拆分，达到 ADR-0006 的体量上限前拆出选择器、列表行、表单区与展示纯函数。
