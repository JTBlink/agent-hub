# 预览与浏览交互原型

本原型回答：网页、HTML 与 Markdown 作为独立预览模块，如何复用公共能力，并完成从浏览、检查到交给 Agent 的交互？

完整对齐范围与架构边界见 [规划](../../docs/plans/agent-hub.md#独立预览与浏览模块)。此目录是可丢弃的交互原型，不是浏览器内核或生产模块。

## 运行

```sh
./prototype.sh preview
```

脚本自动打开 <http://127.0.0.1:4176/prototypes/preview/?variant=A>，已有当前项目目录的原型服务时复用；端口被其他服务或其他工作树占用时提示换端口，不终止已有进程。新服务在当前终端运行，按 Ctrl+C 停止。

```sh
./prototype.sh preview --layout B               # 直接查看阅读布局
./prototype.sh preview --port 4180 --no-open   # 自选端口，不打开浏览器
```

底层命令 `npm run prototype:preview` 仍可直接使用。正式应用的预览模块随应用启动，不需要单独运行本脚本。

无需启动 Tauri，不读取应用数据库或真实登录配置，不调用真实 Agent。已有前端开发服务也可打开相同路径。

## 三种布局

- `?variant=A`：浏览器与右侧检查栏。推荐默认布局。
- `?variant=B`：阅读区与底部批注区。适合 Markdown 和长文档。
- `?variant=C`：浏览器、检查栏与 Agent 演示区并排。

顶部「预览命令与布局」菜单或左右方向键切换方案；输入时保留方向键原生行为。切换布局保留当前内存状态。刷新页面重置全部数据。

## 验收路径

1. 在网页标签点「批注页面元素」，点击「新建项目」，填写批注，点「交给 Agent」，查看交付草稿并送到演示区。
2. 切到 README，点选章节段落，验证独立批注；切换源码编辑，再返回预览；点击目录定位。
3. 切到 HTML，切换移动视口，选取示例操作按钮；从截图菜单查看视口、整页、元素三种范围。
4. 打开本地 Markdown 或 HTML。Markdown 使用现有渲染器，源码编辑复用 CodeMirror；HTML 用无脚本的 sandbox iframe 展示。
5. 在左侧查看历史、登录配置、下载与远程设置；新建配置、切换网络位置、添加自动浏览计划，观察状态变化。
6. 导出批注或当前文档；关闭并恢复标签；切换深浅主题与三种布局。

## 已执行与演示的边界

真实运行：内存标签／历史、示例页面元素的 DOM 与 CSS 抓取、Markdown 渲染与源码编辑、目录滚动、批注编辑与删除、文件导入、剪贴板复制、浏览器本地文件导出、布局与主题切换。

演示：外部网页导航、Cookie 隔离与导入、网页下载、截图位图、CDP／开发工具、远程网络与画面流、真实 Agent 投递与自动浏览、公开产物托管。对应入口明确显示演示或尚未接入，未发起外部操作。

本地 HTML 单文件预览不执行脚本，不解析相对磁盘资源，不允许跨帧选取。Markdown 原型不加载相对图片或外链。上述能力包含在完整设计中，不能把本原型的限制当成正式实现验收通过。

## 复用

- `MarkdownContent`：GFM、表格、代码块和现有主题。
- `CodeEditor`：CodeMirror、语言识别、源码编辑与现有主题。
- `src/styles/brand.css`：全部工作台色彩 token。
- Lucide：与产品共用图标。

本原型的宽 model 仅服务布局比较，正式模块按规划拆为会话、渲染器、抓取、批注与交付接口；不直接将原型提升为生产实现。

HTML 示例是普通预览页面，不包含账户入口、登录按钮或登录流程。浏览器配置演示仍作为独立浏览能力保留。

默认收起资源与检查栏，标签与地址工具各占一行。左上角展开资源工具，右侧「更多操作」提供视口、查找、浏览配置与开发工具。抓取元素直接复制，批注元素打开意见编辑；截图仍为明确标注的原型演示。
